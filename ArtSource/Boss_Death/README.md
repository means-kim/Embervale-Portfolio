# Boss Death

설산 거인이 마지막 타격을 받고 무릎과 팔에 힘을 잃어 앞으로 무너지는
8프레임 사망 애니메이션입니다. Idle, Hit, Charge를 참조하여 내장 ImageGen으로
제작하며, 기존 Idle·Walk·Slam·Swing·Charge·Hit와 동일한 셀·피봇·PPU를 사용합니다.

## 결과물

- `Assets/04.Sprites/Boss/Boss_Death.png`: 투명 RGBA PNG, 2048×1024
- 4열×2행, 프레임 0–3은 위 행, 4–7은 아래 행, 각 행 왼쪽부터 재생
- Rect 512×512, 피봇 Bottom Center `(0.5, 0)`, 픽셀 `(256, 0)`, PPU 50
- Max Size 2048, Bilinear, Mipmap 끔
- `Assets/05.Animation/Boss/Boss_Death.anim`: 1.4초, 20fps 시간 눈금, Loop 끔
- 첫 프레임은 기존 최대 피격 자세인 `Boss_Hit_1`을 그대로 사용합니다.
- 마지막 프레임은 완전히 쓰러진 사망 자세입니다. Idle로 복귀하지 않습니다.

마지막 포즈를 클립 끝까지 유지하도록 1.35초에 프레임 7 참조 키를 반복합니다.
시트에는 8개 포즈, 클립에는 9개의 스프라이트 참조 키가 있습니다.
GIF는 검토를 위해 마지막 자세에 1초를 추가로 머문 뒤 반복합니다.
게임용 클립은 반복하지 않습니다. Animator가 Death 상태에 머물도록 전이를
구성해야 마지막 자세를 유지할 수 있습니다.

## 정렬 기준

생성된 첫 타격 자세와 기존 `Boss_Hit_1`의 알파 128 이상 높이를 비교하여
한 가지 배율을 구하고, 나머지 포즈에 동일하게 적용합니다. 낮아진 사망 자세를
원래 키에 맞춰 확대하지 않습니다. 팔과 무릎을 접은 자세로 셀 폭 안에 배치합니다.

초반은 발, 후반은 손·무릎·쓰러진 몸이 셀 하단의 같은 접지선에 닿도록 정렬합니다.
피봇은 전 프레임에서 고정되며, 사망 자세에서는 발바닥만 억지로 기준에 맞추지 않습니다.
생성 이미지의 알파 16/255 미만 미세 잔상을 정리한 뒤 Lanczos 크기 조정을 사용합니다.
실제 그림 경계·배율·프레임별 위치는 `measurements.json`에 기록합니다.

| 프레임 | 실제 그림 크기 (알파 > 0) | 하단 투명 여백 |
|---|---|---:|
| 0 | 395×364 | 0px |
| 1 | 345×357 | 0px |
| 2 | 350×304 | 0px |
| 3 | 398×282 | 0px |
| 4 | 368×253 | 0px |
| 5 | 390×187 | 0px |
| 6 | 375×160 | 0px |
| 7 | 376×154 | 0px |

초반 두 생성 포즈는 앞발 X 210.5px에 맞추고, 무릎을 댄 이후 프레임 3–7은
그림 경계의 가로 중심을 X 240px 근처에 유지했습니다. 생성 포즈마다 발 형태와
신체 위치에는 차이가 있으며, 이 정렬은 모든 신체 부위의 픽셀 위치를 고정한다는 뜻은 아닙니다.
위쪽과 양옆에는 투명 여백이 있으며, 포즈가 셀 밖으로 잘리지 않습니다.

얼음 파괴·눈먼지·White Flash는 별도 효과로 추가할 수 있도록 그림에 넣지 않았습니다.
Animator 전이, HP/사망 판정, 이동·공격 중단, 오브젝트 제거, VFX/SFX는 별도로 연결해야 합니다.
