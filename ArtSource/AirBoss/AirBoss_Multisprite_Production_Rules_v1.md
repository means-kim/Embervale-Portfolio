## 3. 고정할 디자인과 허용되는 동작

- 가면의 길이·형태·균열·푸른 발광 틈, 높은 분절 목 갑옷, 가슴과 몸통의 판 구조를 유지한다.
- 팔 길이, 손 크기, 손가락·발톱의 수와 관절, 천의 부착점과 주요 갈래를 유지한다. 가려진 부위를 새 장식이나 임의의 손가락으로 채우지 않는다.
- 왼쪽 위의 후면 천 고리와 오른쪽 아래의 긴 천 흐름 등 마스터의 비대칭 디자인을 유지한다. 좌우 복제로 대칭화하지 않는다.
- 팔·손목·관절의 회전, 몸통의 미세한 기울기, 천의 접힘과 후행 움직임은 허용한다. 단단한 가면·갑옷·고드름을 고무처럼 늘리거나 찌그러뜨리지 않는다.
- 광원 방향, 재질, 전체 색과 명암을 프레임 사이에서 유지한다. 눈·틈새의 발광 위치를 바꾸거나 임의의 점멸을 추가하지 않는다.
- 공격 VFX, 빨간 위험 가이드, 배경, 바닥 그림자, 텍스트, 가이드 선은 Body PNG에 포함하지 않는다. 기존 신체의 푸른 발광은 보존한다.

## 4. 배치·좌표·크기 유지

제작 좌표는 **셀 왼쪽 아래 (0,0), 오른쪽 위 (1024,1024)**를 기준으로 한다. 피벗은 매 셀 (512,512)이며 가면이나 가슴의 위치와 구분한다. PNG 픽셀 배열과 이미지 분석은 왼쪽 위 원점이므로 표·기록에 원점을 반드시 표시한다.

- 모든 프레임을 같은 1024 캔버스와 같은 기준 좌표 위에서 제작한다.
- 프레임 00은 현재 마스터를 그대로 사용한다. 디코딩한 RGBA 픽셀이 마스터와 같아야 하며 다시 생성하거나 재보간하지 않는다.
- 나머지 프레임은 마스터와 직전·다음 포즈를 함께 참조한다. 같은 셀 좌표에 겹쳐 비교하고, 비교할 때도 외곽을 재정렬하지 않는다.
- 가면·목 갑옷·흉갑·양쪽 손목·천 부착점을 대응시켜 체격 변화와 의도한 관절 움직임을 구분한다. 기준점을 맞춘다는 이유로 모든 신체 부위를 정지시키지는 않는다.
- 자동 Trim, 외곽 중심 맞춤, 프레임별 fit-to-cell, 개별 확대·축소, 종횡비 변형을 금지한다. 천이 넓게 펼쳐져도 얼굴·몸통을 줄여 맞추지 않는다.
- 시트 조립은 검수된 셀을 정수 좌표에 그대로 복사한다. 조립 과정에서 리사이즈·재보간하지 않는다.

마스터의 가면 위부터 천 끝까지 약 690px는 시각적 참고값이며 프레임마다 맞출 목표 높이가 아니다. 높은 후면 천까지 포함한 주요 외곽은 604×778px다. 동작에 따른 외곽 변화는 허용하되 체격 자체는 유지한다.

### 실제 마스터의 여백

아래는 왼쪽 위 원점, 양끝 픽셀을 포함한 범위다.

| 측정 | X | Y | 여백: 좌 / 우 / 상 / 하 |
| --- | --- | --- | --- |
| 모든 alpha>0 | 131~935 | 84~910 | 131 / 88 / 84 / 113px |
| 주요 외곽 alpha≥8 | 211~814 | 126~903 | 211 / 209 / 126 / 120px |

모든 셀의 바깥 64px 띠는 완전 투명이어야 한다. 즉 0 기반 픽셀 인덱스에서 alpha>0인 픽셀은 X·Y 모두 **64~959** 안에 있어야 한다. alpha≥8 수치는 주요 실루엣 비교용이며 alpha 1~7을 숨겨 안전 판정을 통과시키는 기준이 아니다.

희미한 stray alpha가 발견되면 천·발광의 일부인지 확인하고 처리 이력을 남긴다. 손·천 끝을 잘라내거나 alpha를 일괄 문턱 처리해 여백을 확보하지 않는다. 마스터의 기존 부분 투명도도 불투명으로 일괄 변환하지 않는다.

현재 Idle의 여백은 실제로 확인했지만 큰 동작의 안전성은 아직 확인하지 않았다. 공간이 부족하면 해당 포즈와 공통 규격을 재검토하고 새 마스터 버전으로 관리한다. 특정 포즈만 줄이지 않으며, 기존 프레임들과 다른 체격을 몰래 혼용하지 않는다.

## 5. Idle 동작 규칙

Idle은 정면을 유지하는 차분하고 위협적인 부유 자세다. 가슴·어깨·팔·손목의 작은 자세 변화와 천의 느린 흐름으로 살아 있는 느낌을 만든다. 공격 준비처럼 양팔을 높이 들거나 몸통을 크게 젖히지 않는다.

이번 Idle의 제작 기준은 **캔버스 전체의 이동량 0, 전체 배율 변화 0**이다. 전체 이미지를 상하 이동·회전·확대하거나 흔드는 것만으로 프레임을 만들지 않는다. 몸통 내부의 작은 자세 변화는 허용하며, 실제 월드 부유 이동과 중복되는 큰 상하 왕복은 넣지 않는다. 월드 부유 방식·코드는 별도 구현 범위다.

움직임은 **가슴·어깨 → 팔·손목 → 천 부착부 → 천 끝** 순서로 이어진다. 주요 천 끝은 본체의 방향 전환보다 늦게 따라오되 모든 천을 같은 파형으로 움직이지 않는다. v02에서는 현재 1.2초 재생과 느린 재생으로 지연·진폭을 검수하며, 8장 초기안의 1프레임 지연을 16장에 그대로 대입하지 않는다.

### v01 8프레임의 초기 동작 계획 — 과거 이력

이 표는 제작할 포즈의 역할을 정한 초기안이며 완성된 애니메이션의 동작 검증 결과가 아니다.

| 프레임 | 시작 시간 | 본체·팔·손의 역할 | 천의 역할 |
| --- | --- | --- | --- |
| 00 | 0.000초 | 현재 마스터 그대로. 다음 열림으로 이어지는 기준 자세 | 현재 마스터 그대로. 07에서 이어져 01 방향으로 흐름 |
| 01 | 0.375초 | 가슴·어깨가 조금 열리고 팔이 작게 따라감 | 부착부가 반응하고 천 끝은 이전 흐름 유지 |
| 02 | 0.750초 | 열림의 정점 부근. 손목·손가락의 작은 후행 | 본체보다 늦게 펼쳐지는 흐름 |
| 03 | 1.125초 | 어깨·팔이 회복 방향으로 전환 | 일부 긴 천은 뒤늦게 정점을 지나감 |
| 04 | 1.500초 | 기준 자세 근처를 반대 방향으로 통과. 00 복제 금지 | 00과 다른 진행 방향과 접힘 유지 |
| 05 | 1.875초 | 어깨·팔이 조금 이완되고 손목이 따라감 | 회복 방향의 흐름이 천 끝까지 전달 |
| 06 | 2.250초 | 이완의 정점 부근에서 다음 열림 준비 | 천의 관성이 늦게 남았다가 전환 |
| 07 | 2.625초 | 00으로 접근하되 같은 그림으로 정지하지 않음 | 07→00→01로 위치와 진행 방향이 이어짐 |

00·02·04·06의 주요 상태를 먼저 비교하고, 01·03·05·07을 연결한다. 00 이후의 모든 프레임은 전체 마스터와 비교하여 디자인이 조금씩 달라지는 누적 오차를 방지한다.

### v01 초기 재생 시간과 루프 — 과거 이력

현재 v02는 기존 8장을 짝수 번호에 보존하고 홀수 번호에 중간 동작을 넣는다. 15는 기존 07→00 사이의 새 그림이다. **00~15를 각 0.075초씩, 총 1.2초로 재생**한다. 아래 3초 표기는 v01 초기안이며 현재 클립에 재적용하지 않는다. 실제 순서·종료 유지 키는 [v02 기록](../../Docs/Boss/AirBoss/AirBoss_Idle_Float_v02.md)을 따른다.

- 최초 검토는 프레임당 **0.375초**, 총 **3.0초**로 한다. 프레임 07도 0.375초 표시한 뒤 00으로 돌아간다.
- 8장은 고유 그림 수다. 초당 고유 그림 전환은 8÷3≈2.667회이며, “8장=8fps”가 아니다. 8fps로 균등 재생하면 1초가 되어 의도한 길이와 다르다.
- 3.0초의 루프 경계는 다시 00을 가리킨다. 첫 그림을 복제한 9번째 셀이나 중복 노출을 추가하지 않는다. 엔진 타임라인 샘플률과 고유 그림 수는 별개로 관리한다.
- 00→…→07→00 순서로 재생한다. 00~03을 역순 복제하는 ping-pong으로 후반을 대신하지 않는다. 천의 지연도 거꾸로 재생되어 부자연스러워질 수 있다.
- 3.0초 실제 속도, 느린 재생, 07→00→01 확대 비교로 연결을 확인한다. 루프 경계의 이동 폭·방향이 주변 구간과 비슷하게 이어져야 한다.
- 8장과 3초만으로 부드러움이 보장되지 않는다. 끊김이 크면 포즈 간격·노출 시간을 먼저 검토하고, 추가 연결 그림이 필요하면 장수·배열·시트 규격을 함께 버전 갱신한다. 장수를 맞추려고 복제하거나 불투명도 교차만으로 움직임을 대신하지 않는다.

## 6. 시트 배열과 셀 좌표

현재 v02는 **4×4, 4096×4096**이다. 위에서부터 00~03 / 04~07 / 08~11 / 12~15다. 프레임 i의 Unity Rect는 아래 원점 기준 `(i%4)×1024, (3-floor(i/4))×1024, 1024, 1024`이며 Pivot은 각 셀 Center다.

### v01 4×2 좌표 — 과거 이력

위 행을 왼쪽부터 00~03, 아래 행을 왼쪽부터 04~07로 배치한다. 번호나 격자선은 실제 PNG에 넣지 않는다.

```text
00  01  02  03
04  05  06  07
```

각 Rect는 폭·높이 1024다. 아래 표의 PNG 좌표는 셀 왼쪽 위, 제작·슬라이스 Rect 좌표는 시트 왼쪽 아래 기준의 셀 왼쪽 아래다.

| 프레임 | 열 / 위부터 행 (0 기반) | PNG 위치 X,Y | 아래 원점 Rect X,Y,W,H |
| --- | --- | --- | --- |
| 00 | 0 / 0 | 0, 0 | 0, 1024, 1024, 1024 |
| 01 | 1 / 0 | 1024, 0 | 1024, 1024, 1024, 1024 |
| 02 | 2 / 0 | 2048, 0 | 2048, 1024, 1024, 1024 |
| 03 | 3 / 0 | 3072, 0 | 3072, 1024, 1024, 1024 |
| 04 | 0 / 1 | 0, 1024 | 0, 0, 1024, 1024 |
| 05 | 1 / 1 | 1024, 1024 | 1024, 0, 1024, 1024 |
| 06 | 2 / 1 | 2048, 1024 | 2048, 0, 1024, 1024 |
| 07 | 3 / 1 | 3072, 1024 | 3072, 0, 1024, 1024 |

피벗은 시트 전체의 중심이 아니라 **각 셀의 Center**다. 시트에서 셀을 다시 추출한 RGBA 픽셀이 개별 프레임과 동일해야 한다. 파일명·슬라이스 자동 번호만 믿지 않고 시각적 순서를 대조한다.

## 7. 파일·참조·버전 규칙

현재 v02는 `idle/frames/v02/`, `idle/sheets/AirBoss_Idle_Float_4x4_1024_v02.png`와 `Assets/04.Sprites/AirBoss/AirBoss_Idle_Float_4x4_1024_v02.png` 및 `.meta`에 보존한다. 아래 v01 경로도 과거 원본으로 유지한다.

개별 셀과 시트를 함께 보존한다. 생성·수정 프롬프트에는 마스터 경로·버전, 프레임 번호, 직전·다음 동작, 고정할 디자인, 목표 셀 규격을 기록한다. 매번 마스터를 실제 이미지 참조로 사용하며, 프롬프트와 미리보기만으로 제작 완료를 선언하지 않는다.

ArtSource는 제작 원본 보관 위치다. Unity 도입이 별도로 요청되면 검수본을 `Assets/04.Sprites/AirBoss`로 옮기는 범위를 정하고 기존 `.meta` GUID를 보존한다. `Assets/04.Sprites/Boss`는 변경하지 않는다. 현 문서는 Assets의 기존 복사본을 동기화하거나 Import 설정을 바꾸는 권한을 추가하지 않는다.

## 8. 완료 판정

### 실제 PNG·시트

- [ ] 개별 셀 16개가 모두 1024×1024 RGBA이며 alpha 투명 배경이다.
- [ ] 00의 RGBA 픽셀이 기준 마스터와 동일하다.
- [ ] 모든 셀의 바깥 64px가 완전 투명하며 손·천·발광이 잘리지 않는다.
- [ ] 가면·갑옷·손·천의 구조와 체격, 광원·재질이 유지된다.
- [ ] 같은 셀 좌표에서 겹쳐 확인했고 자동 Trim·재중앙정렬·개별 배율 보정이 없다.
- [ ] 시트가 정확히 4096×4096, 4×4이며 추출한 셀 픽셀이 개별 파일과 동일하다.

### 동작과 루프

- [ ] 00~15의 서로 다른 상태가 전신 자세와 천의 흐름으로 읽힌다.
- [ ] 몸통·어깨·팔·손·천의 후행 관계가 유지된다.
- [ ] 1.2초 반복에서 14→15→00→01의 위치·속도·흐름이 자연스럽다.
- [ ] 손가락 수, 가면 균열, 갑옷 판, 천 갈래가 프레임마다 바뀌지 않는다.
- [ ] 전체 이미지 상하 이동, 크기 변화, 역순 복제, 과도한 공격 전조로 대체하지 않았다.
- [ ] 어두운 바탕·밝은 바탕·투명 확인 화면에서 가장자리와 잔상을 확인했다.

### Unity 적용 시 별도 확인

도입 시 확인할 기준은 **PPU 24**, Sprite Multiple 16개, 1024×1024 셀, 셀별 Center, 실제 4096×4096 해상도 유지다. Max Size 4096은 이 시트를 축소하지 않기 위한 기준이며, 플랫폼별 재축소·압축 여부도 실제 임포트 결과로 확인한다. 필터·압축의 최종값은 게임 화면 검토 전 임의로 확정하지 않는다.

PPU 24는 모든 AirBoss 시트에 동일하게 적용하며 동작별로 바꾸지 않는다. PPU는 Unity 임포트 설정이며 PNG 해상도나 세부 묘사를 바꾸지 않는다. 현재 마스터 100% 배율·셀 규격·피벗은 유지한다. 실제 표시 크기·Transform Scale·카메라 배치는 별도 검토한다.

아트 검수 완료와 Unity 임포트·실제 재생·게임 크기 검수 완료를 별도 상태로 기록한다. 위 목록은 버전별 검수용이다. 현재 v02는 정적 파일·여백·셀 픽셀 일치·Unity 16분할과 두 루프의 Sprite 적용 순서를 확인했다. 실제 게임 화면에서의 자연스러움·최종 아트 승인·게임 크기는 별도 검토 대상이다. 세부 결과는 제작 기록에 남긴다.

## 9. 제작용 공통 지시문

현재 v02 지시: 기존 v01 8장은 변경하지 않고 각 구간의 양쪽 이미지를 참조해 새 중간 동작 8장을 제작한다. 07→00 구간도 포함한다. 기존 그림은 짝수 00~14, 새 그림은 홀수 01~15로 배치한다. 1024 셀·Center·64px 여백·PPU 24를 유지하고 **16장·4×4·4096×4096·각 0.075초·1.2초 루프**로 조립한다.

아래는 v01 최초 제작 당시 지시문으로 보존한다. 장수·배열·시간은 위 v02 지시가 우선한다.

> 현재 `AirBoss_Idle_Master_image2.png` 1024×1024 마스터를 100% 체격·디자인·좌표 기준으로 사용한다. 과거 72% 축소를 재적용하지 않는다. 00은 마스터 픽셀을 그대로 사용하고, 후속 포즈는 정면 Idle을 유지하며 몸통·어깨·팔·손목과 천의 후행으로 변화를 만든다. 가면·갑옷·손가락·천 부착점·주요 갈래·광원·색을 바꾸지 않는다. 각 프레임은 1024×1024 실제 투명 RGBA, Center (512,512), 사방 64px 안전 여백을 유지한다. 자동 Trim·외곽 중앙정렬·프레임별 확대축소를 하지 않는다. 8개 고유 프레임을 00~07로 검수한 후 위 행 00~03 / 아래 행 04~07의 4096×2048 시트로 픽셀 그대로 조립한다. 3초 루프의 07→00→01 연결과 실제 alpha·해상도를 확인한다. Unity 임포트 PPU는 24로 통일한다. 큰 포즈의 셀 적합성, 실제 게임 표시 크기, Unity 재생은 별도 검증한다.
