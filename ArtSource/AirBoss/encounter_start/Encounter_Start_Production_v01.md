이미 공중에 떠 있는 상태에서 고개와 몸통을 숙이고 팔을 모은 뒤, 몸을 일으키며 양팔을 어깨 높이에서 양옆으로 크게 펼친다. 망토가 뒤늦게 펼쳐지고 본체와 천의 관성을 정리하여 Idle로 복귀한다. 기존 Raise의 머리 위 높은 V자 시전과 구분한다. 기존 눈·갑옷의 푸른 발광만 약하게 강화하며 공격 구체·빔·입장 이동·순간이동·바닥 효과는 넣지 않는다.

| 셀 | 동작 |
| --- | --- |
| 00 | 고정 마스터 픽셀 그대로 |
| 01~03 | 고개·몸통을 점진적으로 숙이고 양팔을 몸 가까이 모음 |
| 04~06 | 고개·몸통을 일으키고 양팔을 바깥으로 펼침, 천 후행 |
| 07~09 | 어깨 높이의 넓은 펼침과 짧은 위세 유지, 천이 뒤늦게 최대 확장 |
| 10~12 | 어깨와 팔을 점진적으로 내리고 천의 관성 수습 |
| 13~15 | 같은 비반전 Idle로 가까워지는 새 복귀 포즈 |

1024×1024 RGBA 셀, 16장, 4×4·4096×4096. PPU 24, Center (512,512), 모든 alpha>0에 사방 64px 투명 여백. 전체 캔버스 정규화 외에 개별 체격 축소·Trim·재중앙정렬·역순 복제로 중간 그림을 대신하지 않는다. 주요 최대 자세를 먼저 검사한다. 연결된 부분 투명 천과 발광을 보존하고 분리된 희미한 잡점 처리 수량을 기록한다.

3.6초는 후속 클립의 기획 참고이며 이번에는 타임라인·클립·재생 파일을 만들지 않는다. 생성 원본·제외 후보·개별 셀·시트와 실제 프롬프트를 보존하고 정적 이미지 검수·Unity 분할 확인·실제 게임 검증 상태를 구분한다.
