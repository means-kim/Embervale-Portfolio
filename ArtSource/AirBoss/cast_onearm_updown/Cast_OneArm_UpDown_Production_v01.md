# Cast_OneArm_UpDown v01 제작 기준

2026-09-30 사용자 요청: 이 동작의 멀티 스프라이트만 제작한다. 다른 동작·클립·Animator·씬·게임 코드는 변경하지 않는다.

## 참조와 고정 기준

- [공통 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [기획서 ANIM-04](../Aerial%20Boss%20Design%20Document%20v1.md), [콘티 단팔 항목](../references/AirBoss_Storyboard_v01.png)을 확인한다.
- [현재 Idle 마스터](../idle/AirBoss_Idle_Master_image2.png)의 100% 체격·디자인·좌표계를 유지한다. 고정 버전과 SHA-256 일치 확인.
- 시전 팔은 **캐릭터 오른팔 = 정면 화면 왼쪽 팔**로 고정한다. 화면 오른쪽 팔은 낮은 보조 자세이며 같은 시전 구체를 만들지 않는다. 좌우 반전 사용 금지.
- 손 근처 구체와 하강 때 손·팔을 뒤따르는 푸른 잔상은 Body PNG에 포함한다. 독립 투사체·피해 영역·바닥 효과·빨간 가이드는 포함하지 않는다.

## 포즈 계획

| 프레임 | 역할 |
| --- | --- |
| 00 | Idle 마스터 원본 그대로 |
| 01~04 | 화면 왼쪽 팔을 당겨 모았다가 올림. 같은 쪽 어깨가 먼저 움직임 |
| 05~06 | 한 팔 최대 상승과 짧은 응축. 반대팔은 낮게 유지 |
| 07~09 | 한 팔 하강과 시전. 같은 쪽 어깨·몸통이 따라가고 천은 지연 |
| 10~12 | 낮은 손의 관성·되돌림, 잔광 소멸 |
| 13~15 | 정면 Idle로 복귀, 남은 천 흐름 정리 |

일반 캐스팅의 12장은 초기 목표다. 이번에는 앞서 제안한 16장을 사용해 단팔 하강 궤적과 회복 연결을 확보한다. 기획서의 준비 1.2초 / 하강 0.5초 / 회복 1.5초는 향후 연결 의도이며 실제 클립은 생성하지 않는다.

## 출력과 확인

1024×1024 RGBA 셀 16장, 4×4·4096×4096 시트, Center (512,512), PPU 24. 모든 alpha>0에 사방 64px 여백 적용. 00은 마스터 파일 그대로 보존하고 나머지는 개별 새 그림으로 제작한다.

실제 생성 크기와 요청 크기를 구분해 기록한다. 전체 캔버스 정규화 외에 Fit·Trim·개별 체격 축소·외곽 중앙정렬·역순 복사는 하지 않는다. 시트는 셀 픽셀을 그대로 복사하고 재추출 검사한다.

원본 `source/v01`, 셀 `frames/v01`, 시트 `sheets`. 초기 시도와 수정 프롬프트는 보존한다. 결과·검증 범위는 [제작 기록](../../../Docs/Boss/AirBoss/AirBoss_Cast_OneArm_UpDown_v01.md)에 기록한다. 실제 게임 재생과 최종 아트 승인은 별도다.
