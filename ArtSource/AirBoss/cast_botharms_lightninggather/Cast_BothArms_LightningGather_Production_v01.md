최신 수정본은 [천·몸통 움직임과 1024 셀을 적용한 v02](Cast_BothArms_LightningGather_Production_v02.md)다. 이 v01은 비교용으로 보존한다.

2026-10-04 사용자 요청: 양옆 팔을 둥글게 모아 가슴 아래의 작은 번개 덩어리를 감싼다. 천천히 응축하고 잠시 유지한 뒤 Idle로 복귀한다. 24프레임 멀티 스프라이트만 제작하며 애니메이션 클립은 만들지 않는다.

- 00과 23은 [Idle 마스터](../idle/AirBoss_Idle_Master_image2.png)의 RGBA 픽셀을 그대로 사용했다. 01~22는 built-in image_gen으로 각각 그렸다.
- 00 Idle / 01~04 준비·펼침 / 05~13 모으기·응축 / 14~17 유지 / 18~22 소멸·이완 / 23 Idle.
- 손 사이의 작은 푸른 번개와 손목 빛은 Body PNG에 포함된다. 독립 공격 판정이나 발사체가 아니다.

## 실제 사양과 공통 여백

| 항목 | 값 |
| --- | --- |
| 생성 요청 / 실제 생성 파일 | 1024×1024 요청 / 1254×1254 RGBA 출력 |
| 규격화 | 생성 결과의 전체 정사각 캔버스를 1024×1024로 동일하게 변환 |
| 최종 셀 | 1152×1152 RGBA, 중앙 1024 영역에 그림을 놓고 사방 64px 투명 패딩 |
| Part1 | 00~15, 4×4, 4608×4608 |
| Part2 | 16~23, 4×2, 4608×2304 |
| Unity | Sprite Multiple, PPU 24, 셀별 Center (576,576), Max Size 8192 |
| 배열 | 왼쪽 위부터 행 우선, 두 시트 연속 00~23 |

생성본의 매우 약한 alpha 픽셀까지 삭제하지 않고 보존하기 위해 공통 셀을 확장했다. 프레임별 외곽 fit·Trim·재중앙정렬·배율 보정은 하지 않았다. 원본의 (512,512)와 최종 셀의 (576,576)은 같은 그림 기준점이며 투명 패딩 자체는 보이는 몸체를 키우거나 줄이지 않는다. 생성된 팔·손의 실제 그림 차이까지 픽셀 불변이라고 의미하지는 않는다.

## 수정과 검토

초기 generated 시리즈는 몸통 크기와 손 모으기 속도 차이가 있어 채택하지 않았다. revised 시리즈는 원본의 머리·몸통·주요 천 위치를 유지하는 국소 편집 지시로 다시 제작했다. 05/06/07/18/19/21은 refined 시리즈로 손 동작을 추가 보완했다. 손 간격이 큰 자세가 먼저 오도록 최종 07/08/09는 각각 `frame08_revised`, `frame09_revised`, `frame07_refined`를 배치했다. 정확한 셀별 채택 소스는 [검사 기록](validation_v01.json)에 있다.

- 첫·끝 셀의 중앙 1024 영역은 Idle 마스터와 바이트 단위 일치.
- 24셀 모두 사방 64px의 alpha=0 검사 통과.
- 시트에서 셀을 재추출한 픽셀과 개별 프레임 일치.
- Unity 실제 로드 결과: 16+8=24 Sprite, Rect 1152, Pivot 576, PPU 24, 실제 텍스처 해상도 유지. [Unity 결과](unity_validation_v01.json).
- 전체 비교로 몸통 크기와 포즈 흐름을 검토했다. 프레임별 손가락·갑옷·천의 미세한 재묘사 차이는 남는다. 최종 재생의 자연스러움과 실제 게임 카메라 크기는 별도 검토 대상이다.
- 미리보기 기본 12fps는 2초 검토 설정이며 실제 클립 타이밍을 확정하지 않는다. 천천히 모으기와 유지 시간은 사용자 클립에서 조절한다.

## 보존과 범위

[최초·보완 프롬프트](prompts_v01.json), [추가 보완 프롬프트](refinement_prompts_v01.json), `source/v01`, `frames/v01`, `sheets`에 제작 파일을 보존한다. [조립 스크립트](build_sheet.py)는 생성 이미지를 규격화·패딩·배치하고 메타를 만든다. 그림이나 관절 움직임을 절차적으로 생성하지 않는다.

Unity 배포 위치는 `Assets/04.Sprites/AirBoss`의 동일 파일명 PNG와 meta다. 애니메이션 클립·Animator·씬·프리팹·게임 코드 및 `Assets/04.Sprites/Boss`는 변경하지 않았다. 새 프레임을 사용할 실제 클립 작성은 사용자 작업이다.
