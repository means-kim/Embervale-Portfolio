# Cast_RiseDrop_ShadowSplit v01 제작 기준

2026-09-30. 최신 사용자 요청에 따라 이 동작의 멀티 스프라이트만 제작한다. 앞선 기획 수정 단계의 제작 보류는 이번 요청으로 해소되었다. 클립·Animator·씬·프리팹·게임 코드는 만들거나 변경하지 않는다.

## 기준

- [기획서 ANIM-08](../Aerial%20Boss%20Design%20Document%20v1.md), [멀티 스프라이트 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [Idle 마스터 지침](../idle/Master%20Crafting%20Guide%20for%20Aerial%20Bosses%20%28Idle%29%20v1.md), [콘티](../references/AirBoss_Storyboard_v01.png)를 따른다.
- [고정 마스터](../idle/AirBoss_Idle_Master_image2.png)를 모든 생성의 디자인·체격 참조로 사용한다. 00은 원본 파일 그대로 보존한다. 과거 72% 축소를 다시 적용하지 않는다.
- 마스터와 콘티, 기존 LiftDrop·Raise 비교 이미지와 ForwardReach 주요 자세를 실제 이미지로 확인한다. 이번 동작은 전신 수직 이동과 잔상 분리이며 양팔 구체 시전·팔 내리치기·수평 대시를 추가하지 않는다.

## 동작 구성

| 셀 | 역할 |
| --- | --- |
| 00 | 고정 Idle 마스터 |
| 01~04 | 팔·몸통 준비 후 점진적 상승, 천은 아래로 후행 |
| 05 | 상승 정점, 상단 천은 접혀 여백 확보 |
| 06~07 | 하강, 천 끝은 위로 늦게 따라옴 |
| 08 | 원래 부유 높이보다 낮은 최저점에서 정지하며 잔상 2개 분리 시작 |
| 09~12 | 본체는 위로 복귀, 잔상은 좌우로 벌어짐 |
| 13 | 잔상이 옅어지며 소멸, 본체는 부유 높이로 안정 |
| 14~15 | 잔상 없이 천과 손목이 Idle로 정리됨 |

잔상은 피해 없는 보스 형상의 푸른 시각 효과다. 본체와 같은 프레임 PNG·시트에 그리며 별도 VFX 자산·충돌·히트박스·위험 가이드를 만들지 않는다. 본체가 가장 선명하게 읽혀야 한다. 비대칭 디자인을 좌우 반전해 대체하지 않는다.

이번 시트에는 자세 변화와 함께 셀 내부의 상승·하강·원래 높이 복귀가 보이도록 그린다. 전체 PNG 이동만으로 연결 그림을 대신하지 않으며, 자동 재중앙 정렬로 이 높이 차이를 지우지 않는다. 실제 월드 이동 코드는 별도 범위다. 타이밍은 클립에서 확정할 후속 값이며 이번에는 재생 파일도 만들지 않는다.

## 출력과 검토

- 1024×1024 RGBA 셀 16장, 4×4·4096×4096 시트, PPU 24, 각 셀 Center (512,512).
- 몸·천·잔상·희미한 발광 전체의 alpha>0에 사방 64px 여백을 검사한다. 본체를 줄이거나 외곽을 잘라 통과시키지 않는다.
- 생성 결과가 1254 정사각형이면 전체 캔버스를 동일 비율로 1024에 정규화하고, 마스터 대비 체격·좌표를 확인한다. 실루엣 fit·Trim·개별 체격 보정은 하지 않는다.
- 분리된 저농도 잡점 정리는 기존 제작 스크립트와 같은 엄격한 조건으로만 수행하며 수량을 기록한다. 연결된 반투명 천·잔상은 유지한다.
- 주요 자세와 전체 셀을 밝은·어두운 바탕에서 정적으로 확인한다. PNG 시트 재추출 픽셀 일치, Unity Multiple·16개 Rect·피벗·PPU·실제 해상도를 확인한다.
- [제작 기록](../../../Docs/Boss/AirBoss/AirBoss_Cast_RiseDrop_ShadowSplit_v01.md)에 원본, 실제 프롬프트, 측정값, 미검증 범위를 보존한다.
