# Death v01 제작 기준

2026-10-01. [공통 제작 규칙](../AirBoss_Multisprite_Production_Rules_v1.md)과 [기획서 ANIM-10](../Aerial%20Boss%20Design%20Document%20v1.md)을 따른다. 사용자는 Death 멀티스프라이트 제작을 요청했으며 애니메이션 클립은 제외했다.

- 총 32프레임 00~31, 16장씩 두 시트. 각 4×4·4096×4096, 셀 1024×1024 RGBA·Center·PPU 24.
- 00은 현재 Idle 마스터의 원본 픽셀 그대로 사용한다. 다른 프레임은 마스터를 실제 이미지 참조로 사용해 개별 생성한다.
- 최종 v01 그림 기준 00~10: 힘을 잃고 고개·어깨·팔이 처지며 비대칭으로 기울어짐, 균열이 점차 나타남. 11~19: 천과 갑옷이 빠르게 분해됨. 20~31: 분리된 조각과 천이 회전·표류하며 여운을 남김. 15→16은 동일한 연속 동작이다.
- 약 4초를 출발점으로 준비는 느리게, 분해 순간은 빠르게, 마지막 파편은 여운 있게 배분한다. 자세에 따라 노출 시간을 제안하되 클립을 만들지 않는다.
- 현재 v01에서는 바닥 잔해 없이 작은 파편과 천이 옅어지는 종결안을 제작한다. 이는 제작상의 선택이며 바닥 잔해나 별도 사망 VFX의 최종 기획 확정이 아니다.
- 분해는 원래 가면·목·가슴·팔·천의 부위에서 발생한다. 새 신체 부위나 피·살점을 추가하지 않는다. 파편화에 따른 의도적인 연결 해체를 디자인 흔들림과 구분한다.
- 전체 캔버스 규격 정규화 외에 개별 체격 축소·자동 Trim·재중앙 정렬·종횡비 변형·역순 복제를 하지 않는다. 분해 이후에도 파편 구름을 셀에 꽉 맞추거나 다시 확대하지 않는다.
- 모든 alpha>0 픽셀에 사방 64px 여백 검사. 파편·천·발광을 잘라서 통과시키지 않는다. 마스터의 반투명성을 보존한다.
- 원본은 source/v01, 셀은 frames/v01, 시트는 sheets에 보존한다. Unity 도입은 Assets/04.Sprites/AirBoss에 새 버전 파일과 meta로 저장한다.
- 클립·Animator·씬·게임 코드·전역 설정·Assets/04.Sprites/Boss는 변경하지 않는다. 정적 아트/픽셀/슬라이스 검증과 실제 재생·게임 크기 검증을 구분한다.

프롬프트와 실제 생성·수정·검증 기록: [Death v01](../../../Docs/Boss/AirBoss/AirBoss_Death_v01.md).
