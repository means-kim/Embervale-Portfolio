# Cast_BothArms_LiftDrop v01 제작 기준

2026-09-30. 이번 사용자 요청 범위는 이 동작의 멀티 스프라이트 제작이다. 다른 동작, Animation Clip, Animator, 씬, 공격 기능은 제작·수정하지 않는다.

## 참조와 동작

- [현재 Idle 마스터](../idle/AirBoss_Idle_Master_image2.png)를 체격·디자인·좌표 기준으로 사용한다. 원래 비반전 가면·갑옷·천 부착점·광원을 유지한다.
- [기획서 ANIM-06](../Aerial%20Boss%20Design%20Document%20v1.md), [공통 제작 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [콘티](../references/AirBoss_Storyboard_v01.png)의 3번 양팔 상승·하강을 따른다.
- 이번 v01은 **16장**으로 구성한다. 콘티의 12장·약 3초는 동작 참고이며 이번 출력 장수가 아니다. 기획서의 3.4초는 향후 재생 검토를 위한 초기안이고 클립을 만들지 않는다.
- 양팔과 몸통이 힘을 모아 상승 → 머리 위 구체 응축 및 짧은 홀드 → 양팔을 강하게 내림 → 천의 후행과 잔광 감쇠 → Idle에 가까운 자세로 복귀.
- 구체·손팔 잔상은 Body PNG에 포함한다. 실제 지면 공격·피해 판정·빨간 위험 가이드는 별도 범위다. 손이 땅에 닿는 동작으로 바꾸지 않는다.

## 프레임 역할

| 셀 | 역할 |
| --- | --- |
| 00 | 현재 Idle 마스터 파일 그대로 |
| 01~04 | 준비, 가슴 높이에서 얼굴 양옆을 거쳐 머리 위로 양팔 상승 |
| 05~06 | 최대 전조·응축 홀드와 하강 준비 |
| 07~09 | 구체 소멸·양팔 하강·몸통 압축 |
| 10~12 | 팔과 천의 후행, 잔광 소멸, 본체 회복 시작 |
| 13~15 | 원래 정면 Idle 방향으로 자세와 천의 흐름 정리 |

## 출력과 검수

1024×1024 RGBA 셀 16개, 4×4·4096×4096 시트. Center (512,512), PPU 24, 모든 alpha>0 픽셀에 사방 64px 투명 여백을 적용한다. 00은 마스터 픽셀을 그대로 복사한다. 프레임별 Trim·외곽 맞춤 축소·재중앙정렬을 하지 않는다.

생성 도구의 실제 출력 해상도와 셀 규격은 구분해 기록한다. 정사각형 생성 캔버스 전체만 공통 1024 셀로 정규화한다. 연결된 천·발광을 보존하며, 가시부에서 16px 넘게 떨어진 독립 alpha 1~7 잡점만 정리하고 수량을 기록한다. 손·천이 여백을 침범하면 잘라내지 않고 다시 그린다.

정적 아트·여백·시트 픽셀 일치·Unity Multiple 분할과 실제 게임 재생/전환 품질을 구분한다. 이번에 실제 재생·게임 배치를 검증하지 않는다.

결과와 생성 프롬프트는 [제작 기록](../../../Docs/Boss/AirBoss/AirBoss_Cast_BothArms_LiftDrop_v01.md)에 보존한다.
