# Move_Bank v01 제작 기준

2026-09-30. 사용자 요청: Move_Bank 멀티스프라이트만 제작하고 애니메이션 클립은 만들지 않는다.

## 제작 구성

- [공통 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [보스 기획서](../Aerial%20Boss%20Design%20Document%20v1.md), [콘티](../references/AirBoss_Storyboard_v01.png)를 따른다.
- 오른쪽 이동을 기준으로 16장, 4×4 시트. 왼쪽은 향후 좌우 반전해 재사용한다.
- 00~03: Idle에서 진입. 00은 현재 Idle 마스터 원본 픽셀을 그대로 보존한다.
- 04~11: 오른쪽으로 기울어진 이동 유지 구간. 이 구간만 반복할 수 있도록 11→04를 연결한다. 반복마다 정면 직립으로 돌아오지 않는다.
- 12~15: 감속·복귀. 몸을 먼저 세우고 팔·천은 뒤늦게 정리한다. 15 다음은 Idle로 이어진다.
- 00~15 전체를 하나의 이동 루프로 반복하는 규격이 아니다. 4장/8장/4장 배분은 이번 제작안이며 실제 재생 속도와 함께 후속 검토한다.

## 그림과 규격

1024×1024 셀, 4096×4096 RGBA, Center (512,512), PPU 24, 사방 64px 완전 투명 여백. 현재 마스터의 체격을 유지하며 전체 이미지를 기계적으로 회전하거나 좌우 이동시키는 것만으로 동작을 대신하지 않는다. 세계 좌표의 실제 이동은 그림에 넣지 않는다.

이동 반대 방향인 화면 왼쪽으로 망토와 천을 흘린다. 몸통·어깨·머리의 기울기, 팔·손목의 관성, 천의 후행을 구분한다. 이동 중에는 몸의 기울기를 유지하며 천과 손목만 작은 주기로 변한다. 감속에는 본체보다 늦은 천의 복귀를 넣는다.

일반 Move는 시전 동작이 아니므로 공격 구체·큰 휘두름 잔상을 새로 넣지 않는다. 기존 손목·가면의 발광은 유지한다. 필요 시 움직임에 딸린 작은 잔광은 애니메이션 전용 표현으로 취급하며 독립 공격 판정과 연결하지 않는다.

새 시트 경로는 `Assets/04.Sprites/AirBoss/AirBoss_Move_Bank_4x4_1024_v01.png`다. 원본 생성 결과와 개별 셀은 이 폴더 아래 source·frames에 보관한다. Unity 임포트는 Multiple 16개, Max Size 4096, Mipmap Off, Uncompressed, Bilinear, Clamp, Full Rect를 검토용으로 사용한다.

클립·Animator·씬·기존 Idle 자산은 이번 제작에서 변경하지 않는다. 정적 그림·파일 규격·분할 확인과 이동 루프의 최종 자연스러움·실제 게임 화면 검증을 구분한다.

후속 사용자 요청으로 직접 만든 Move_Bank 클립의 노출 시간을 조정했다. 16장 순서·Loop Off를 유지하며 총 1.6초다. [최신 클립 타이밍](../../../Docs/Boss/AirBoss/AirBoss_Move_Bank_timing_v01.md)을 따른다. 아래는 멀티스프라이트 제작 당시 기록이다.

16장 시트와 Unity Multiple 등록을 완료했다. 셀·시트 픽셀 일치, 사방 64px 투명 여백, PPU 24와 Center 분할을 확인했다. [제작·검증 기록](../../../Docs/Boss/AirBoss/AirBoss_Move_Bank_v01.md), [전체 비교](../../../Docs/Boss/AirBoss/AirBoss_Move_Bank_v01_contact_dark.png)를 따른다. 현재는 정적 스프라이트 검토 단계이며 클립과 실제 재생 검증은 진행하지 않았다.
