- [멀티 스프라이트 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [Idle 마스터 지침](../idle/Master%20Crafting%20Guide%20for%20Aerial%20Bosses%20%28Idle%29%20v1.md), [콘티](../references/AirBoss_Storyboard_v01.png)를 확인한다. 콘티의 손·천·응축광 흐름을 참고하되 ANIM-09를 다른 공격으로 바꾸지 않는다.
- [고정 마스터](../idle/AirBoss_Idle_Master_image2.png)를 모든 생성에 참조한다. 동일 픽셀 보존본과 SHA-256 일치. 마스터 100% 체격·좌표 유지, 과거 72% 축소 재적용 금지.

## 동작

캐릭터 오른팔(정면 화면 왼쪽)을 사용한다. 반대팔은 낮은 보조 자세다. 단팔 UpDown과 달리 손을 머리 위로 올리거나 아래로 내리치는 대신, 가슴 앞에서 화면 밖 관객 쪽으로 뻗는다. 짧아 보이는 전완과 가까운 손의 원근으로 깊이를 표현하고 가면은 가리지 않는다. 손의 투영 크기 변화는 원근에 따른 것이며 얼굴·몸통 배율을 바꾸지 않는다.

| 셀 | 역할 |
| --- | --- |
| 00 | Idle 마스터 원본 |
| 01~04 | 낮은 손을 몸 쪽으로 당김, 어깨·몸통 준비와 작은 응축광 |
| 05~06 | 전완이 관객 쪽으로 향하며 손바닥을 펼침 |
| 07~08 | 최대 뻗기·지정 시전, 손에 붙은 짧은 방출광 |
| 09~11 | 손의 후행·회수, 잔광 감쇠 |
| 12~15 | 팔과 몸통이 Idle로 복귀, 천의 잔여 흐름 정리 |

일반 캐스팅 12장은 초기 목표다. 이번에는 원근에 따른 손의 변화와 복귀 연결을 위해 16장의 서로 다른 셀로 제작한다. 기획서 1.2초 준비 / 0.5초 뻗기 / 1.5초 회복은 연결 의도이며 타임라인이나 클립을 생성하지 않는다.

## 출력·검사

- 1024×1024 RGBA 셀 16장, 4×4·4096×4096 시트, PPU 24, 셀 Center (512,512).
- 모든 alpha>0에 사방 64px 안전 여백. 손·천·발광을 잘라 맞추거나 개별 체격 축소·Trim·재중앙정렬하지 않는다.
- 00은 마스터 파일 그대로. 나머지는 개별 새 그림이며 역순·좌우 반전·전신 반투명 중첩으로 중간 동작을 대신하지 않는다.
- 손에 붙은 응축광·짧은 잔광은 Body에 포함한다. 독립 투사체·지면 가시·빨간 가이드·피해 영역은 포함하지 않는다.
- 생성 요청과 실제 출력 크기는 별도로 기록한다. 조립 전 전체 캔버스 정규화와 좌표·체격 확인, 조립 후 셀 재추출 픽셀 일치 검사.
