## 참조와 방향

[기획서 ANIM-07](../Aerial%20Boss%20Design%20Document%20v1.md), [공통 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [마스터 지침](../idle/Master%20Crafting%20Guide%20for%20Aerial%20Bosses%20%28Idle%29%20v1.md)을 따른다. [마스터](../idle/AirBoss_Idle_Master_image2.png)와 [콘티](../references/AirBoss_Storyboard_v01.png)를 실제 이미지로 확인한다. 콘티 Rotate의 화면 평면 회전 예시는 최신 세로축 지시로 대체한다.

이번 제작 방향은 정면에서 먼저 화면 오른쪽을 보고, 후면·반대쪽 측면을 거쳐 정면으로 돌아오는 순서다. 사용자 확정 사항은 세로축이며 회전 방향은 제작 선택이다. 측면과 후면을 먼저 내부 검토하고 연결 그림을 만든다. 이를 사용자 최종 아트 승인으로 표시하지 않는다.

## 포즈 계획

| 셀 | 목표 방향과 역할 |
| --- | --- |
| 00 | 고정 Idle 마스터 원본 |
| 01~02 | 팔을 몸 쪽으로 모으고 작게 반대 방향으로 비트는 준비 |
| 03 | 약 30도, 화면 오른쪽으로 회전 시작 |
| 04 | 약 60도, 측면으로 접근 |
| 05 | 약 90도, 화면 오른쪽을 보는 측면 |
| 06~07 | 약 120·150도, 뒤쪽으로 넘어감 |
| 08 | 약 180도, 후면 |
| 09~10 | 약 210·240도, 반대쪽 측면으로 진행 |
| 11 | 약 270도, 화면 왼쪽을 보는 측면 |
| 12~13 | 약 300·330도, 정면으로 복귀 |
| 14~15 | 한 바퀴 회전을 마치고 손·천의 관성을 정리하며 Idle로 연결 |

각도는 포즈 제작 목표다. 3D 모델로 실측한 각도나 엔진 Transform 값이 아니다. 3.6초 기획은 후속 클립 참고이며 이번에는 타임라인·재생 파일을 만들지 않는다.

## 디자인 연속성

- 몸은 세워 두고 마스터와 같은 중심·높이·체격을 유지한다. 옆면의 원근 단축을 실제 신체 축소로 보정하지 않는다.
- 후면은 기존 목 갑옷 고리와 분절 판의 연속 구조를 사용한다. 뒤통수·등에 정면 가면, 눈, 가슴 구조를 복제하지 않는다. 새 문양·뿔·보석·다리를 만들지 않는다.
- 정면에서 화면 왼쪽에 보이는 높은 천의 부착점은 캐릭터 오른쪽 어깨다. 회전하면서 보이는 위치와 가림 관계가 바뀌며, 반대편 천으로 복제하지 않는다.
- 양쪽 측면은 별도로 그린다. 얼굴·가슴·손과 천의 부착점이 몸 회전에 맞게 앞뒤로 가려져야 한다. 천 끝은 본체보다 늦게 따라와 감속 뒤에도 흐름이 남는다.
- 시전의 짧은 푸른 회전 잔광은 같은 Body PNG에 포함한다. 효과로 자세를 가리거나 독립 공격·전신 잔상 분신을 추가하지 않는다.

## 출력과 검수

- 셀 1024×1024 RGBA 16장, 4×4·4096×4096, PPU 24, Center (512,512). 00은 고정 마스터 파일 그대로.
- 원본 PNG를 회전·반전한 복제본으로 양산하지 않는다. 실루엣 fit·Trim·재중앙 정렬·프레임별 크기 보정 금지.
- 생성 요청 크기와 실제 출력 크기를 구분한다. 전체 캔버스 정규화 뒤 마스터 체격·좌표를 확인하고 검수한 셀을 정수 좌표로 복사해 조립한다.
- 모든 alpha>0에 사방 64px 안전 여백. 천·빛을 잘라내거나 본체를 줄여 맞추지 않는다. 분리된 희미한 잡점 정리는 기존 검수 조건과 수량을 기록한다.
- 밝은·어두운 바탕의 전체 프레임 및 주요 방향을 정적으로 비교한다. 조립 후 셀 재추출 픽셀 일치와 Unity Multiple 16개·Rect·PPU·피벗·실제 해상도를 확인한다.
