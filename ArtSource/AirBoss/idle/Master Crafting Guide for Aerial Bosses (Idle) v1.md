# 공중 보스 Idle 기준 마스터 제작·보존 지침 v1.1

갱신일: 2026-09-30. 파일명은 기존 링크를 보존하기 위해 유지합니다. 현재 1024×1024 마스터를 후속 제작 기준으로 지정했으며, **멀티스프라이트의 상세 제작 규칙은 [AirBoss_Multisprite_Production_Rules_v1.md](../AirBoss_Multisprite_Production_Rules_v1.md)**를 따릅니다.

## 1. 목적

이 문서는 **공중 보스의 모든 멀티 스프라이트 애니메이션 제작의 기준이 되는 Idle 마스터 1장**의 디자인·배치·보존 지침입니다. 현재 기준 파일은 [AirBoss_Idle_Master_image2.png](AirBoss_Idle_Master_image2.png), 같은 내용의 고정 버전은 [AirBoss_Idle_Master_image2_v02.png](AirBoss_Idle_Master_image2_v02.png)입니다.

이 단계의 목표는 **애니메이션 시트를 만드는 것**이 아니라,

앞으로 제작할

- Idle 8장
- Move 16장
- 일반 캐스팅 12장
- 핵심 공격 / 회전 / 사망 16장

모든 동작에 공통으로 적용할 **체격 / 배치 / 여백 / 피벗 기준**을 관리하는 것입니다. Idle 8장은 1차 제작 규격이며 나머지 장수는 후속 제작 목표입니다. 후속 사용자 요청으로 [Idle v01 시트와 Unity 8분할](../../../Docs/Boss/AirBoss/AirBoss_Idle_Float_v01.md)을 제작했으며 전체 정적 검토 대기입니다. 마스터 자체는 변경하지 않았고 애니메이션 클립은 만들지 않았습니다.

---

## 2. 기준 원칙

### 2-1. 디자인 기준

- **공중 보스 디자인은 현재 확정된 디자인으로 Lock**
- **Idle 기준은 2번째 정면 이미지의 현재 1024×1024 마스터**
- 현재 마스터를 **100% 배율**로 사용. 1254 원본에서 적용한 과거 72% 축소는 재적용하지 않음
- 얼굴, 가면, 푸른 발광 틈, 분절 갑옷, 손 형상, 긴 서리 천/망토의 핵심 특징을 유지
- **새로운 디자인 해석, 비율 변경, 장식 추가/삭제 금지**
- 보스의 분위기는**어둡고 신비롭고 위협적인 공중형 존재**로 유지

### 2-2. 이 단계에서 하는 일

- 1024×1024 셀 안의 **기존 Idle 기준 자세 1장**을 보존
- 후속 애니메이션에 사용할 **현재 기준 위치와 크기**를 기록
- 현재 Idle의 여백과 **아직 확인하지 않은 최대 포즈의 여백**을 구분

### 2-3. 이 단계에서 하지 않는 일

- **PPU 24는 확정**했으며 실제 월드 배치·Transform Scale·카메라 크기는 이 단계에서 확정하지 않음
- 아직 **애니메이션 시트 제작 아님**
- 아직 **이동/회전/공격 포즈 양산 아님**
- 코드용 부유 이동은 고려하되, **이미지 자체를 크게 위아래로 흔들지 않음**

## 3. 캔버스 / 제작 규격

| 항목 | 값 |
| --- | --- |
| 캔버스 크기 | **1024 × 1024 px** |
| 배경 | **투명 배경** |
| 출력 형식 | **8bit/channel RGBA PNG** |
| 피벗 기준 | **Center** |
| 피벗 좌표 | **(512, 512)** |
| 배치 기준 | 셀 왼쪽 아래를 `(0, 0)`으로 보는 제작 좌표계 |
| 자동 Trim | **금지** |
| 프레임 외곽 기준 자동 중앙정렬 | **금지** |

현재 파일의 SHA-256은 `B67EBB82308AB8FA7D8A5C74C10F59FD7761E7335303AEF3ACF6C2F22587D722`입니다. 피벗은 제작·임포트 기준이며 PNG에 Unity Pivot 설정이 내장된 것은 아닙니다. 마스터 제작 당시 Unity Import는 변경하지 않았습니다. 이후 사용자 지시로 AirBoss 공통 임포트 기준을 PPU 24로 확정했습니다. PNG 해상도와 마스터 100% 배율은 유지합니다.

## 4. 배치 원칙

## 4-1. 가장 중요한 목표

이 마스터는 **셀에 꽉 차는 그림**이 아니라,

**다른 포즈를 만들 때도 같은 체격으로 충분히 확장 가능한 기준 그림**이어야 합니다.

즉, Idle 한 장만 보기 좋게 크게 넣는 것이 목적이 아닙니다.

---

## 4-2. 여백 원칙

- 보스가 1024×1024 셀 안에 **너무 꽉 차지 않도록 배치**
- 향후 다음 포즈를 고려한 여백 필요:
    - 양팔 크게 들어 올리기
    - 정면 손 뻗기
    - 360도 회전 (화면 평면 내 회전은 공간 검토 후보이며 최종 회전축은 기획서의 미정 상태 유지)
    - 90도 대시 기울기
    - 사망 시 기울어진 자세
- **손끝 / 천끝 / 실루엣 외곽이 셀 경계에 닿지 않도록 배치**
- 매 프레임 사방 **최소 64px 안전 여백**을 검사. 0 기반 픽셀 인덱스에서 alpha>0은 X·Y 모두 64~959 안에 있어야 함
- 현재 Idle은 통과했지만 모든 최대 포즈의 통과를 의미하지 않음

---

## 4-3. 현재 Idle의 실제 크기

현재 1024 마스터를 직접 측정한 값은 다음과 같습니다. 자세가 달라질 때 외곽 높이를 이 값에 억지로 맞추지 않습니다.

- **가면 위부터 천 끝까지**: 시각적으로 약 **690px**
- **가면보다 높은 후면 천까지 포함한 주요 외곽**: **604×778px** (alpha≥8)
- **모든 alpha>0 픽셀의 여백**: 좌131 / 우88 / 상84 / 하113px
- 가로 폭은 원본 비율 유지
- 보스를 정사각형에 억지로 꽉 맞추지 않음
- 세로로 긴 실루엣 특성을 유지

> 이 수치는 현재 마스터의 측정값이며, 큰 포즈의 적합성은 후속 검토 대상입니다.
>
>
> 이후 최대 포즈 비교 시 공간이 부족하면 개별 포즈만 줄이지 말고,
>
> **공통 체격·규격을 재검토하고 새 버전으로 관리**합니다. 현재 마스터를 덮어쓰거나 특정 프레임만 축소하지 않습니다.

원본 좌표와 현재 마스터의 변환, alpha별 외곽, 검수 한계는 [마스터 v02 실측 기록](../../../Docs/Boss/AirBoss/AirBoss_Idle_Master_image2_v02.md)을 참고합니다.
>

## 5. 포즈 기준

## 5-1. 자세 방향

- **정면 기준 Idle**
- 공중에 부유한 상태
- 지나치게 딱딱한 직립이 아니라, **살짝 살아 있는 긴장감**이 있는 자세
- 몸통은 과하게 비틀지 않되, 완전히 기계적으로 정면 대칭인 느낌도 피함

## 5-2. 표현해야 하는 인상

- 위협적
- 정적이지만 살아 있음
- 공격 직전까지 갈 수 있는 긴장감
- 몸이 무겁다기보다, **공중에서 떠 있으면서도 존재감이 큰 타입**

## 5-3. Idle에서 허용되는 변화

Idle 기준 마스터 1장은 애니메이션이 아니므로,

아래 요소들을 “움직일 여지가 있는 형태”로 잡아 두면 됩니다.

- 몸통의 미세한 기울기 여지
- 팔과 손의 제스처 여지
- 망토 / 천이 후행할 수 있는 흐름
- 얼굴·가면 주변의 정면 인상 유지

---

## 6. 피벗 / 중심축 기준

## 6-1. Unity Pivot

- **Pivot = Center**
- **셀 기준 좌표 = (512, 512)**

## 6-2. 주의사항

- 피벗이 중앙이라는 뜻이지,**가슴이나 얼굴을 반드시 셀 정중앙에 맞추라는 뜻은 아님**
- 긴 망토/천이 아래로 내려오므로**몸통 중심과 셀 중심은 완전히 일치하지 않아도 됨**
- 다만, 앞으로의 애니메이션 전반에서 기준이 되어야 하므로**기준 마스터의 전체 배치는 이후 모든 프레임에서 일관되게 유지**

## 6-3. 정렬 원칙

- 프레임마다 외곽을 기준으로 새로 가운데 맞추지 않음
- 프레임마다 캐릭터 크기를 따로 키우거나 줄이지 않음
- 기준 마스터에서 정한 체격과 중심을 유지한 상태에서자세 변화만 생기도록 제작

Idle 00은 현재 마스터의 RGBA 픽셀을 그대로 사용합니다. 이후 셀의 전체 이동·배율 변화는 넣지 않고, 같은 캔버스 위에서 몸통·어깨·팔·손·천의 자세를 바꿉니다. 가슴과 가면을 셀 정중앙으로 다시 옮기지 않습니다.

---

## 7. 시각 요소별 유지 지침

## 7-1. 얼굴 / 가면

- 가면 형태는 현재 디자인 유지
- 흰 균열형 마스크 실루엣 유지
- 푸른 발광 눈 / 틈새 표현 유지
- 얼굴 인상은 공중 보스의 정체성을 가장 강하게 보여주는 부위이므로**단순화하더라도 특징 소실 금지**

## 7-2. 몸통 / 갑옷

- 어두운 분절 갑옷 구조 유지
- 몸통 실루엣이 너무 작아져서 읽히지 않지 않도록 주의
- 갑옷의 판 구조와 틈새 발광 느낌 유지

## 7-3. 팔 / 손

- 큰 발톱 손의 형상 유지
- 손은 이후 캐스팅과 손 뻗기 동작의 핵심이므로Idle에서도 **손이 읽히는 배치**가 좋음
- 너무 몸에 붙여서 실루엣이 묻히지 않도록 주의

## 7-4. 망토 / 서리 천

- 길고 흩날리는 후면 천/망토는 이 보스의 핵심 실루엣 요소
- 다만 Idle 기준 마스터에서 너무 넓게 퍼뜨려이후 포즈 공간을 잡아먹지 않도록 주의
- 천의 주요 덩어리 흐름은 살아 있어야 함
- 나중에 애니메이션에서 **후행 움직임을 줄 수 있는 구조**가 보이게 배치

## 8. Idle 기준 마스터 검수 항목

현재 마스터에서 확인한 항목과 후속 동작을 만들어야 확인할 수 있는 항목을 구분합니다. 아래 상태는 멀티스프라이트나 Unity 검증 완료를 뜻하지 않습니다.

### 8-1. 배치 검수

- [x]  1024×1024 투명 RGBA 파일이며 현재 Idle의 여백을 실제 측정했다
- [x]  현재 손끝과 천끝을 포함한 모든 alpha>0 픽셀에 최소 84px 여백이 있다
- [ ]  향후 큰 포즈를 같은 체격으로 만들어 64px 안전 여백을 검수했다
- [ ]  전 동작의 공통 체격·셀 적합성을 검수했다

### 8-2. 실루엣 검수

- [x]  정면 공중 보스의 기존 실루엣과 비대칭 천을 보존했다
- [x]  얼굴 / 가면 / 손 / 천을 재해석하지 않고 원본에서 등비 축소했다
- [ ]  실제 게임 화면 크기에서 디테일과 동작 가독성을 확인했다
- [ ]  이후 최대 포즈에서도 같은 체격과 여백이 성립한다

### 8-3. 제작 기준 검수

- [x]  제작 피벗을 셀 Center(512,512)로 기록했다
- [ ]  이후 Move / Cast / Spin / Death로 확장 가능하다
- [x]  기준 파일·배율·좌표를 고정하고 프레임별 자동 중앙정렬 금지를 명시했다

## 9. 다음 단계

사용자가 지정한 현재 마스터를 기준으로, 후속 제작은 다음 순서로 진행합니다. 현재 Idle v01은 정적 시트·Unity 분할 검토본까지 준비했으며, 사용자의 전체 스프라이트 검토 후 다음 범위를 진행합니다.

1. **Idle 8장 제작**
    - 00은 마스터 그대로, 01~07은 다른 자세·후행 상태
    - 4×2
    - 4096×2048
    - 초기 3초 루프, 각 0.375초. 8장과 8fps를 혼동하지 않음
    - 07→00→01 연결, 전신 움직임, 64px 여백 검수 후 시트 조립
2. **Unity 임포트 테스트**
    - Slice: 1024×1024
    - Pivot: Center
    - Max Size: 4096
    - 실제 씬에서 크기 확인
3. **PPU 24 기준 실제 표시 크기 검토**
    - 모든 AirBoss 시트의 Unity Pixels Per Unit을 **24**로 설정하고, 게임 화면에서 Transform Scale·카메라·플레이어 대비 크기를 검토
4. **Move 16장 제작**
    - 후속 목표. 같은 체격의 주요 포즈·최대 외곽 확인 후 진입 / 루프 / 이탈 구성

## 10. 제작자에게 전달할 수 있는 짧은 실무 지시문

아래 문장은 바로 넘겨도 되는 축약 지시문입니다.

> **현재 공중 보스 Idle 기준 마스터 1장을 보존하고 후속 제작의 기준으로 사용합니다.**
>
>
> 기준은 현재 1024×1024 AirBoss_Idle_Master_image2.png이며, 디자인과 현재 100% 배율을 유지합니다. 마스터를 다시 생성하거나 과거 72% 축소를 반복하지 않습니다.
>
> 캔버스는 **1024×1024 투명 PNG**, **Pivot 기준은 Center (512,512)** 입니다.
>
> 현재 배치와 여백을 유지하고, 향후 양팔 상승, 손 뻗기, 360도 회전, 대시, 사망 포즈는 같은 체격으로 공간을 별도 검토합니다.
>
> 손끝과 천끝을 포함한 외곽이 셀 경계에 붙지 않도록 하며, 최대 포즈를 고려해 **최소 64px 수준의 안전 여백 확보를 목표**로 합니다.
>
> 정면 공중 부유 자세의 위협적인 인상을 유지하고, 얼굴·가면·발광 틈·갑옷 구조·큰 손·긴 서리 천의 핵심 특징을 보존합니다.
>
> 자동 Trim, 프레임별 개별 크기 보정, 외곽 기준 자동 중앙정렬은 금지합니다.
>
> 이 이미지는 애니메이션 시트가 아니라 **향후 모든 애니메이션 제작의 공통 체격/배치 기준 마스터**입니다.
