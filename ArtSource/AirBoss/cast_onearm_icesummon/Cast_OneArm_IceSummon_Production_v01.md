# 단팔 상승 얼음 소환 v01 — 2026-10-04

사용자 요청: 보스가 아래에서 손을 올려 플레이어 위치에 얼음을 솟게 하는 패턴의 바디 멀티스프라이트 24장. 손 궤적은 바디에 포함한다. 독립 얼음 공격 VFX는 이번 제작 대상이 아니다.

## 기준과 출력

- [공통 제작 규칙](../AirBoss_Multisprite_Production_Rules_v1.md), [단팔 기존 기준](../cast_onearm_updown/Cast_OneArm_UpDown_Production_v01.md), Idle 마스터 및 콘티 실제 이미지 확인.
- 마스터와 고정 버전 SHA256 일치: b67ebb82308ab8fa7d8a5c74c10f59fd7761e7335303aef3acf6c2f22587d722.
- 화면 왼쪽 팔(캐릭터 오른팔)을 낮게 준비했다가 위로 퍼 올림. 푸른 궤적은 상승 방향 뒤에 남고 복귀에서 소멸.
- 00은 마스터의 RGBA 픽셀을 그대로 사용. 01~23은 built-in image_gen으로 개별 생성. 06·07·17·18은 연결 보완본 선택; 초기 생성본도 보존.
- 요청 생성 캔버스 1024×1024, 실제 생성 원본 1254×1254 RGBA. 전체 캔버스를 동일하게 1024×1024로 정규화했다. 개별 외곽 fit·Trim·재중앙정렬·역순 복제는 하지 않았다.
- **공통 캔버스 확장:** 일부 천 끝이 기존 1024 기준 64px 안전 띠 안에 들어오므로, 모든 프레임에 사방 64px 투명 패딩 추가. 최종 셀 1152×1152, 피봇 (576,576)/(0.5,0.5), PPU 24. 그림 배율·몸체 기준점과 기존 마스터의 피봇 대비 좌표는 유지. alpha 문턱 제거 및 손·천·효과 잘라내기 없음.
- Part1: 00~15, 4×4, 4608×4608. Part2: 16~23, 4×2, 4608×2304. Unity Max Size 8192는 재축소 방지 설정이며 네이티브 8K 그림이라는 뜻이 아니다.

## 재생 제안

00~05 준비, 06~09 상승 가속, 10~13 발동·정점, 14~16 잔광, 17~23 복귀. 24fps/1초와 12fps/2초는 아트 비교용이며 최종 게임 타이밍이 아니다. 얼음 생성 이벤트 후보는 10~12. 클립·Animator·씬·프리팹·게임 코드 변경 없음.
