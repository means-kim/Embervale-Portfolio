## 🎮 게임 소개

**Embervale(엠버베일)**은 어두운 설산을 배경으로, 불 속성의 주인공이 거대한 보스에 맞서는 **2D 횡스크롤 소울라이크 액션 게임**입니다.

플레이어는 설산을 탐험하며 이동과 공격을 익히고, 보스와의 1대1 전투에 도전합니다. 빠른 대시로 공격을 회피하고 반격의 기회를 찾아, 반복되는 도전 끝에 보스를 쓰러뜨리는 성취감을 핵심 경험으로 삼습니다.

차가운 눈과 얼음, 어두운 배경 위로 드러나는 붉은 불꽃의 대비를 통해 전투의 속도감과 시각적 타격감을 표현합니다.

## ✨ 핵심 플레이 경험

### ⚔️ 보스의 패턴을 읽고 돌파하는 전투

설산 거인과의 1대1 전투를 중심으로, 보스의 공격 패턴과 기믹을 파악하고 대응하는 재미를 지향합니다. 공격과 회피의 타이밍을 익히며, 처음에는 어려웠던 전투를 스스로 극복하도록 설계합니다.

### 💨 빠른 이동과 대시를 활용한 회피

이동, 점프, 근접 공격, 대시를 조합해 전투를 진행합니다. 보스의 공격을 피하는 긴장감과 회피 후 반격하는 속도감을 강조합니다.

### 🌱 실패가 다음 도전으로 이어지는 성장

보스 공략에 실패하더라도 다시 도전할 수 있도록 성장 요소를 기획하고 있습니다. 사망 시 최대 체력이 증가하는 구조를 통해 재도전의 부담을 낮추고, 패턴 학습과 함께 보스 클리어에 가까워지도록 합니다.

### 💥 불꽃과 타격감이 살아 있는 전투 연출

히트스탑, 피격 시 번쩍임, 타격 이펙트, 카메라 흔들림, 효과음을 활용해 공격의 무게감을 표현하는 것을 목표로 합니다. 불꽃과 조명 연출로 어두운 설산 속 플레이어의 움직임과 공격을 강조합니다.

## 🕹️ 조작법

> 기획서 기준의 키 배치입니다. 스킬과 상호작용은 추가 구현 목표에 해당합니다.

| 행동 | 조작 | 설명 |
| --- | --- | --- |
| 이동 | `W` `A` `S` `D` 또는 방향키 | 기본 방향 입력. `W` / `↑`는 점프에 사용 |
| 점프 | `W` 또는 `↑` | 위로 점프 |
| 기본 공격 | 마우스 왼쪽 버튼 | 근접 공격 |
| 대시 / 회피 | `Shift` | 짧은 거리를 빠르게 이동하며 회피 |
| 맵 확인 | `Tab` | 탐색한 지역을 지도에 표시 |
| 스킬 | `E` / `R` / `F` | 타입별 스킬 사용 · 추가 구현 목표 |
| 상호작용 | 마우스 휠 버튼 클릭 | UI를 통한 선택 · 추가 구현 목표 |

## 🔁 게임 진행 흐름

**게임 시작 → 설산 탐험 및 조작 습득 → 전투와 구역 이동 → 보스 방 진입 → 보스전 → 결과 확인**

보스를 쓰러뜨리면 클리어에 도달합니다. 실패하면 성장을 바탕으로 재도전하며, 이전 전투에서 익힌 패턴과 조작을 활용해 다시 보스에 맞섭니다.
