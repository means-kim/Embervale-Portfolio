## 🎮 게임 소개

**Embervale(엠버베일)**은 어두운 설산과 동굴을 배경으로, 불꽃을 다루는 주인공이 거대한 적에 맞서는 **2D 횡스크롤 소울라이크 액션 게임**입니다.

플레이어는 일반 몬스터와 지형 장애물을 지나 설산 거인과 공중 보스에 도전합니다. 2단 점프, 방향 대시, 벽 점프, 활공을 조합해 이동하고, 차지 점프로 얼음 투사체를 붙잡아 새로운 이동 기회를 만들 수 있습니다.

전투에서는 근접 콤보와 불꽃 공격을 활용해 적의 빈틈을 공략합니다. 보스의 공격 예고를 읽고, 페이즈에 따라 달라지는 패턴과 전장에 대응하며 승리를 향해 나아갑니다.

차가운 눈과 얼음, 어두운 암벽 위에 드러나는 붉은 불꽃의 대비로 이동의 속도감과 전투의 타격감을 표현합니다.

## ✨ 핵심 플레이 경험

### 💨 지상과 공중을 연결하는 이동

2단 점프와 방향 대시, 벽 붙잡기·벽 점프, 활공을 조합해 설산과 동굴을 이동합니다.

현재 기본 구성은 **2단 점프와 착지 전 최대 2회의 일반 공중 대시**입니다. 활공으로 낙하 속도를 줄이고, 차지 점프로 원하는 방향으로 빠르게 이동하며 공중에서도 다음 행동을 이어갈 수 있습니다.

차지 점프는 주변의 잡을 수 있는 얼음 투사체를 이용합니다. 조준 중 시간이 느려지고, 발사하면 플레이어는 조준 방향으로, 투사체는 반대 방향으로 날아갑니다. 투사체가 없는 경우에는 체력을 소모해 사용할 수 있습니다.

### ⚔️ 콤보와 체력 관리를 결합한 전투

기본 공격은 연속 입력으로 이어지는 **3단 근접 콤보**입니다. 별도의 횡베기와 화염구 공격을 함께 사용해 상황에 맞게 적을 공략합니다.

특수 공격에는 체력 소모가 있으며, 공격을 적중시키면 체력을 회복할 수 있습니다. 공중 공격의 마지막 타격에는 추가 피해와 회복 보너스가 적용되어, 회피와 반격을 연결하는 조작이 중요합니다.

### 👹 설산 거인에서 공중 보스까지

설산 거인은 돌진, 내려치기, 팔 휘두르기, 얼음 가시 공격으로 플레이어를 압박합니다.

이후 만나는 공중 보스는 **3개 페이즈**로 구성됩니다. 번개, 얼음 기둥, 고드름, 눈보라 등 다양한 공격을 사용하며, 체력 감소에 따라 공격 구성이 달라집니다.

공격 전에는 텔레그래프로 위험 범위를 알립니다. 지속적인 타격으로 그로기 게이지를 쌓으면 반격 기회를 만들 수 있으며, 후반 페이즈에서는 발판 배치와 전장 조건도 변화합니다.

### 🌱 선택한 강화가 다음 도전으로 이어지는 성장

사망 후 재도전할 때 다음 능력 중 하나를 선택해 강화합니다.

- **최대 체력**: 생존 여유 증가
- **공격력**: 공격 피해 증가
- **공격 속도**: 공격 동작 속도 증가

각 능력은 최대 5단계까지 강화할 수 있습니다. 강화 기록은 재도전과 이어하기에 유지되며, 숨겨진 구역에서도 추가 강화 기회를 얻을 수 있습니다.

체크포인트와 주요 적 처치 기록을 활용해 진행 상황을 이어가고, 패턴 학습과 능력 강화를 바탕으로 다시 도전합니다.

### 🏔️ 탐색과 지형 기믹

눈 덮인 외부 구역과 동굴 내부를 이동하며 일반 몬스터, 얼음 발사 장치, 발판과 낙하 위험을 만납니다.

공격으로 부술 수 있는 암반과 숨겨진 보상 구역이 배치되어 있으며, 이동 기술과 공격을 활용해 길을 찾습니다. 주요 전투 구역은 진입 연출과 장벽으로 구분됩니다.

### 💥 불꽃과 타격감이 살아 있는 연출

히트스탑, 피격 플래시, 타격 이펙트, 카메라 흔들림과 효과음으로 전투의 무게감을 표현합니다.

보스 조우와 페이즈 전환에는 전용 시네마틱을 사용하며, 공중 보스 처치 후에는 마무리 연출과 엔딩 영상이 이어집니다.

## 🕹️ 조작법

> 현재 게임 씬의 입력 연결 기준입니다.
> 활공 키와 입력 방식은 설정에서 변경할 수 있습니다.

| 행동 | 조작 | 설명 |
| --- | --- | --- |
| 좌우 이동 | `A` / `D` 또는 `←` / `→` | 지상·공중 이동 |
| 점프 / 2단 점프 | `Space` | 공중에서 추가 점프 |
| 벽 점프 | 벽에 붙은 상태에서 `Space` | 벽을 이용해 도약 |
| 기본 콤보 | 마우스 왼쪽 버튼 연속 입력 | 3단 근접 공격 |
| 횡베기 | `E` | 체력을 소모하는 별도 공격 |
| 화염구 | `R` | 체력을 소모해 전방으로 화염구 발사 |
| 방향 대시 | `W` `A` `S` `D` + `Shift` | 입력 방향으로 대시. 방향 입력이 없으면 바라보는 방향으로 이동 |
| 활공 | `F` | 기본 설정에서는 누를 때마다 시작·해제 |
| 차지 점프 | 마우스 오른쪽 버튼 누르기 → 조준 → 떼기 | 주변 얼음 투사체를 이용하거나 체력을 소모해 발사 |
| 차지 점프 취소 | 조준 중 `Q` | 조준 취소 |
| 발판 아래로 내려가기 | `S` 또는 `↓` | 내려갈 수 있는 발판에서 사용 |
| 일시정지 / 메뉴 | `Esc` | 게임 중 메뉴 열기 |

활공은 설정에서 `F` 또는 `Space`, **토글 또는 누르고 있기** 방식으로 선택할 수 있습니다. `Space`를 선택하면 공중 점프를 모두 사용한 뒤 활공 입력으로 동작합니다.

## 🔁 게임 진행 흐름

**타이틀 → 새 게임·난이도 선택 또는 이어하기 → 도입 연출 → 설산·동굴 탐색 → 설산 거인 전투 → 후속 구역 이동 → 3페이즈 공중 보스전 → 엔딩 → 타이틀**

탐색 중에는 체크포인트를 기록하고 숨겨진 강화 보상을 찾을 수 있습니다.

사망하면 **재도전 → 능력 강화 선택 → 체크포인트 복귀**로 이어집니다. 이미 획득한 강화와 주요 적 처치 기록을 유지하며 다음 도전을 준비합니다.

## ⚙️ 난이도와 편의 기능

- **쉬움 / 보통 / 어려움**: 플레이어 공격력, 받는 피해, 자동 회복과 일부 함정 공격 간격에 차등 적용
- **이어하기**: 저장된 진행 위치와 강화·주요 적 처치 기록 복원
- **일시정지 메뉴**: 게임 중 설정 및 메뉴 접근
- **사운드 설정**: 배경음악과 효과음 볼륨 개별 조절
- **언어 설정**: 한국어 / 영어 선택
- **활공 설정**: 사용 키와 토글·홀드 방식 선택

탐색부터 보스전과 엔딩까지 연결된 구성을 바탕으로, 플레이어의 이동과 공격이 자연스럽게 이어지도록 조작감을 다듬고 있습니다.

보스의 공격 예고와 실제 판정, 페이즈별 전장 변화, 난이도와 성장 속도를 조정하고, 전체 동선과 재도전·이어하기 흐름을 지속적으로 검증합니다.
