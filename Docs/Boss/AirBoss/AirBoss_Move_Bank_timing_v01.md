# Move_Bank 클립 타이밍 v01

2026-09-30. 사용자가 제작한 `Assets/05.Animation/AirBoss/AirBoss_Move_Bank.anim`의 자연스러운 동작을 위해 기존 클립을 수정해 달라고 요청했다. 앞선 멀티스프라이트 전용 제작 제한보다 이번 명시 요청을 우선한다.

- 기존: 00~15 순서, 모든 셀 1/12초, 총 약 1.333초, Loop Off.
- 변경: 동일한 16장과 순서, 총 1.6초, Loop Off 유지. 진입은 약 0.367초 동안 가속, 유지 구간은 약 0.767초, 감속·복귀는 약 0.467초로 배분했다.
- 각 프레임의 120분의 1초 단위 노출은 `14,12,10,8,12,11,11,12,12,11,11,12,10,12,15,19`다. Sample Rate 120은 시간 격자이며 120장의 그림을 뜻하지 않는다.
- 마지막 셀의 노출을 보장하기 위해 191/120초에 동일 Sprite 종료 유지 키를 추가했다. 고유 그림은 여전히 16장이다.
- 클립 GUID `6e52565f04f1ff24d95fbfb5a80aa4f9` 유지. 기존 Animator 사용자 변경 사항, Idle 클립, PNG와 Move 클립 meta의 해시가 변경되지 않았음을 확인했다.
- [수정 전 원본](AirBoss_Move_Bank_before_timing_v01.anim.txt), [타이밍 및 Unity 샘플링 검증](AirBoss_Move_Bank_timing_v01.json).

Unity Preview Scene의 AnimationClipPlayable로 각 노출 중간과 종료 직전 총 17개 시점을 검사하여 모두 기대한 Sprite가 표시됨을 확인했다. 직접 SampleAnimation 호출은 ObjectReference 곡선을 표시하지 않아 Playable 방식으로 검증했다. 실제 게임 화면에서의 시각적 자연스러움을 검증 완료로 표시하지 않는다. 그림 사이의 형태 차이는 타이밍만으로 제거되지 않는다.

이 클립은 진입·유지·복귀를 포함한 단발 동작이다. 전체를 반복하면 매번 몸을 세우게 되므로, 지속 이동 구현 시에는 04~11 유지 구간을 별도 반복 클립으로 구성하는 기존 규칙을 유지한다. 이번에는 추가 클립이나 Animator 전환을 만들지 않았다.
