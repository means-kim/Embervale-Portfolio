# AirBoss 멀티스프라이트 규칙 갱신 기록 v01

날짜: 2026-09-30.

## 요청과 결과

사용자는 현재 1024×1024 Idle 마스터를 기준으로, Idle 멀티스프라이트를 만들기 전에 제작 규칙을 정하고 문서를 최신화하도록 요청했다. 문서만 갱신했으며 프레임·시트 생성과 Unity 적용은 진행하지 않았다.

## 정리한 기준

- 현재 마스터를 100%로 사용하며 과거 72% 축소를 다시 적용하지 않는다.
- 1024×1024 RGBA 셀, 셀별 Center (512,512), 사방 64px 완전 투명 여백을 검사한다.
- Idle은 00~07의 8개 상태, 4열×2행, 4096×2048을 1차 제작 규격으로 사용한다.
- 00은 마스터 픽셀을 유지한다. 후속 포즈는 전신의 작은 자세 변화와 천의 후행으로 만들며 자동 정렬·개별 축소를 금지한다.
- 3초·프레임당 0.375초는 초기 재생안이다. 8장과 8fps를 구분하고 07→00→01의 흐름을 검수한다.
- 기존 Move 8장 후보와 이후 Move 16장 목표의 충돌을 정리했다. Idle 외 장수와 최대 포즈의 셀 적합성은 후속 검토 대상이다.
- 이 기록 작성 당시 PPU, 실제 게임 크기, Unity 재생과 최대 동작 검증은 미완료였다. 이후 2026-09-30 사용자 지시로 **PPU 24를 확정**했다. 실제 게임 크기·Unity 재생·최대 동작 검증은 별도로 유지한다.

## 확인

세 제작 문서의 상대 링크와 문서 간 규격을 대조했고 `git diff --check`가 통과했다. 현재 마스터와 v02 보존본의 SHA-256은 모두 `B67EBB82308AB8FA7D8A5C74C10F59FD7761E7335303AEF3ACF6C2F22587D722`로 유지된다. 이번 갱신에서 PNG, Unity Assets, 씬, 코드, Import 설정은 수정하지 않았다.

이미지 생성 도구나 새 이미지 프롬프트는 이번 문서 갱신에 사용하지 않았다. 후속 제작자가 사용할 공통 지시문은 제작 규칙 문서에 포함되어 있다.
