# AirBoss 본체 보간 업스케일 v01

2026-10-08 사용자 요청: AI 재묘사 없이 본체만 확대하며 디자인, 동작, 참조를 보존. 공격 이펙트는 후속 판단 대기.

## 적용
- 현재 클립이 사용하는 본체 시트 31개, 스프라이트 456개.
- Premultiplied-alpha Lanczos 1.5배 보간. 기존 디자인과 프레임 순서 유지. 새로운 세부 묘사를 생성하는 방식은 아니다.
- 1024 셀 →1536, 1152 셀 →1728. 시트 4096→6144, 4608→6912 (반높이 시트 포함).
- PPU24→36, Sprite rect와 border를 1.5배. GUID/localID/name/pivot 월드 위치와 월드 크기 유지. 씬 Transform Scale은 변경하지 않았다.
- 기본 최대 텍스처 크기8192, 비압축 유지. 텍스처 픽셀 수와 동일 포맷의 메모리 비용은 약2.25배 증가한다.
- 미사용 구버전 Idle 시트는 변경하지 않았다. 공격 동작의 본체 프레임은 포함하되 별도 AirBossAttack 이펙트는 변경하지 않았다.

## 검증
- Unity 실제 재임포트 후 31개 텍스처가 확대된 원본 해상도로 로드됨.
- 456개 Sprite의 GUID/localID/name, 월드 크기·피벗 일치.
- 본체 애니메이션 Sprite 키의 참조·순서·시간 전후 동일.
- 보호 파일439개(씬/프리팹/클립/컨트롤러/타임라인/공격 이펙트) SHA256 변경0개. 작업 전 존재했던 MainTestScene 사용자 변경도 그대로 유지.
- 확대 비교 이미지에서 형태 유지 확인. Comparison.png 왼쪽 기존/Bilinear 표시, 오른쪽 적용 후 동일 크기 표시.
- 전체 Play 모드 전투 및 Timeline 재생의 시각 검수는 별도 미실시. 기존 연결과 데이터 동일성 검증 결과와 구분한다.

## 보존 및 재실행 주의
Original에는 적용 전 PNG/meta, Prepared에는 적용 시트, Paths.txt에는 적용 경로가 있다. Apply.cs.txt는 완료 마커를 검사하는 당시 적용 이력이며 임의 재실행하지 않는다. 복원 시 Original의 PNG와 meta를 함께 원래 경로에 복사하고 Unity 재임포트한다.
