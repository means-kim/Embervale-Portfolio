# PlayerWall 경량화 v02

2026-10-06. 공용 이동 코드만 정리했다. HyunseoTest의 별도 구현과 씬·프리팹 배치는 수정하지 않았다.

- 런타임 파일 7개 → 5개, 총 688줄 → 550줄.
- PlayerJump 221줄 → 195줄. 추가했던 벽 점프 예산 플래그를 제거하고 기존 공중 상태를 재사용한다.
- PlayerInput 68줄 → 46줄. 임시 입력 필드와 단순 전달 메서드를 제거했다.
- PlayerWall에 스태미나와 효과 재생을 직접 통합했다. 효과 구독 객체/이벤트와 중복 잠금 타이머를 제거하고, 자신의 잠금만 해제한다.
- PlayerWallSensor는 현재 접촉과 옆면 Cast 판정을 담당하는 일반 C# 클래스로 유지한다.
- PlayerWallFeedback/PlayerWallStamina 및 PlayerWallRegression Editor 스크립트와 해당 meta는 제거했다. 추가 컴포넌트 연결이 필요 없다.

## 유지한 동작

벽에 붙으면 CurrentJumpCount를 0으로 회복한다. MaxJumpCount는 변경하지 않는다. 벽에서 떨어져도 회복한 횟수는 유지하며, 착지나 스태미나 회복으로 취급하지 않는다.

Ground/Platform 옆면 및 단방향 발판의 옆면을 탐색한다. 발판 윗면·아랫면·Trigger·충돌 무시 대상은 제외한다. 피격·사망·대시·다른 소유자의 이동 잠금 중에는 벽 이동을 중단한다.

스태미나 기본값은 100, 0.1초당 매달림 1/등반 2 소모, 벽 점프 비용 25다. 첫 벽 점프만 비용을 내는 기존 정책도 유지한다. 설정은 PlayerWall의 필드로 옮겼다. 현재 씬·프리팹에 이전 중첩 스태미나 설정이 저장되어 있지 않은 것을 확인했다.

## 확인 범위

사용자 요청에 따라 새 테스트 코드를 만들거나 동작 테스트를 실행하지 않았다. Unity 6000.3.22f1의 실제 프로젝트 소스/참조/define으로 런타임과 Editor 코드를 컴파일했고 오류 없이 완료했다.

[이전 v01의 검사 기록](PlayerWall_Refactor_v01/Regression.txt)은 과거 구현에 대한 결과이며 이번 경량화의 검증 결과가 아니다. 현재 동작 테스트는 사용자가 진행한다.
