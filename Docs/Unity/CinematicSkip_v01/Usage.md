# 시네마틱 ESC 홀드 스킵

2026-10-14. 기본 홀드 시간은 1.5초다. 연출 중 ESC를 누르면 화면 오른쪽 아래에 진행 표시가 나타나며, 누른 시간을 채우면 연출의 최종 상태를 적용한다. 놓으면 진행 표시와 누적 시간이 초기화된다.

## Inspector 설정

- 인게임 연출: `CinematicManager > 시네마틱 스킵 > Skip Hold Duration`.
- 시작 영상: `OutGameUI > Intro Skip Hold Duration`.
- 둘 다 기본 1.5초이며 최소 0.1초다. 새 필드는 기존 씬에서도 기본값으로 동작한다.
- `CinematicSkipUI`는 Play 중 자동 생성된다. 별도 씬 오브젝트나 프리팹 연결은 필요 없다. 화면 표시용 CanvasGroup과 그래픽은 입력을 가로채지 않는다.

시작 영상, 엘리트 등장, 보스 등장과 재입장, 2페이즈, 3페이즈의 Timeline/발판 전환, 엔딩 전체와 마지막 업적 영상에 적용된다. 엔딩을 스킵하면 타이틀로 돌아간다.

## 동작과 상태 유지

게임 시간과 별개인 `Time.unscaledDeltaTime`으로 측정한다. 시작 영상의 timeScale 0과 엔딩 슬로모션에도 동작한다. 현재 프로젝트의 기존 Input과 Input System ESC 입력을 모두 읽는다.

연출 시작 전에 이미 누르고 있던 ESC는 인정하지 않는다. 포커스를 잃거나 앱이 일시 중단되면 누적 시간을 초기화하고, 키를 놓은 뒤 다시 눌러야 한다. 연출 완료/취소/비활성화 시 표시도 정리된다. 활성 스킵 대상이 있는 동안 일시정지와 능력 UI의 ESC 취소를 막아 입력이 겹치지 않게 한다.

`Cancel()`의 되돌리기 동작은 유지한다. 새 `Skip()`은 `CinematicManager.Complete()`와 연출별 최종 상태를 사용한다. Timeline 끝으로 이동하는 방식에 의존하지 않는다.

| 연출 | 스킵 후 처리 |
|---|---|
| 시작 영상 | 로딩 완료를 기다린 뒤 게임 진입, 시작 이력 저장, 입력 복원 |
| 엘리트 등장 | 카메라 복원, Completed 전달, 전투 시작 |
| 보스 등장 | 자동 이동 목적지 X 적용, 보스 표시/활성화, BGM 적용, 전투 시작 |
| 보스 재입장 | 별도 Timeline 정지, 정상 완료와 전투 시작 |
| 2페이즈 | 달 가림/조명/BGM 적용, 보스 위치 복원, 페이즈 완료 |
| 3페이즈 | 보스 이동, 이전 발판 제거, 다음 발판 표시/충돌 복원, 페이즈 완료 |
| 엔딩 | 영상/입력 효과 정리, 시간/물리 주기 복원, 타이틀 이동 |

비활성 포효 효과는 Timeline 콜백에서 호출하지 않는다. 스킵하는 포효는 새 `StopImmediately()`로 링과 틴트/플래시를 즉시 정리한다. 기존 `Stop()`의 페이드 종료 동작은 유지한다.

## 검증

Unity 6000.3.22f1 에디터 컴파일과 Play 자동 검사 91건을 통과했다. 수정 후 새 런타임 오류는 없었다. [검증 코드](Verify.cs), [검증 결과](Verification.txt), [시작 영상 진행 표시](Intro_Hold.png)를 참고한다.

홀드 임계값/키 해제/포커스 복귀/연출 전부터 누른 키/단일 완료/비활성화, 실제 Input System에 주입한 ESC의 시작 영상·엔딩 스킵, 활성 포효 중 Skip의 효과 정리, AreaController의 전투 시작·이력·재입장, 2/3페이즈 전환, 3페이즈 발판과 충돌, 기존 Cancel과 자연 종료를 구분해 확인한다. 테스트는 저장된 MainTestScene과 타이틀 흐름을 기준으로 한다. 테스트 중 변경한 PlayerPrefs 9개는 원래 존재 여부와 값으로 복원한다.

씬/프리팹/PNG/애니메이션/프로젝트 설정은 저장 변경하지 않았다. HyunseoScene의 기존 3페이즈/엔딩 연결 누락은 별도 상태로 남아 있다. 빌드 실행과 전체 동선 완주는 이 검증에 포함하지 않는다.

검증 재실행은 Play 전 `SnapshotPrefs`, Play 중 `FullSuite`, Play 종료 후 `RestorePrefs` 순서다. 모든 호출은 Unity CLI `run_script`로 실행하고 `--entry CinematicSkipVerification.메서드명`을 지정한다. ESC 입력 테스트는 Unity 에디터와 Game 뷰의 포커스가 필요하다. 검증 코드는 로컬 프로젝트의 Pipeline 패키지에 있는 `editor_focus` 구현을 호출해 테스트 전에 포커스를 확보한다. 장면 전환과 입력은 Play 중 일시 변경하며 씬을 저장하지 않는다.
