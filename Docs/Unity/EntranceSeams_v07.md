# 입구·등반 경계 v07

현재 씬: Assets/MapReview/MapReview_v02.unity. 적용 전 백업: Assets/MapReview/Before_EntranceSeams_v07.unity.

[동일 카메라 전후 비교](EntranceSeams_v07.html)

- 외부 숲보다 뒤에 있던 동굴 배경을 연속된 불투명 내부 배경으로 교체. 입구 뒤부터 등반 상단까지 여유를 확보.
- 중복 잘린 배경·벽·천장 5개와 기존 상단 왼쪽 보충 배경은 비활성 보존.
- 입구 바위·눈의 오른쪽 끝, 입구 벽 왼쪽 끝, 상단 벽·천장 끝과 통로 배경 접합은 겹침 구간에서 알파 보간.
- 발판 표시 순서를 내부 배경 앞으로 조정. JoinGround 유지, ExitLower 제외 유지. 눈은 별도 소재 유지.
- 원본 PNG/임포트 설정 변경 없음. 이 씬의 ReviewArt 메시와 표시 순서만 수정.

검사: Unity 1600×900 고정 카메라 8위치에서 전후 렌더. 입구 전후·등반 중단·상단 점프 높이·상단 통로 확인. 전체 경로 이동/충돌 완주 검증은 아님. 입구 밖이 화면에 포함되는 위치에서는 외부 풍경이 남으며, 진입 시 화면 전체 외부를 끄는 v03 기능은 재적용하지 않음.

원본 텍스처를 확장 재사용하므로 상단/왼쪽 깊은 영역에 반복 질감이 남는다. 보스/낙하 구역 전체 접합 완료로 해석하지 않는다.

비아트 컴포넌트 21개 전후 동일 여부: true (이동·카메라·지형 판정 포함).
