# 동굴 양방향 가림 v08

사용자 명시 승인: 밖에서는 내부 검정, 진입하면 외부 검정, 복귀 시 원상태.

현재 씬: Assets/MapReview/MapReview_v02.unity. 백업: Assets/MapReview/Before_PortalMask_v08.unity.

[화면 7장](PortalMask_v08.html) · [상태 기록](PortalMask_v08_checks.txt)

ReviewPortalVisibility가 플레이어 X를 판별한다. 입구 X=34.5, 진입 >34.75, 이탈 <34.25, 중간은 이전 상태 유지. 인스펙터에서 입구 위치 조정 가능. 현재 좌우 연결에 맞춘 구현이므로 다른 방향의 출입구에 자동 적용되는 범용 룸 시스템은 아니다.

별도 PortalMask 셰이더와 렌더러별 PropertyBlock 사용. 공유 원본 셰이더/PNG는 변경하지 않음. 입구 이미지에 합쳐진 내부 벽은 UV 다각형으로 검정 처리. 입구 바위·눈·고드름·Ground 계열 연결 바닥은 유지. 플레이어, 물리 판정, 이동 코드는 변경하지 않음.

검증: 외부→내부→외부 연속 위치의 상태 기록 및 1600×900 렌더 확인. Play 모드 Point2→Point1 전환 시 배경 교체 확인, 콘솔 오류 0. 직접 걸어서 전체 경로 완주 검증은 아님. 기존 비아트/물리/카메라 컴포넌트 44개 비교, 변경 0개.

현재 가림은 즉시 전환이며 페이드 연출은 추가하지 않음. 원본 입구 이미지를 교체하면 UV 가림 윤곽도 다시 맞춰야 함.
