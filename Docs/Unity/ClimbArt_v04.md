# 등반 발판·우측 암벽 보완 v04

현재 씬: Assets/MapReview/MapReview_v02.unity. 사용자 요청에 따라 발판 아트와 동굴 오른쪽 빈 공간을 수정했다.

- 등반 착지 발판 8개를 얇은 윗면의 측면 아트로 교체했다. 기존 EdgeCollider2D 끝점과 높이를 기준으로 배치했다. 좁은 발판과 넓은 쉼턱의 폭·위치는 유지했다.
- 신규 BG_Climb_LedgeSide_v02.png: 1536×1024 RGBA, PPU 100. 컨셉과 기존 중간 발판을 이미지 참조로 생성. 투명 여백을 제외한 UV 영역을 사용한다. 원본 PNG의 불투명 경계는 대략 x49..1489, y402..768이다. 별도 눈 소재는 포함하지 않는다.
- 우측에 기존 내부 후면 암벽과 ExitLower 소재로 암벽 두 겹을 추가했다. 왼쪽·상단 가장자리를 투명도로 연결하고 상단 통로 아래에서 끝낸다. 새 암벽은 장식이며 새 충돌벽을 추가한 것은 아니다.
- 변경 전 씬은 Before_ClimbArt_v04.unity에 보관했다. 기존 발판 아트 7개 오브젝트(총 8개 발판)는 삭제하지 않고 비활성 상태로 보존했다. BG_Climb_JoinGround_v01과 시작/등반 기존 렌더 순서를 유지한다. 동굴 v03 가림은 재적용하지 않았다.

## 확인

16:9 실제 Unity 카메라로 하단 발판, 넓은 쉼턱, 우측 암벽, 상단 통로의 전후 4쌍을 렌더했다. 하단/쉼턱 캡처는 캐릭터를 기존 충돌선 위에 놓은 시각 검사다. 우측 암벽 캡처는 공중 위치에서 촬영한 것으로 착지 장면이 아니다. 전체 이동·점프 검증은 이번 검사에 포함하지 않는다. 상단 통로와 기존 배경 일부에는 직선 접합 흔적이 남아 있다.

아트를 나중에 이동하면 해당 Gameplay 콜라이더도 함께 이동해야 한다. 시작 바닥과 입구 연결 바닥은 이번 발판 교체 대상에서 제외했다.
