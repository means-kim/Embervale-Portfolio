# 상단 빈 공간과 보스 오른쪽 경계 보완

최신 씬은 [MapReview_v02.unity](../../Assets/MapReview/MapReview_v02.unity)다. v01은 보존했다. v02를 단독으로 열고 16:9에서 확인한다. 기존 검토 메뉴도 v02를 연다.

## 변경

- 시작맵: 달이 포함되지 않은 기존 상부 하늘을 후방에 추가. 월드 X -4~44, Y 22~67까지 이어서 기존 배경 위쪽을 채운다. 기존 달과 시작 배경의 크기는 유지한다.
- 등반맵: 실내 후면 암벽을 X 24~94, Y 28~90에 추가. 왼쪽 위에서 배경이 끝나던 범위를 덮고 하늘을 노출하지 않는다.
- 보스전맵1: 컨셉 오른쪽 암벽 구도를 참고하여 기존 암벽을 반전 배치. 암벽 X 236~264, Y 18~102. 별도 비트리거 BoxCollider2D의 경계는 X 243~265, Y 16~102다. 기존 지면보다 아래까지 내려가고 오른쪽 지면 기준 5회 점프 상승량 12.6 유닛보다 충분히 높다.

새 배치는 Hierarchy의 `Boundary repair v02` 아래에 모았다. 그림과 충돌체는 독립되어 있으므로 벽을 옮기면 둘을 함께 조정한다. 원본 PNG 수정이나 신규 이미지 생성은 없고 기존 소재를 재사용했다.

## 검증 상태

씬 내부 ID 중복, 추가 그룹의 부모 연결, 메시·텍스처 참조와 수치상 배경/충돌 범위를 확인했다. [수치 검사](Boundary_v02_StaticValidation.json).

실제 Unity 렌더와 충돌 검증은 아직 완료하지 못했다. 작업 도중 Unity 창이 사라졌으며 별도 실행에서는 다른 인스턴스가 프로젝트를 열고 있다는 오류가 발생했다. 프로세스를 강제 종료하거나 잠금을 삭제하지 않았다. 기존 v01의 캡처와 5.02초 낙하 기록은 이번 수정의 검증 결과가 아니다.

Unity가 다시 사용 가능하면 Tools → Map Review → Capture boundary repair로 시작 5회 점프 높이, 등반 왼쪽 위, 보스 오른쪽 지면/점프 높이를 캡처한다. 같은 메뉴는 캐릭터 크기 캡슐을 오른쪽으로 투사하여 네 높이에서 암벽 충돌체를 만나는지 검사하고 Boundary_v02_Validation.txt를 기록한다. 이 투사 검사는 실제 플레이 완주를 대체하지 않는다. 배경 이음 색감과 암벽 윤곽에 맞는 충돌 위치도 실제 화면에서 추가 확인해야 한다.


## Unity 연결 후 실제 확인 (2026-09-23)

v02를 Unity 6000.3.22f1에서 단독으로 열었다. 경계 캡처 4장을 직접 확인했고 시작 점프 높이·등반 좌상단·보스 우측 지면과 점프 높이에서 빈 화면이 없었다. 캐릭터 크기 0.7×1.68 캡슐의 우측 투사 검사에서 Y 38.6 / 44 / 51.2 / 70 모두 충돌체를 만났다. [검사 기록](Boundary_v02_Validation.txt), [실제 화면](Boundary_v02.html). 이전 접근 불가 상태는 해소되었다. 전체 이동 완주 및 실제 입력으로 벽을 넘으려는 Play 검증은 별도다. 등반 상단의 기존 암벽과 확장 배경 사이 직선 접합은 시각 보완 항목으로 남아 있다.
