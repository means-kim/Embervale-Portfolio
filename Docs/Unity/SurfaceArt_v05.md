# 다른 구역의 발판·착지면 v05

현재 MapReview_v02.unity에 적용. 변경 전은 Before_SurfaceArt_v05.unity로 보존.

- 보스 독립 발판 3개는 승인한 BG_Climb_LedgeSide_v02를 재사용해 기존 충돌선 위에 정렬. 기존 2개 아트 오브젝트(3개 발판 표현)는 비활성 보존.
- 입구·JoinGround·상단 연결·보스 경사·낙하 착지·중앙 파괴 바닥과 별도 눈의 12개 아트 묶음은 원본 PNG를 유지하고 렌더 메시의 상부를 수정. 얇은 윗면으로 투시 깊이를 줄이며 하단은 보존.
- 시작 바닥과 눈 2개 묶음은 비교 후 원래 형태를 유지했다. SurfaceArtGeometry_v05.json의 총 17묶음은 수정 12 + 시작 유지 2 + 보스 발판 3이다.
- 중앙 정상·균열 아트 모두 보정. 파괴 상태 오브젝트·전환 참조와 분리된 눈은 유지했다. 이번에 파괴 동작을 다시 재생한 것은 아니다.
- 충돌 컴포넌트와 ReviewTerrain 직렬화 블록 41개를 백업 씬과 비교해 차이 0개. 지형 경사·발판 폭·간격·점프 사양은 유지.
- Unity 16:9 카메라 9곳 전후 캡처 확인. 캐릭터를 충돌선 위에 놓은 시각 검사이며 실제 이동 완주와 동적 착지 검증은 별도. 일부 배경 이음새 및 파괴 바닥 측면 경계는 남아 있다.
