# 동굴 내부 전환 v03

최신 씬: Assets/MapReview/MapReview_v03.unity. 열린 v02의 미저장 배치를 포함하여 새 이름으로 저장했고 v02 파일은 보존했다.

StartFar·숲 중경·성·안개·추가 하늘 6개 아트는 X33~39에서 점차 숨기고, 내부 후면/검은 좌우 가림/우측 암벽을 표시한다. X74~82 출구와 외부 복귀 시 역으로 복원한다. 검은 가림 가장자리는 2유닛 전이, 입구 기존 소재 끝은 X39.2~41.4815에서 부드럽게 연결했다. 원본 PNG 및 기존 geometry 대신 v03 geometry 복사본을 사용한다.

Unity에서 7개 위치 카메라 렌더를 비교했다. 외부 복귀 렌더는 진입 전과 동일한 해시였다. 실제 이동 입력으로 전체 경로 완주한 검증은 아니다. 충돌과 이동 수치는 수정하지 않았다. 세부 바닥 및 상단 소재 접합은 기존 시각 보완 대상으로 유지한다.

[화면](Cave_v03.html) · [렌더 기록](Cave_v03_Validation.txt). 재캡처: Tools → Map Review → Capture cave interior. 기본 검토 메뉴가 과거 씬을 열 수 있으므로 v03 씬을 직접 연다.
