## 구역 경계 해결안 — 아직 적용 전

사용자 캡처와 Unity에서 외부 숲 노출, 후면 암벽 사각 끝, 천장·바닥 재질 접합이 함께 드러나는 것을 확인했다.

1. 경계를 가로지르는 내부 후면 암벽을 이어서 외부 배경을 완전히 가린다. 내부 암벽은 불투명하게 유지하고 외부 숲보다 앞, 캐릭터·플레이 지형보다 뒤에 둔다.
2. 후면 배경 끝은 불규칙한 동굴 입구 테두리와 천장 바위 뒤에 숨긴다. 사각 절단면이 플레이 공간에 노출되지 않도록 이미지 끝과 구역 경계를 분산한다.
3. 기존 JoinGround를 연결 바닥으로 유지하면서 윗면 높이·바위 크기·명암을 양쪽과 맞춘다. 눈은 입구 안쪽으로 얇아지도록 별도 연결한다.
4. 좌우 접근, 되돌아오기, 점프 중 위쪽 노출을 이동하는 16:9 카메라로 점검한다. 경계용 가림 아트는 플레이 지형과 같은 속도로 움직이게 두고 패럴랙스 배경과 구분한다.

이전 롤백한 v03 전체 가림 처리의 재적용은 하지 않았다. 이번에는 해결안 설명까지만 진행했다.
