## 원본 재확인과 정정

사용자 정정: 통로를 지난 첫 보스전은 외부. [원본 컨셉](../../Assets/04.Sprites/Bg_Concept.png)을 다시 열어 오른쪽 위의 달·설산·부서진 석주·눈 덮인 바닥을 확인했다. 아래쪽 동굴 보스전과 구분한다. 실내 등반 규칙을 첫 보스전까지 확장한 v01 해석은 잘못이었다.

실내 통로는 유지하고 보스전 뒤벽을 외부 원경으로 교체했다. 전투 구역까지 이어지던 추가 천장은 제외. 기존 v01 파일은 이력으로 보존한다. AGENTS.md에 사용자 정정을 추가했다.

## 합성 배치

HTML 단위이며 Unity 월드 단위 확정값이 아니다. 모든 콘텐츠의 전체 개요 Y오프셋은300. 실제 카메라는 폭1000,높이562.5,콘텐츠 로컬Y0,캐릭터77.14286의 기존 설정 유지. 실제 보이는 캐릭터 높이 약9%.

- 외부 원경 x1700,y-40,width2250,brightness0.72.
- 기존 통로 뒤벽 x900,y-100,width1600,brightness0.65. 마지막10% 임시 가장자리 마스크.
- 통로 마지막 천장 우단x2500. 추가 실내 천장(x2100,y-330)은 제외.
- 석주 x2850,y10,width280,brightness0.75. 배경 장식이며 충돌 없음.
- 바닥 x2100,y224.2965,width1900,brightness0.85 유지.
- 눈 x2380,y250.3370,width1620,brightness0.8. 첫6% 임시 마스크로 동굴 입구부터 점차 드러남.
- 외부 구역 후보 x2500..3950,폭1450(카메라1.45배). 통로 밖 공간만 다시 산정했으며 실제 전투 면적 확정이 아니다.

## 확인과 남은 한계

출구·중앙·오른쪽의16:9 화면을 실제 브라우저에서 확인했다. 출구는 실내 암벽에서 설산으로 전환되고, 중앙/오른쪽은 하늘이 보인다. 이미지 로드 누락 없음. [출구](BossArena_Connection_v02_Entry.png), [중앙](BossArena_Connection_v02_Center.png), [오른쪽](BossArena_Connection_v02_Right.png).

원본은 통로에서 전투장까지 이어지는 전체 맵 컨셉이므로, 세부 산 형태와 폐허 배열은 동일 복제가 아닌 참고 재구성이다. 원본 가장자리의 고드름/암벽 테두리까지 구현한 최종본은 아니다. 오른쪽 후속 낙하 통로는 이번 범위 밖이다.

뒤벽과 눈 시작점에 HTML 마스크가 남아 있으며 Unity용 투명 출구 접합 소재 제작 완료를 뜻하지 않는다. PNG 자체 가장자리·확대·패럴랙스는 실제 Unity에서 추가 검토 필요. 보스 크기/패턴, 충돌, 이동, 전투 기능은 미구현. 눈 제거는 나중에 발 접촉 범위에 맞춰 촘촘하게 구현할 요구를 유지하며 긴 스프라이트 단위 통삭제로 확정하지 않는다.
