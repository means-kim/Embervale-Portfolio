## 마감 범위

사용자가 등반맵의 나머지 작업을 자율 진행해 마무리하도록 요청했다. 현재 권한 범위인 아트 시안·소재 정리·Unity 조립 인계를 마감한다. 게임 플레이 완성이나 자동 사용자 승인을 의미하지 않는다. 이번 마감에서는 추가 PNG 생성 없이 분리벽 v05의 구도를 유지했다. 별도 소품을 더 넣을 필요가 있는 결함은 이번 정지 화면 검토에서 찾지 못했다.

- 실내 후면, 입출구 분리벽3종, 발판3종, 천장, 시작맵 연결바닥: 총9종의 PNG+.meta를 통합했다.
- 입구/첫 등반/중간 쉼턱/상단 등반/출구를 각각 실제16:9 화면으로 확인하고 캡처했다.
- 입구와 출구의 임시벽 clip-path 제거 상태 유지. 새 암벽 기둥과 눈 끝을 재도입하지 않았다.
- 넓은 발판 반복 대신 좁음/중간/넓음 유지.9개 발판 각각 조절 가능.
- 배치 저장 내용을 발판뿐 아니라 벽·배경·천장·카메라 기준이 들어 있는 전체 조립 데이터로 보강했다. 다운로드 파일 수신 동작 자체는 별도 검증하지 않았다.
- 상단 출구의 다음 통로 접합 기준을 기록했다. 다음 구역을 임의 제작하지 않았다.

컨셉의 차가운 바위 질감은 기준으로 유지하되 등반 전체를 실내로 바꾼 사용자 지시가 우선한다. 컨셉과 동일한 맵 복제는 아니다. 일부 발판은 독립된 떠 있는 형태로 보인다. 실제 벽 부착형/독립형 선택과 위치는 플레이 배치에서 정한다. 그림을 억지로 벽에 붙이기 위해 점프 간격을 바꾸지 않았다.

## 파일 확인

활성9종 실제 해상도·중앙pivot·PPU100·고유GUID·MaxSize를 확인했다. 후면 RGB, 나머지RGBA. 긴 발판2172px에Max4096, 나머지Max2048. 검토 페이지 이미지31개 로드 실패0. [기계 판독 점검 기록](ClimbMap_Closeout_v01_AssetAudit.json).

## 아직 완료라고 부르지 않는 것

실제 Unity 씬 조립, 캐릭터 이동/점프/충돌, 카메라 추적/패럴랙스, 조명·색공간, 눈 제거는 검증하지 않았다. 시작맵 연결의 승인된 배경 마스크는 남아 있으며 같은 화면을 Unity에서 재현하려면 별도 처리가 필요하다. 등반 단독 입출구 벽에는 그 잘라내기가 필요 없다. 상단 출구 이후 보스전 통로와 실제 룸 전환은 별도 작업이다.

## 사용자가 실제 배치에서 확인할 순서

1. 캐릭터가 입구와 상단 출구를 통과하는지.
2. 작은 발판에 착지할 수 있고 긴 간격을 건널 수 있는지.
3. 실제 카메라가 상하·좌우로 움직여도 배경 끝이나 소재 틈이 보이지 않는지.
4. 플레이어가 어두운 벽 앞과 넓은 쉼턱에서 계속 잘 보이는지.

플레이 수정이 필요하면 해당 발판 위치/너비/간격을 먼저 고치고 아트를 맞춘다. 이 검증을 지금 Codex가 수행한 것으로 기록하지 않는다. 기존 역할 합의대로 사용자가 Unity 배치와 조립을 담당한다.
