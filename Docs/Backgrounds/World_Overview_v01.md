# 현재 제작 전체 배치도

[전체도](World_Overview_v01.html) · [PNG](World_Overview_v01.png)

StartToClimb_Joined_v05와 DropPassage_Prototype_v02(상부 BossArena v09 포함)의 실제 합성 레이어를 같은 HTML 단위로 연결했다. 시작/등반은(0,1200),통로/보스/낙하는(1250,1200)에 배치하여 등반 상단 출구를 맞췄다. 전체도7450×5900 배치 단위이며 PNG는 브라우저 전체 페이지 캡처다. Unity 월드 좌표나 네이티브 맵 텍스처가 아니다.

시작 숲·실내 등반·보스전 통로·외부 첫 보스전·확장된5초 낙하 통로·하단 연결 공간 표시. 보스전맵2는 미제작 표시만 있고 실제 구역은 없다. 낙하5초는 v02의 임시 물리 가정을 유지한다.

단위 배율을 통일했으므로 긴 낙하의 상대 규모를 비교할 수 있다. 전체 지도에서 보이는 배경 사각 경계/빈 검은 영역은 소재 범위와 미제작 공간이다. 경계 가림이나 전체 지형 메움은 이번 출력 작업에서 하지 않았다. 캐릭터 비교 마커는 전체도에서 제외,보스 크기 도형 유지. 구역 상세16:9 검토 링크 제공.

이미지 로드 누락0과 전체도 시각 확인. Unity 씬/코드/원본 스프라이트 변경 없음.
