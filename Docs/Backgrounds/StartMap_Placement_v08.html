수정 후 레이어 확인
점검 항목적용한 해결남아 있는 차이·후속 처리
숲의 형태·밀도오른쪽 나무 높이를 낮추고 군집 크기와 중앙 간격을 바꿈.왼쪽 나무의 눈은 원본보다 선명함. 근경이 준비되면 다시 조정.
고목 형태반복된 꼬임을 줄이고 넓은 줄기 면·세로 균열을 늘림.원본 가지 방향·기울기와 완전히 같지 않음. 눈 덮개는 별도 제작.
원경 거리감기존 독립 안개를 성 뒤·산 앞에 22%로 배치.산 능선 자체는 기존과 같음. 형상 일치까지 해결한 것은 아님.
빠진 화면 요소현재 소재 문제와 미제작 요소를 구분해 기록.왼쪽 고목·지면·눈 덮개 미제작. 다음 제작에서 화면 경계와 뿌리 접지를 연결.

배치 후보는 v05와 같은 비율을 유지해 수정 효과를 비교했다. 성·달 가시성과 알파 연결을 검토했으나, 캐릭터 대비 크기·Unity 카메라·구역 접합·플레이 화질은 미검증이다. 새 수정본은 사용자 최종 승인 전이다.
