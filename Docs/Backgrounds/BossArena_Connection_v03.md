## 검토 조건과 결과

카메라1000×562.5,캐릭터 보이는높이50.625(9%).1회75.9375,5회379.6875 상승. 카메라1:1추적과 추가56.25(화면높이10%)를 합쳐 상단Y-435.9375까지 검토했다. 새 하늘은Y-600부터 시작하여 이 조건에서164.0625의 추가 상단 여유가 남는다. 패럴랙스나 더 높은 발판 출발점까지 보장하는 값은 아니다.

지상 중앙,5회+추가여유에서 출구·중앙·오른쪽을 실제 확인했다. 화면 안에 빈 배경 상단은 보이지 않았고, 출구의 기존 천장 직선 절단면은 마스크 겹침을 보완했다. 모든 이미지 정상 로드.

## Unity 조립에 넘길 내용

HTML 로컬 좌표를 사용한다. 전체 개요에서Y오프셋1200을 더하고 카메라는1200-rise-extra로 이동한다. 아트 크기를 실제 월드 단위로 확정한 값은 아니다.

- UpperSky:x1700,y-600,width2250,brightness0.72. 기존 원경 아래 순서.
- 기존OutdoorFar:위치/크기 유지,상단9% 그라디언트 겹침.
- UpperRock:x700,y-1095,width2050,brightness0.8. 기존 천장 뒤에 두고 하단2.5% 겹침.
- 기존 통로 천장:상단15%,오른쪽4% 마스크 교차로 직선 절단면 완화.

위 마스크는 HTML 검토용이며 PNG 자체에 적용하지 않았다. Unity에서도 동일한 겹침/마스크 처리가 필요하다. 별도 마스크 없는 최종 Unity 접합 완료로 보지 않는다. 전체 등반과 통로를 새로 검증한 것이 아니라 보스전 외부와 출구 상단을 검토했다.

검토 UI는0~5회 높이를 단순 누적 이동한다. 충돌이 없어 캐릭터가 천장 암벽에 겹쳐 보일 수 있으며 실제 그곳에서 점프할 수 있다는 의미가 아니다. 실제 점프곡선/카메라/콜라이더/패럴랙스는 사용자 Unity 구현 후 검증한다. 게임 코드·씬은 수정하지 않았다.
