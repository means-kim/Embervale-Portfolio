# 보스맵 굴곡 초안v05

[검토](BossArena_Connection_v05.html) · [배치와 곡선 데이터](BossArena_Connection_v05.json)

사용자 요청: 초안을 먼저 보고 피드백. 보스높이는 주인공5~6배로 가정했고 패턴은 돌진·땅내리치기·점프내려찍기·팔휘두르기다. 실제 보스너비와 점프높이는 미정이다.

## 제안

입구 평지→낮은 둔덕→넓은 중앙 평지→오른쪽 완만한 오르막. 기본 전체높이차0.5캐릭터높이(25.3125),왼쪽둔덕0.3높이(15.1875). 중앙평지x2800..3400. 오르막x3400..3750. 곡선은smoothstep으로 양끝기울기를0으로 이어 급격한단차를 피했다. 평탄/0.3/0.5비교선택 제공.

보스비교도형은5/5.5/6배 높이 선택. 정식보스아트·히트박스·공격범위가 아니다. 반투명 기하도형으로 구분했다. 중앙기본5.5배높이는278.4375,캐릭터높이는50.625. 중앙평지폭600은 보스 이동·공격 사양 확인 후 조정 가능하다.

## 제작 방식과 확인

기존 바위와 눈 PNG를 HTML에서 가는구간으로 나누어 높이곡선을 따라 이동한 레이아웃초안이다. 원본을 래스터편집하거나 새 경사PNG로 저장하지 않았다. 피드백후 실제 경사/평지/접합용 소재를 만들기 위한 검토이며 Unity에그대로사용할완성지형팩이 아니다. 별도바위·눈구조 유지.

[중앙](BossArena_Connection_v05_Center.png),[오른쪽](BossArena_Connection_v05_Right.png),[5회상승](BossArena_Connection_v05_MaxJump.png)확인. 이미지로드누락없음. 지형에따라캐릭터접지와카메라기준도같이상승한다. 지형최고점25.3125+5회379.6875+추가56.25=461.25이며 하늘시작-600 대비138.75여유가 남는 것을 산술확인했다. 실제최고점물리점프검증은아니다.

확인할피드백: 굴곡이너무약한지/강한지,중앙평지가충분히넓은지,보스5~6배대비공간비율. 보스점프높이는플레이어점프와별개로미정. 실제돌진경사처리·지면공격범위·안전지대·플레이어와보스동시프레이밍은Unity검증필요. 이번에는씬/게임코드/충돌변경없음.
