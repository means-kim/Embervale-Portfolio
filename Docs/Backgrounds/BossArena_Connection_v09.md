# 중앙 파괴 구멍 단면 마감 v09

[검토](BossArena_Connection_v09.html) · [배치](BossArena_Connection_v09.json) · [프롬프트](BossArena_Connection_v09_Prompts.md)

사용자가 v08 배치를 채택했다. 이번 변경은 중앙 파괴 구멍 양쪽의 직선 절단면을 불규칙한 암반 실루엣으로 마감하는 작업이다. 정상·균열 바닥과 넓은 전투장, 비대칭 굴곡, 발판3개는 유지한다.

## 새 소재와 조립

- BG_Boss1_BreakEdge_v01.png: 요청과 실제1024×1536 RGBA. PPU100, 중앙pivot, Sprite Single, Max2048. 고유 .meta 포함. 눈·파편·후면 배경은 포함하지 않는다.
- 기본 방향은 왼쪽 지반의 오른쪽 단면. 오른쪽은 같은 소재를 좌우 반전해 사용한다.
- HTML 왼쪽 X4140, Y356.625+terrainY(4510), 폭320. 오른쪽 X4560, Y359.625+terrainY(4510), 폭320, flipX. 기본 굴곡3 기준 Y402.1875/405.1875. 수치는 Unity 월드 단위가 아니다.
- 파괴 후 기존 바위 본체 제외 구간을 X4290~4730으로 넓히고 전용 단면을 겹친다. 레이어는 후면→바닥/파편→단면→별도 눈. 눈 제거 범위는 기존4340~4680 유지. 전용 소재의 알파 윤곽이 보이는 구멍 경계를 만든다.
- 정상·균열에서는 단면을 표시하지 않는다. 중앙 파괴 바닥 v02와 별도 눈의 접합을 유지한다.

## 확인과 다음 단계

원본 컨셉과 기존 바닥을 실제 이미지로 대조했다. 출력의 RGBA와 외곽 표본 알파0 확인. 브라우저 정상·균열·파괴 후를 직접 확인하고 캡처했으며 정상 상태 누락 이미지 없음. 중앙 위치,16:9,캐릭터약9%,보스5~6배 비교 유지.
