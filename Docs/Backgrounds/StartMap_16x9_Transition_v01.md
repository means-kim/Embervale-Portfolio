## 최신 사용자 정정 — 카메라는 전체 맵의 일부만 표시

이 문서의 전체 합성을16:9에 맞춘 확장안은 과거 검토 가정이다. **원경 양옆 확장이 먼저 필요하다는 결론과 캐릭터 화면 높이5.42% 유지 가정은 철회한다.**16:9는 카메라 뷰포트 비율이다. 전체 맵 비율·배경 이미지 비율·실제 카메라 범위는 별개다.

이후에는 전체 배치도를 유지하면서 이동 경로의 일부를 보는 카메라 구간별 검토를 먼저 한다. 그 결과 경계가 노출되는 영역에 한해 확장·분할 제작을 결정한다. 아래 수치와 표는 전체 합성을 한 화면에 맞췄던 과거 가정의 계산 기록이며 현재 제작 요구량이 아니다.

## 확정과 가정 구분 (과거 검토)

확정: 목표 화면비16:9. 작업 가정: 기존 캐릭터 화면 높이 약5.42%를 유지하면서 좌우 표시 범위를 늘린다. 최종 카메라 크기·캐릭터Scale·출력 해상도는 아직 미정이다. 씬이나 전역 설정은 변경하지 않았다.

기존4:3 합성을 중앙에 놓고 높이를 유지하면 새 화면의 중앙75%가 기존 범위다. HTML 변환식은 너비=기존너비×0.75, X=12.5+기존X×0.75, Y=기존Y. 이미지 종횡비를 유지하므로 가로 늘이기나 세로 자르기가 아니다. 프레임 비율과 캐릭터 보이는 높이 약5.42%를 DOM 크기로 확인했다.
