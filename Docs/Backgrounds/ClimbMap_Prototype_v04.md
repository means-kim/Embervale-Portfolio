# 하단 입구 바닥 접합 점검 v04

2026-09-23. 사용자 지적에 따라 입구 바닥 양끝과 투명 여백을 점검했다.

[수정 화면](ClimbMap_Prototype_v04.html) · [수정 캡처](ClimbMap_Prototype_v04_Entry.png) · [배치](ClimbMap_Prototype_v04.json)

## 원인

입구 바닥은 독립 긴 발판 PNG를 사용한다. 기존 X-70·너비1140 배치에서 화면 왼쪽 경계가 원본 x약133에 해당한다. 이 열의 alpha128 이상 영역은 y202~226으로 매우 얇아, 그 아래에 후면 배경이 드러난다. 오른쪽 끝도 원본x약2038에서 y213~308만 바위여서 바닥 끝이 노출될 수 있었다. 이는 독립 발판 끝을 연속 바닥처럼 사용한 배치 문제다.

## 수정

입구 entry만 X-300, Y1311.08, 너비1600으로 변경했다. 양쪽 끝을 화면 밖으로 빼고 더 두꺼운 내부 부분이 경계에 오도록 했다. 비율 유지 확대이므로 바닥 암석도 더 굵게 보인다. 개별 등반 발판의 폭·위치·간격은 변경하지 않았다. 신규 PNG와 Unity 변경 없음.

기본 캐릭터 위치의 원본 표면 y약227/2172를 사용해 발 기준선을 약1478.3으로 유지했다. 이 보정은 참고 위치에서의 정지 합성을 위한 것이며 편집으로 임의 위치에 옮겨도 정확한 접지가 되는 충돌 계산이 아니다. 실제 표면은 굴곡져 있다.

하단 구도에서 끊겨 보이던 끝부분과 캐릭터 발의 위치를 확인했다. 카메라 최하단에서도 끝이 드러나는지 점검했다. 이미지 로드 실패0, 전체 배치도와 카메라 창의 entry 좌표 일치. 기존 v03은 보존했다.

현재 확인은 등반맵 내부 입구 바닥에 한정한다. 시작맵 외부와 실제 씬 경계로 이어지는 접합·충돌·플레이는 아직 검증하지 않았다.
