# 시작맵 화면비 검토 v01

2026-09-23. [인터랙티브 비교](StartMap_Framing_v01.html) · [너비 유지 캡처](StartMap_Framing_Width_v01.png) · [높이 유지 캡처](StartMap_Framing_Height_v01.png).

채택 배치v28(성v02·숲v03)을 기준으로 기존4:3 비교 범위를16:9에 담는 두 방식을 검토했다. 실제 게임 화면비를16:9로 결정한 것은 아니다. 신규 스프라이트·Unity 씬·카메라 설정 변경은 없다.

| 방식 | 기하학적 변화 | 관찰과 한계 |
|---|---|---|
| 너비 유지 | 높이가 기존의75%, 캐릭터 화면 높이 비율5.42%→7.22% | 위25%를 자르면 이동로는 남지만 달과 성 상단이 잘린다. 아래를 자르면 이동로가 잘릴 수 있다. |
| 높이 유지 | 표시 너비가 기존보다33.3% 증가, 캐릭터 화면 높이 비율5.42% 유지 | 기존 검토 범위는 새 화면 중앙75%를 차지한다. 좌우 각12.5%의 영역을 추가 확인해야 한다. |

비교 패널은 같은 가로 너비이므로 높이 유지 모드의 그림은 왼쪽보다 작게 표시된다. 이는 패널 안의 축소 표시이며 플레이어 Unity Scale을 줄인 결과가 아니다. 사선 여백은 기존4:3 합성 범위 밖을 뜻하며 실제 소재가 반드시 없는 영역 또는 검은 띠를 넣는 최종 화면을 뜻하지 않는다. 원래 프레임 밖으로 뻗은 소재도 있을 수 있어 실제 배치 검토가 필요하다.

선택 메뉴로 두 방식 전환, 위쪽 자름0~25%, 숲·그루터기·동굴 플레이어 위치 동기 비교를 제공한다. 높이 유지에서 잘림 슬라이더 비활성, 양쪽 플레이어 이동 동기, 전체 이미지 로드, 패널 비율을 확인했다. 정지 합성만 검토했으며 이동·점프·카메라 추적·패럴랙스는 구현하지 않았다.

## 다음 배치 판단에 필요한 사용자 기준

목표 화면비가 먼저 필요하다. 이후 실제 플레이어 Scale과 카메라에서 보이는 캐릭터 높이를 맞추고 좌우 표시 범위 및 지형 고저차를 결정한다. 기존 컨셉 비교용4:3을 실제 플레이 카메라로 자동 채택하거나, 이 검토의16:9를 확정 설정으로 쓰지 않는다.

최신 아트 배치 기준은 계속 [v28](StartMap_Placement_v28.html)이다. 눈 제거의 발 크기 기준도 실제 배치 후 결정한다.
