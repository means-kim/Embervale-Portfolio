# 시작 구역 눈발용 입자

## 납품

- 이미지: ../../../Assets/04.Sprites/Backgrounds/StartMap/FX_Start_SnowParticle_v01.png
- 내장 image_gen으로 Bg_Concept.png의 팔레트를 참고해 제작. 원본 실제 1254×1254 RGBA, 모서리 알파0. 프롬프트는 Prompt.txt.
- Unity: Sprite/Single, PPU100, Max Size128(실제 가져온 Texture 128×128), Bilinear, Clamp, Uncompressed, mipmap off, Alpha Is Transparency on. 원본 PNG를 리사이즈하거나 덮어쓰지 않음. .meta 함께 보존.
- 단일 비대칭 눈 알갱이. 전체 화면 눈발 이미지나 애니메이션 시트가 아님.

## 정지 합성 검토

Preview_0: 기존 맵. Preview_1: 낮은 안개+작은 눈32개. Preview_2: 안개+작은 눈32개+조금 큰 눈8개. 임시 SpriteRenderer와 카메라로 확인했으며 실제 씬에는 배치하지 않았다.

- 카메라(12,9), Orthographic Size12, 16:9 960×540. X-8~32,Y2~21에 고정 시드의 무작위 분포.
- 작은 입자는 투명 여백 포함 전체 폭0.16~0.30, alpha0.42, GA1_BG_Mid/35.
- 가까운 입자는 전체 폭0.30~0.44, alpha0.65, GA1_World/50. 플레이어 Actors보다 뒤.
- 임의 회전0~360도, 약한 청백색 틴트. 실제 눈의 가시 폭은 PNG 여백 때문에 전체 폭보다 작으며 출력 해상도에 따라 달라진다.
- 배경을 덮는 눈보라가 되지 않는 낮은 밀도와 지형/캐릭터 가독성을 확인. 움직임/시간당 방출량은 검증하지 않았다. 임시 오브젝트는 모두 제거하고 플레이어 원위치 복원, 씬 저장 안 함.

## 사용자가 이어서 구현할 사항

이번 결과는 텍스처와 정지 합성뿐이다. 기존 Particle System에 이 소재를 사용하거나 새 시스템을 Inspector에서 구성하는 작업은 아직 하지 않았다.

추후 시작 구역의 느린 낙하, 작은 좌우 흔들림, 수명 양끝의 알파 페이드, 크기/회전 차이를 설정하면 된다. 합성의 40개는 한 화면의 예시 개수이지 Emission Rate 값이 아니다. 최종 방출량은 수명과 이동 속도를 함께 보고 정한다.

기본 눈발 자체는 Particle System 설정으로 구성할 수 있다. 플레이어를 따라 방출 영역을 옮기거나 동굴 진입 시 숨기는 동작이 필요하면 사용자 코드와 연결할 지점을 따로 설계한다. 현재 포털 셰이더의 표시 전환이 새 입자에 자동 적용된다고 가정하지 않는다. 스크립트/셰이더/씬/프리팹은 이번 작업에서 수정하지 않았다.

다음 아트 작업은 착지 눈먼지. 이 입자와 같은 이미지로 통째로 대체하지 않고 발밑에서 짧게 퍼지는 별도 형태로 제작한다.
