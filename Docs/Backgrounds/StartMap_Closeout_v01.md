# 시작맵 1차 아트 마감 검토

2026-09-23. 사용자가 ‘전체 검토 → 필요한 수정 → 배치 자료 정리와 확인 → 등반맵’ 순서에 동의해 진행했다.

## 현재 판단

시작맵의 1차 아트 시안과 인계 자료가 준비되었다. 실제 플레이 가능한 맵 완성이나 개별 소재의 최종 사용자 승인을 뜻하지 않는다. 근거 없는 완성률 숫자는 부여하지 않는다.

현재 카메라 v04의 숲·하단 안개 위치 보정을 마감 검토안으로 유지했다. 이번 검토에서 새로 확인된 문제 중 추가 장식 생성으로 해결해야 할 항목은 없었다. 새 PNG·씬·게임 코드 변경 없이 최신 소재 목록을 통합했다.

## 컨셉 대비 남은 차이와 처리

| 항목 | 현재 판단 | 처리 |
|---|---|---|
| 오른쪽 고목 대신 동굴 | 사용자 선택 방향 | 유지 |
| 숲 밑동이 떠 보이던 문제 | v04에서 지면 뒤로 이동 | 현재 구도 유지 |
| 평평한 이동 지형 | 지형의 최종 고저차 미확정 | 실제 이동·점프 검증 후 지형 아트를 맞춤 |
| 달·성의 화면 밖 위치 | 선택한 부분 카메라에서는 자연스러운 크롭 | 모두 보이도록 맵을 축소하지 않음 |
| 입구 내부와 바닥이 합쳐진 동굴 | 연결용 최종 모듈이 아님 | 다음 구역 진입 지형에 맞는 소재를 분리 제작 |
| 원본과 다른 산·숲 실루엣 | 컨셉 완전 일치가 아님 | 현재 마감 시안으로 제시하고 전체 재생성은 진행하지 않음 |

## 확인한 범위

- PNG18개와 .meta를 확인한 19개 표시 항목. 눈5쌍의 크기·PPU·피벗·좌표 일치.
- 시작·중간·입구의 정지 구도와 캐릭터 가독성을 기존 v04 캡처 및 마감 화면에서 확인.
- 마감 화면은 16:9, 창 크기80×60%, 기준X20~100%·Y40~100%, 캐릭터 높이약9% 유지.
- 이미지 로드 실패 없음. 세 구간과 기준 구도 전환 제공.

실제 Unity 배치·충돌·점프·카메라 추적·패럴랙스·눈 제거는 미검증이다. 이 항목 전체의 완료를 다음 맵 장식 아트 착수 조건으로 두지는 않는다. 최종 플레이 지형 아트 확정에는 필요하다.

## 등반 연결 제안

시작 숲 → 오른쪽 동굴 입구 → 같은 높이의 짧은 전이 통로 → 위로 열린 암벽 틈에서 등반 → 상부 보스전 통로.

이것은 원본에 그대로 있는 경로라고 주장하는 것이 아니라, 오른쪽 동굴 변경과 기존 수직 진행 방향을 함께 유지하기 위한 제안이다. 연결 설명도의 꺾인 화살표는 진행 방향이며 실제 발판 배치를 의미하지 않는다. 구역 수와 Unity 씬 수는 별도로 결정한다. 시작맵의 오른쪽 고목을 복원하지 않는다.

연결 지점의 바닥 높이와 바위 재질을 이어주고, 실내 전이 통로에서는 눈을 줄인다. 위로 열린 틈은 달빛과 먼 산이 보이게 하며 눈은 바깥에 노출된 턱에 둔다. 카메라 한 화면에 등반 전체를 넣지 않는다. 현재 캐릭터의 화면 크기감을 비교 기준으로 삼고 실제 수직 카메라 범위는 지형과 함께 검토한다.

## 사용자 확인과 다음 작업

확인할 결정: **현재 시작맵을 1차 아트 기준으로 고정하고, 위 연결 방향으로 등반맵에 착수할지.** 사용자가 요청한 마감 확인 단계이며 추가 장식을 만들 때마다 받는 승인이 아니다.

동의 후에는 등반맵 하단 진입부 한 구간의 구도·레이어 분리 계획부터 시작한다. 첫 소재는 그 구도를 받치는 암벽 틈의 먼 배경으로 한정하고 원본 컨셉과 시작맵 입구를 참조한다. 암벽·발판·눈을 한 이미지에 합쳐 전체 맵을 한 번에 제작하지 않는다. 실제 발판 간격과 점프 동선은 플레이 검증 이후 확정한다.

이 문서 작성 시 등반맵 PNG는 아직 제작하지 않았다. 사용자가 연결 방향을 확인할 때까지 시작맵에 소품을 계속 추가하지 않는다.
