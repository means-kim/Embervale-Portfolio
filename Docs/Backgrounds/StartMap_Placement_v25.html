컨셉의 시작 구역

동굴 입구 배치 후보

오른쪽 고목 몸통·앞뿌리·고목 눈을 제외했습니다. 동굴 입구에는 어두운 내부 벽이 포함됩니다. 현재 암벽과 바닥은 구도 검토용 한 소재이며 최종 충돌 지형이 아닙니다.

컨셉 좌상단 640×480에서 인물 높이를 약 24~28px로 육안 추정 → 비교 목표 26px(화면 높이 5.42%). Run_00 실제 불투명 그림 높이 336px 기준으로 환산했습니다. 이전 시안은 같은 범위에서 약 74.3px로 약 2.86배 컸습니다. Unity Scale 확정값이 아닙니다.

숲에서 동굴까지 바위 지면 후보를 추가했습니다. 별도 눈 덮개를 추가했고 동굴 내부 확장은 아직 미제작이며, 실제 지형 충돌과 접합 검증은 남아 있습니다. 전체 맵 경로 변경 범위는 확정하지 않았습니다.

고드름은 암벽과 분리된 천장 장식입니다. 표시 밝기55%는 HTML 검토값이며 위험물·낙하·충돌 판정은 없습니다. 점프 여유는 실제 플레이에서 확인해야 합니다.

추가한 관목은 시작 숲의 바닥 뒤에 배치한 장식입니다. 가시·장애물·발판이 아닙니다. 눈은 포함하지 않았으며 작은 크기에서 가지 가독성은 실제 카메라로 재확인이 필요합니다.

추가한 바위는 캐릭터와 이동 바닥 뒤의 장식입니다. 새로운 장애물이나 발판으로 확정하지 않았습니다. 눈 제거 연출 검토는 중단하고 배치 소재 제작을 진행합니다.

외부 암벽의 눈은 바위와 같은 캔버스에 분리했습니다. HTML 표시 밝기70%이며 입구 내부와 이동 바닥에는 추가하지 않았습니다.

암벽과 눈 정렬 확대

작은 그루터기는 이동로 뒤의 장식입니다. 현재 보이는 높이는 캐릭터의 약1.69배이며, 나무·지면 접합을 가릴 수 있도록 지면보다 뒤에 배치했습니다. 나무 PNG에는 눈을 포함하지 않았으며 별도 눈 PNG를 같은 좌표에 겹쳤습니다. 충돌·발판 기능은 없습니다.

그루터기 눈은 동일1254×1254 캔버스의 독립 소재입니다. 축소 화면에서는 얇은 서리처럼 은은하게 보입니다. 눈 전후 확대 비교
