## 수정

실내 영역을 왼쪽으로 200 확장해 시작맵 아래에 먼저 그린다. 기존 실내 오브젝트의 월드 X는 유지하고 후면 배경만 폭1200·높이1600 cover로 다시 맞췄으므로 뒤벽 구도는 조금 달라진다. 시작맵 컨테이너를1250에서1450으로 열어 원래 잘리던 동굴 오른쪽을 보여주고 X1170~1450 범위에 가장자리 마스크를 적용했다. 지면과 별도 눈의 마지막12%에도 마스크를 적용해 맨바위로 이어지게 했다. 등반 입구 바닥만 Y+15 내려 높이 차이를 줄였다. 다른 발판 크기·간격은 그대로다.

## 확인 결과

브라우저에서 접합 확대·실내 하단·전체 배치를 실제 확인했다. 수직 절단선과 갑작스러운 바닥 단차가 완화되고 내부에 하늘이 노출되지 않는다. 이미지 로드 실패0. 카메라16:9·캐릭터 높이약9% 유지. 바위 덩어리 크기의 차이는 남지만 겹침 구간을 거쳐 전환된다.

## 적용 범위

기존 PNG를 사용한 HTML 아트 조립 시안이다. 새로운 이음 스프라이트를 제작한 것이 아니며 PNG 자체는 수정하지 않았다. 가장자리 마스크를 생략하고 Unity에 단순 배치하면 같은 결과가 나오지 않는다. 실제 조립 시 동등한 마스크 또는 별도 이음 소재가 필요하다. 이번 수정은 Unity·충돌·실제 이동·패럴랙스 검증을 포함하지 않는다. v01 보존.
