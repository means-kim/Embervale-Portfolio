이후 아트 제작·크기·접합 검토의 기준으로 사용한다. 이전55%·13.1%는 탐색 기록이며 현재 선택값이 아니다. 전체맵을 한 화면에 맞추는 방식으로 되돌리지 않는다.

초기 화면과 ‘선택 기준 복원’ 버튼에 위 값을 반영했다. 구간 버튼은 창 크기를 유지하고 가로 위치·비교 캐릭터만 바꾼다. 다른 값을 탐색하면 ‘비교용 변경값’으로 구분한다. 복원 버튼은 카메라 값을 복원하며 비교 캐릭터 위치까지 강제 초기화하지 않는다.

선택된 X/Y는 기준 구도이며 실제 게임 카메라가 항상 고정된다는 의미가 아니다. 캐릭터의 초기 표시 위치27%는 기존 도구 값을 유지했으며 이번 선택을 스폰 위치 승인으로 해석하지 않는다.

화면비·박스 좌표·캐릭터 표시 비율·이미지 로드를 확인하고 구간 이동 후 선택 기준 복원을 확인했다. Unity Orthographic Size, 월드 좌표, 플레이어Scale, 추적·패럴랙스·이동·충돌은 아직 적용·검증하지 않았다. 이후 배치도의 월드 크기가 달라지면9% 시각 기준과 실제 플레이를 함께 맞추며80%라는 배치도 비율만 기계적으로 재사용하지 않는다.
