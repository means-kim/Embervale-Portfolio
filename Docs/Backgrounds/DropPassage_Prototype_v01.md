## 구성

보스전 v09의 중앙 구멍 X4510에서 아래로 내려가는 통로다. 신규 후면 암벽과 기존 독립 단면 암벽4개를 조립했다. 배경·좌우 벽·하단 바닥은 분리되어 있다. 하단은 다음 구역을 연결하기 위한 착지 공간이며 보스전맵2 전투장을 만든 것은 아니다.

카메라1000×562.5(16:9), 실제 보이는 캐릭터 높이50.625(9%) 유지. 깊이0/480/1000/1793의4화면과 연속 슬라이더 제공. 낙하 깊이1793은 약35.4캐릭터 높이의 임시 배치이며 플레이 수치 확정이 아니다. 캐릭터는 기존 달리기 프레임을 크기 비교로 표시했다.

## 새 소재와 조립

Assets/04.Sprites/Backgrounds/DropPassage/BG_Drop_InteriorBack_v01.png: 실제887×1774 RGB, 요청1024×2048과 구분. PPU100·중앙pivot·Sprite Single·Max2048. PNG와 고유 .meta, 폴더 .meta 보존. 동굴 후면과 희미한 얼음 질감만 포함하며 하늘·달·별도 충돌용 벽·발판·눈은 제외했다.

단면은 BossMap1/BreakEdge_v01을 재사용하고 오른쪽은 좌우 반전한다. 큰 암벽의 하단을 다음 조각의 상단에 겹치고, 아래 조각의 상단10~20%에 HTML 마스크를 사용해 수평 이음을 완화했다. 이것은 PNG 자체의 알파 수정이 아니다. Unity에서 동일한 겹침/마스크 또는 후속 전용 이음 소재가 필요하다. 새 배경의 확대 표시가 원본 디테일을 늘리는 것은 아니다.

후면은 Y440부터80높이 동안 전환하며 Y520 아래는 불투명 실내다. 실내 진입 검토 카메라의 상단은 Y525.5625이므로 하늘이 보이지 않는다. 하단 바닥은 기존 Ground_v01을 눈 없이 재사용하며 표면은 약Y2232.5625이다.

## 확인 범위

원본 컨셉의 우측 낙하 틈과 하부 동굴 색감을 실제 이미지로 비교했다. 브라우저에서 [입구](DropPassage_Prototype_v01_Entry.png), [실내 진입](DropPassage_Prototype_v01_Interior.png), [중간](DropPassage_Prototype_v01_Middle.png), [하단](DropPassage_Prototype_v01_Lower.png)4구간을 직접 확인했다. 실내 하늘 노출 없음, 중간 수평 단면 완화, 하단 캐릭터 발 높이 보정, 이미지 로드 누락 없음.

전체 지형 충돌·낙하속도·낙하피해·점프·카메라 기능과 보스전맵2 진입 동선은 미검증이다. 상부5회점프 검토는 기존 자료를 유지하며 이번에는 낙하 카메라 구간을 확인했다. Unity 씬·코드 변경 없음. 다음 작업은 하단과 보스전맵2 진입부의 연결이다.
