# 점프와 배경 상단 검토 기준

사용자 예정 사양: 최대5회 점프,1회 상승은 캐릭터 크기의1.5배. 보수적 아트 검토는 누적7.5캐릭터 높이를 확보하는 방향으로 한다. 실제 물리 상승량은 재점프 타이밍/속도 갱신/중력/천장 충돌에 따라 달라지므로 이 산술값이 실제 점프 궤적이라는 뜻은 아니다.

## 현재 보스전v02 수치 점검

현재 카메라높이562.5,보이는 캐릭터높이9%=50.625.1회75.9375,5회 합산379.6875(카메라높이67.5%). 이 수치는 투명 프레임 전체 크기를 사용하지 않았다.

카메라가 상승량 전체를1:1 추적한다고 가정하면 카메라 상단은 로컬Y-379.6875까지 이동한다. 현재 외부 원경은Y-40에서 시작하므로 약339.6875만큼 추가 상단 그림이 필요하다. 추가 안전 여유와 패럴랙스는 이 수치에 포함하지 않았다. 따라서 현재v02는 지상 구도 검토본이며5회 점프 시 상단 노출 방지 완료가 아니다.

## 이후 제작·검토 순서

1. 실제 배치한 캐릭터 몸체 크기와 이동 사양을 기준으로 최대 도달 높이를 맞춘다. 높은 발판 출발점도 포함한다.
2. 카메라 상하 추적/데드존/한계와 패럴랙스별 배경 이동을 합산해 보여줄 영역을 계산한다.
3. 컨셉 구도와 지상 기준 크기를 유지하면서 위쪽 하늘/암벽 연장 영역을 제작한다. 단순 PNG 늘이기나 카메라 임의 고정으로 대체하지 않는다.
4. 지상·각 점프 정점·최고 상승 카메라·좌우 이동을 함께 점검한다. 천장 스프라이트의 윗 절단면과 출구 양옆도 확인한다.

현재는 요구사항과 기존 소재 여유를 수치 점검한 단계다. 새 이미지/Unity씬/점프/카메라 코드는 변경하지 않았다. 관련수치: [JSON](Jump_Camera_ArtBounds_v01.json).
