# 5초 낙하 통로 v02

[검토 화면](DropPassage_Prototype_v02.html) · [배치와 계산](DropPassage_Prototype_v02.json)

사용자가 낙하 시간을5초로 지정했다. 기존1793에서3695.173 HTML 단위로 약2.061배 깊게 늘렸다. 캐릭터 보이는 높이50.625 기준35.4→73.0캐릭터 높이. 카메라16:9와 캐릭터약9%는 유지했다.

## 계산의 가정

프로젝트 Physics2DSettings의 전역 중력Y=-9.81을 읽었다. Assets의 코드/프리팹에서 플레이어 gravityScale·낙하속도 설정은 확인되지 않았다. 정지 출발,중력 배율1,저항/종단속도 제한 없음,플레이어 Scale1을 임시 가정했다. 검토에 사용하는 실제 그림 높이336px / PPU200 =1.68유닛. 캐릭터 크기 참고 문서의 약337px 예시와1px 차이가 있으므로 정확한 플레이어 치수 확정값으로 보지 않는다.

거리 =0.5×9.81×5² =122.625유닛. HTML 깊이=122.625/1.68×50.625=3695.173. 이는 낙하 시간을 실제로 보장하는 Unity 설정이 아니다. 중력 배율·초기속도·낙하 최대속도·캐릭터Scale이 바뀌면 다시 계산해야 한다. 중력/Scale/코드는 변경하지 않았다.

## 배치와 검토

독립 암벽을 좌우5개씩 총10개로 늘리고 기존 후면 PNG를 상하 겹쳐 배치했다. 후면 추가 패널은 로컬Y2600,상단15%페이드. 기존 PNG 재사용으로 신규 래스터 소재는 없다. Unity 조립에서는 같은 마스크와 겹침을 별도로 재현해야 한다.

하단 바닥 표면은 Y4134.73549로 이동했다. 바닥PNG 배치Y3958.03199,폭1900. 하단은 다음 방 연결 공간으로 유지하고 보스전맵2는 추가 제작하지 않았다.

5초 낙하 재생/일시정지 버튼과 시간 표시를 추가했다. 위치는 t²에 비례하는 아트 미리보기다. 실제 낙하 모션은 기존 달리기 비교 프레임으로 대체하며 물리·충돌 검증이 아니다.

확장 중간과 하단을 직접 확인했다. 재생 종료 표시5.00초,깊이3695.173,이미지 로드 누락0 확인. [중간](DropPassage_Prototype_v02_Middle.png) · [하단](DropPassage_Prototype_v02_Lower.png). 전체 이동 중 모든 프레임을 검증한 것은 아니다. 실내 후면 가림 구조는 v01 유지.
