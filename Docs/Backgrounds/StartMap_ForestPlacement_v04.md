# 중경 숲 접지 배치 v04

2026-09-23. 신규 스프라이트 없이 기존 숲과 하단 안개의 배치만 조정한 검토안.

## 차이와 조정

[원본 컨셉](../../Assets/04.Sprites/Bg_Concept.png)을 실제로 열어 비교했다. 컨셉에서는 숲이 계곡과 지면 뒤로 이어지지만 기존 합성은 수목 밑동이 공중에서 끝나는 인상이 강했다. 숲을 아래로 내려 지면 뒤에 겹치게 했다. 오른쪽 고목 대신 동굴로 향한다는 사용자 변경 방향은 유지한다.

| 항목 | 이전 v03 | 현재 v04 |
|---|---|---|
| ForestMid_v03 top | -9% | 9% |
| 하단 Mist_v01 top | 48% | 66% |
| 하단 안개 불투명도 | 18% | 18% |
| 카메라 폭 / 높이 | 80% / 60% | 동일 |
| 기준 창 | X20~100%, Y40~100% | 동일 |
| 캐릭터 보이는 높이 | 약9% | 동일 |

수치는 전체 배치도 기준이며 Unity 월드 좌표가 아니다. 숲과 하단 안개를 각각18%p 아래로 옮겼다. 상단 안개·원경·캐릭터·지면·눈·동굴 위치와 크기는 그대로다. 중간 시도인 숲 top2%는 작은 수목 밑동이 여전히 드러나 채택하지 않았다.

## 검토 결과와 한계

[현재 화면](StartMap_CameraWindow_v04.html)의 ‘이전 숲 위치 비교’로 두 배치를 전환한다. 전체 배치도와 카메라 창 모두 적용된다. 기본값은 새 배치다.

- [시작 숲](StartMap_ForestPlacement_v04_Start.png): 주요 침엽수 밑동이 지면 뒤에 가려진다. 캐릭터 주변 숲 밀도는 높아졌지만 정지 화면의 실루엣은 구분된다.
- [중간 이동](StartMap_ForestPlacement_v04_Middle.png): 산 능선의 여백과 동굴로 이어지는 이동로가 보인다.
- [동굴 진입](StartMap_ForestPlacement_v04_Entry.png): 입구와 캐릭터를 가리지 않는다. 작은 먼 수목의 끝은 지면 가까이에 보인다.
- 이미지 로드 실패0, 전후 토글 적용, 기준 창과 캐릭터 비율 유지 확인.

현재 PNG 내부의 숲 깊이와 밀도 자체를 바꾼 것은 아니다. 컨셉보다 평평한 이동 지형과 원경 구도 차이는 남아 있다. 실제 Unity 카메라 추적·패럴랙스·점프·접합 품질은 미검증이다. 새 배치는 검토 후보이며 사용자 개별 승인 완료로 간주하지 않는다.

## 파일 상태

기존 v03과 전체 배치 v28은 보존한다. 최신 조립 참고는 [v04 배치 데이터](StartMap_CameraWindow_v04.json)에 기록했다. 기반 v28 + v03 잔돌 눈 추가 + 이번 숲/안개 위치 변경 순서다. Unity 씬·게임 코드·PNG·meta 변경 없음.
