# 보스전 중앙 파괴 바닥 v08

사용자 피드백: 파괴 바닥은 보스전 맵 중앙에 놓고 더 자연스럽게 연결한다. v07의 입구 배치는 철회한다.

[검토 화면](BossArena_Connection_v08.html) · [배치 데이터](BossArena_Connection_v08.json) · [제작 프롬프트](BossArena_Connection_v08_Prompts.md)

## 변경

- 전투장 X2820~6200의 정확한 중앙 X4510에 파괴 구간 X4340~4680을 배치했다. 입구 X2530~2820은 연속 지형으로 복구했다.
- 얇고 작은 돌이 나열된 v01 대신 두꺼운 큰 암반 덩어리로 v02 정상·균열 PNG를 제작했다. 두 상태는 같은 캔버스와 배치 기준을 사용한다.
- 정상/균열 상태는 별도 눈 덮개가 주변에서 연속된다. 파괴 후 해당 구간의 눈과 바닥만 사라지고 기존 파편을 표시한다. 게임 기능이 아닌 아트 상태 전환이다.
- 양쪽 경사의 길이와 굴곡을 다르게 만들고 과도한 둥근 곡선을 줄였다. 기본 전체 높이 차이 3캐릭터키, 중앙 평지 폭1040, 전투장3.38카메라폭, 독립 발판3개를 유지한다.
- 보스 크기 비교 도형을 X4850으로 옮겨 파괴 구멍 위에 떠 있는 표시를 방지했다.

## 새 소재

BG_Boss1_BreakFloor_v02.png와 BG_Boss1_BreakFloorCracked_v02.png: 실제 각각1254×1254 RGBA, PPU100, 중앙pivot, Sprite Single, Max2048. 정상 요청은1024×1024였으며 실제 출력과 구분한다. 암반만 포함하며 눈·파편은 별도다. PNG와 고유 GUID의 .meta를 보존했다. 기존 v01은 삭제하지 않는다.

## 확인과 한계

입구 연속 바닥과 중앙 정상·균열·파괴 후 화면을 브라우저에서 확인하고 캡처했다. 정상 상태의 이미지2613개 로드 완료. 카메라16:9·캐릭터 약9%, 보스5~6배 기준 유지. 상단 배경과 높은 발판은 v07 구성을 유지한다.

지형 굴곡은 기존 PNG의 HTML 스트립 합성이며 최종 경사 스프라이트가 아니다. 파괴 후 구멍의 양쪽 단면은 임시 클리핑이고 전용 파단면 소재까지 완성한 상태가 아니다. 배경 마스크와 이음은 Unity 조립에서 별도 확인해야 한다. 파괴 조건, 충돌, 보스 패턴, 낙하 후 연결과 실제 플레이는 구현·검증하지 않았다. Unity 씬·코드 변경 없음.
