| [StartMap_v01.md](StartMap_v01.md) | 시작맵 v01의 기준 이미지, 실제 사양, 생성·수정 프롬프트, 비교 이미지 |

## 기록 원칙

- 생성 요청 크기와 실제 파일 크기를 따로 적는다.
- PPU·Import 설정·Scale 1 크기·권장 배치 크기를 구분한다. 미정인 값은 미정으로 남긴다.
- 미리보기 완료, 실제 씬 확인, 사용자 확인을 별개로 표시한다.
- 사용자가 확인하지 않은 결과물을 승인된 참조로 승격하지 않는다.
- 기존 프롬프트는 제작 이력이다. 그 안의 과거 설정값이 최신 사용자 요청보다 우선하지 않는다.
- 이미지 참조와 결과 파일은 프로젝트 내부 상대 링크로 연결한다.
- 제작 도구의 임시 출력 경로만 남기지 말고 최종 PNG와 .meta가 프로젝트에 있는지 확인한다.
