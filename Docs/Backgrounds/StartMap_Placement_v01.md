# 시작맵 성 배치 검토 v01

2026-09-22. 사용자 요청: 컨셉을 수시로 확인하고 배치를 점검하며 진행.

## 검토 자료

- [조절 가능한 비교 화면](StartMap_Placement_v01.html): 로컬 파일로 열 수 있으며, 모든 이미지 경로는 프로젝트 내부 상대 경로다.
- [비교 화면 PNG](StartMap_Placement_v01.png): 브라우저에서 실제 렌더링한 화면 캡처다.
- [컨셉 원본](../../Assets/04.Sprites/Bg_Concept.png), [원경 v02](../../Assets/04.Sprites/Backgrounds/StartMap/BG_Start_Far_v02.png), [성·다리·절벽 v01](../../Assets/04.Sprites/Backgrounds/StartMap/BG_Start_CastleBridge_v01.png).

PNG를 생성형 도구로 재해석하지 않고 HTML의 이미지 레이어로 그대로 겹쳐 배치를 검토했다. 원본 에셋·Unity 씬은 수정하지 않았다. 전체 컨셉의 왼쪽 위 640×480 영역을 임시 비교 창으로 사용했으며, 확정된 맵 경계나 카메라 범위가 아니다.

## 배치 후보와 결과

- 원경 전체 1448×1086 기준 성 이미지 캔버스 너비 42%, 좌상단 (24.1%, 11.9%). 약 608×456px, 좌상단 (349,129)px. 수치는 투명 여백을 포함한 전체 PNG 기준이다.
- 성의 높은 탑이 달 오른쪽에 있고, 다리는 왼쪽으로 뻗도록 배치했다. 주요 상대 위치가 원본 시작 구역과 가까운 후보임을 시각 확인했다.
- PPU가 둘 다 100이고 원경 Scale=1, 두 Sprite의 Pivot이 중앙이며 회전·부모 변환이 없다는 조건에서만 성 Scale=0.42, 원경 중심에 대한 상대 위치 (-0.70952,1.85706)유닛에 대응한다. Unity에는 적용하지 않았다. 최종 Scale을 확정한 것이 아니다.
- 성 소재의 탑이 원본보다 많고 받침 절벽 폭이 넓다. 특히 눈 덮인 가장자리가 밝아 원본의 안개 낀 원경보다 앞으로 나와 보인다. 성이 원본과 완전히 일치한다고 평가하지 않는다.
- 원경의 산 능선 구도도 원본과 달라 위치 이동만으로 완전히 맞출 수 없다. 원본 대비 시선을 끄는 설산 윤곽도 추후 숲과 함께 점검한다.
- 절벽 하단의 알파 전환은 배경 위에서 보이나, 숲이 아직 없어 받침이 분리되어 떠 보일 수 있다. 원본처럼 중경 숲과 안개로 하단·다리 기둥 일부를 겹쳐 가리는 검토가 필요하다. 가이드는 그림이 아닌 위치 표시다.

## 이후 제작 기준

뒤에서 앞으로: 원경 v02 → 성·다리·절벽 → 중경 숲·독립 안개 → 근경 고목 → 플레이 지형·별도 눈 덮개.

새 소재 제작 전 컨셉 내 위치·크기·겹침을 확인하고, 제작 후 기존 소재와 겹쳐 비교한다. 다음 소재 제작은 별도 사용자 지시 범위에서 진행한다. 중경 숲이 생기면 성 윤곽의 밝기·다리 가시성·절벽 폭을 다시 평가하고 필요하면 수정한다.

현재 확인한 것은 두 레이어의 브라우저 합성 시안이다. 이웃 구간 접합, 숲 포함 합성, Unity 카메라·캐릭터 대비 크기, 실제 플레이 화질, 사용자 최종 승인은 미확인이다.
