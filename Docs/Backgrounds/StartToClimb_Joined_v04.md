# 바닥만 연결하는 수정 v04

사용자 피드백: v03은 부자연스러우므로 이전 버전에 연결 바닥만 따로 적용. 이전 버전은 부드러운 연결 구도 v02로 해석했다.

[검토본](StartToClimb_Joined_v04.html) · [접합 화면](StartToClimb_Joined_v04_Seam.png) · [배치 데이터](StartToClimb_Joined_v04.json).

v02의 입구·뒤벽·눈 구도를 복원하고 기존 독립 PNG BG_Climb_JoinGround_v01만 사용했다. 새 이미지 생성 없음. 추가 암벽2개와 눈 끝은 최신 배치에서 제외하고 파일은 보존한다.

바닥 좌상단 X1160,Y1410,너비380,종횡비 유지,밝기0.75. v03보다 작게 놓아 접합에 필요한 부분만 덮었다. 캐릭터 뒤에 표시. PNG와 .meta는 Assets/04.Sprites/Backgrounds/ClimbMap에 있다.

접합 화면을 실제 확인. 큰 기둥처럼 보이던 추가 암벽이 없어져 통로 시야가 열렸다. 연결 바닥은 독립 조절 가능. 최종 사용자 확인 전이다.

v02의 배경·지면 마스크를 유지했으므로 전체 구도가 Unity 단순 PNG 조립만으로 재현된 상태는 아니다. Unity 씬·코드 변경 없음. 이전 JoinKit 문서의 암벽 배치표는 현재 적용 기준에서 제외한다.
