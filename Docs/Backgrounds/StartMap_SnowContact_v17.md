# 발 크기 기준 눈 흔적 검토 v17

2026-09-23. 사용자 요구: 실제 캐릭터 발 크기에 맞춰 작은 단위로 촘촘하게 눈이 사라져야 한다. [검토 화면](StartMap_Placement_v17.html)과 [이미지](StartMap_Placement_v17.png)를 작성했다. 신규 스프라이트 생성이나 게임 코드 수정은 없다.

## 크기 기준

기존 Run_00 실제 이미지를 열고 오른발 접지 부근 x240~330,y395~410에서 alpha≥128인 픽셀의 가로 범위를 측정했다. x265~309, 폭45px다. 이는 한 프레임의 보이는 발 끝 표본이며 실제 접촉 판정이나 모든 프레임의 발 크기가 아니다.

기존 그림 높이336px → 컨셉 비교높이26px 비율을 적용하면 발 폭45×26/336≈3.48px/640px 화면이다. 기본 제거 폭은 이 값, 중심 간격은 폭의1.25배≈4.35px로 비교한다. 둘 모두 조절 가능하며 최종 게임 수치나 실제 걸음 간격으로 확정하지 않는다.

## 검토 변경

v16의 넓은 구간 마스크를 작은 타원 접촉 후보들의 SVG 표시 마스크로 교체했다. 처음 세로 띠로 시험했을 때 빗살처럼 보여 얕은 타원으로 수정했다. 눈만 부분적으로 가리고 바위는 유지한다. 타원 중심은 눈 표면 부근에 임시 배치했으며 실제 지면 높이를 추적하지 않는다. 제거 깊이는 최종 접촉과 별도 검토가 필요하다.

밟기 전·잔설·눈 제거 표시와 폭 변경을 확인했다. 표면 확대에서 작은 자국을 확인했고, 전체 화면에서는 변화가 미세하게 보인다. 현재 일정 간격 반복이라 실제 발 디딤의 자연스러움을 보장하지 않는다. PNG는 수정하지 않았다.

HTML은 아트 비교 자료다. Unity 마스크·발 접촉 감지·이동 보간·애니메이션 동기화·누적 흔적·저장·콜라이더는 구현하지 않았다. 실제 구현 시 캐릭터 발과 카메라 크기를 기준으로 촘촘함을 재검토한다. 기존 잔설 덩어리 간격은 제거 단위로 사용하지 않는다.
