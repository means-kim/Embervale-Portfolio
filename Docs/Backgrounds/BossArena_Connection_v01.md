# 등반 출구 → 통로 → 보스전 구역 v01

사용자 지시 범위인 보스전 구역 연결까지 진행한 실내 아트 초안. [검토 화면](BossArena_Connection_v01.html), [추가 배치 데이터](BossArena_Connection_v01.json), [기존 통로 데이터](BossCorridor_Prototype_v01.json), [생성 프롬프트](BossArena_Connection_v01_Prompts.md).

## 결과와 확인

- 실내 후면 암벽과 독립 긴 바닥 추가. 하늘·설산·성소 없음.
- 통로 천장에서 전투 공간으로 올라가는 천장 실루엣. 전투 공간은 카메라보다 넓으며 줌아웃 없음.
- 진입·중앙·오른쪽 16:9 화면 확인, 이미지30개 정상 로드. 진입 바닥 약15 배치 단위 차이를 보정. 바닥 표면의 작은 요철과 재질 경계는 남음.
- 원본 컨셉의 청흑색과 암석 질감을 따르되, 내부 전투 공간 구도는 신규 제안이다. 컨셉에 나온 외부 풍경을 복제한 것이 아님.
- 카메라1000×562.5, 캐릭터 이미지77.14286, 실제 보이는 높이 약9%. 위치별 접지 높이는 비교용 추정값. 실제 걷기 구현이 아님.

## 조립 기준

데이터는 HTML 단위이며 Unity 월드 크기 확정값이 아니다. 기존 통로 배치 위에 아래를 추가한다. 전체 개요에서 모든 로컬Y에300을 더한다. 실제 카메라는 로컬Y0, 폭1000, 높이562.5를 유지한다.

- 새 뒤벽 x2000,y-300,width1950,brightness0.7.
- 기존 통로 뒤벽 폭1600으로 확장, 오른쪽22%를 임시 마스크로 겹침.
- 새 바닥 x2100,y224.2965,width1900,brightness0.85. 알파128이상 상단 샘플202/2172로 표면Y401 근사.
- 전이 천장 x2100,y-330,width1000,brightness0.8. 기존 천장과 겹침.
- 전투 공간 후보 x2200..3950, 폭1750=카메라폭1.75배. 오른쪽 후속 출구는 아직 설계하지 않음.

HTML 밝기·그라디언트는 PNG에 구워져 있지 않다. Unity에서는 동등한 색상 조정 및 마스크/소재 접합 검토가 필요하다. 알파 경계의 색 번짐, 패럴랙스 여유 및 실제 이동은 Unity에서 확인해야 한다.

## 피드백이 필요한 판단

통로에서 넓어지는 정도와 전투 공간의 잠정 폭. 보스 크기·공격 패턴을 모르는 상태여서 최종 전투 면적으로 확정하지 않는다. 보스·전투 문·낙하 통로·전투 기능은 미포함. Unity 씬/코드 미변경.
