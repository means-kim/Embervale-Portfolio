- 색과 내부 표면의 가는 명암으로 가장자리를 정리했다. 사용자 요청에 따라 외부 알파 윤곽 자체를 새로 깎거나 넓히지 않았다. 따라서 원본 윤곽/입자 모양의 픽셀 계단은 유지된다.

제작 및 보존 방법
- 미술 생성/편집: built-in image_gen, transparent_background=true. 정확한 프롬프트는 GenerationPrompt.txt.
- 편집 대상: ../../../../Assets/04.Sprites/AirBossAttack/Attack_Icicle_Fall_Loop_4x3_v01.png
- 화풍 참조: ../../../../Assets/04.Sprites/AirBoss/AirBoss_Cast_BothArms_IcePush_Part1_4x4_1024_v01.png
- Generated_Style_Source.png는 도구 원출력 1448x1086 RGBA. 원출력에는 원본 대비 위치/알파 차이가 있었으므로 그대로 에셋화하지 않았다.
- RegisterGeometry.cs.txt: 생성된 표면을 원본 끝/어깨 위치에 등록하고, 투명 영역의 경계색을 확장한 뒤 원본의 알파 채널을 픽셀 단위 그대로 복제했다. 창작 질감을 코드로 대체한 것이 아니라, 생성된 그림을 사용자 지정 윤곽에 맞춰 등록한 후처리다.
- Registered_Sheet.png가 Assets PNG와 같은 최종 이미지다. 원본과 모든 픽셀의 alpha가 동일하므로 외곽 범위·여백·실루엣·효과 위치가 유지된다.
- 원본 PNG/meta/clip/meta/컨트롤러/프리팹은 SHA256 비교로 변경 없음 확인.

실제 사양
- 1448x1086 RGBA, 4열 x 3행, 12개 362x362 셀.
- 원본과 동일한 12개 rect/custom pivot, PPU400, Point, mipmap off, sRGB on, Clamp, 무압축, max2048.
- 피봇은 중심이 아닌 원본의 각 고드름 아래 끝점 부근 값을 그대로 사용.
- 클립 12FPS / 1초 / Loop Time on. 12개 Sprite 키 시간과 순서, 빈 경로 SpriteRenderer.m_Sprite 바인딩 동일.
- Transform/알파/색 곡선과 Animation Event 없음. 실제 낙하 이동은 포함하지 않는다.
