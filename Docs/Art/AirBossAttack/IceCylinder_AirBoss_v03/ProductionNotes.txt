- built-in image_gen으로 24프레임 전체 생성 후 같은 도구로 배치/상승 보완을 요청했다. 정확한 두 프롬프트: GenerationPrompts.txt.

- RGBA 알파를 사용해 투명 여백 유지. 원시 PNG의 알파0 RGB에 남은 배경색은 불투명 배경이 아니다. 실제 표시 확인은 PreviewFrames의 Unity 렌더로 수행했다.

실제 임포트 사양
- 6열 x4행, 전 셀256x256. 좌상단부터 오른쪽, 다음 행 순서.
- 전 프레임 center pivot(0.5,0.5). 셀 중심 기준이며 프레임마다 보이는 물체의 중심을 다시 계산하지 않는다.
- 셀 내 중심선 x128, 공통 바닥 기준은 위에서 y228. 고정 피봇에서 그림이 위로 솟아오른다.
- PPU256, Bilinear, Mipmap off, sRGB on, Clamp, Full Rect, 무압축, max2048.
- 프레임당1x1 월드 단위(Scale1), 실제 게임 크기는 사용자 Transform Scale에서 조절.

클립
- sampleRate24, 24개 스프라이트와 마지막 null키1개. 길이2.5416667초, Loop Time off.
- 01~08: 상승/정착 0~0.5초. 24FPS 눈금에서1~2틱씩 배분.
- 09~14: 완성된 원기둥의 서로 다른 반짝임 그림6개, 각각0.25초씩 총1.5초 유지.
- 15~24: 균열→분리→낙하 파편→작은 잔해, 2.0~2.5초.
- 2.5초: Sprite를 null로 지워 마지막 잔해가 계속 남지 않게 한다. 이후 마지막1틱은 빈 화면.
- 바인딩: 빈 경로 SpriteRenderer.m_Sprite. Animator와 SpriteRenderer가 같은 오브젝트에 있을 때 사용.
- Transform/색/알파 float curve와 이벤트 없음. 공격 판정·풀 반환 로직은 이 클립에 포함하지 않는다.
