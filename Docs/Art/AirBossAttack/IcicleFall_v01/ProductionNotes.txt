실제 사양
- 요청 캔버스 1536x1152, 실제 생성 PNG 1448x1086 RGBA. 리사이즈 없이 사용.
- 4열 x 3행, 총 12프레임. 셀 362x362. 좌상단부터 가로 방향 순서.
- Sprite Mode Multiple, PPU 400, Point 필터, Mipmap 끔, Clamp, 무압축, Max Size 2048.
- 생성 그림은 기존 96px VFX보다 픽셀 수가 많아 PPU400을 초기값으로 설정함.
- Scale1에서 셀은 0.905x0.905 월드 단위. 최종 공격 크기와 속도는 아직 결정하지 않음.
- 프레임마다 실제 단단한 끝 위치를 기준으로 custom pivot 정렬. 원점은 아래쪽 끝.
- 로컬 셀의 위쪽부터 측정한 단단한 끝 좌표: (181,342),(181,341),(181,342),(181,341),(180,343),(181,342),(180,342),(181,342),(181,343),(181,342),(181,342),(181,342).
- 반투명 냉기/빛은 피벗 정렬의 기준에서 제외함. 윤곽에는 작은 프레임별 변형이 있으며 픽셀 단위로 동일한 몸체는 아님.

클립

- 바인딩: 경로 빈 문자열, SpriteRenderer.m_Sprite. Animator와 SpriteRenderer가 같은 GameObject에 있을 때 사용.
- Transform, 크기, 색/알파 곡선 없음. 이벤트 없음.
- 생성/파괴/소멸 프레임 없이 완성된 고드름 형태를 계속 유지함.
