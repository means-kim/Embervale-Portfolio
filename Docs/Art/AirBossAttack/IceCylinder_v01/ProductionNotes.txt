요청 및 결과

- 최종 월드 크기와 위치는 사용자가 조절. 공격/차단 Collider 및 페이즈 로직은 이번 범위에 없음.

Import 및 배치
- RGBA 1448x1086. 4열x3행, 각 셀362x362.
- 좌상단부터 가로로 01~12 순서, Sprite Mode Multiple.
- PPU400, Point, Clamp, Mipmap Off, 무압축, MaxSize2048, FullRect.
- 12개 전부 SpriteAlignment.Center, 실제 피벗 픽셀 (181,181).
- 셀의 Scale1 월드 크기는0.905x0.905. 보이는 몸체는 셀보다 작음.
- 중심을 기준으로 높이를 키우면 아래쪽도 커짐. Scale 결정 후 부모 위치Y를 조정하여 접지선을 맞출 것.
- 그림의 작은 냉기/기저부 윤곽 변화가 있으며 픽셀 단위의 완전 고정 형태는 아님. 실제 배치 시 바닥과의 겹침 검토 필요.

클립 사양
- Rise: 프레임01~04,12FPS,0.333333초, 반복 끔.
- Hold: 프레임05~08,8FPS,0.5초, 반복 켬. 원하는 유지 시간은 외부 로직/전환에서 제어.
- Break: 프레임09~12,10FPS. 0.4초 시점에 Sprite=null 키 추가, 총0.5초, 반복 끔.
- Break의 마지막 null키는 별도 생성 스프라이트가 아니라 화면을 비우는 종료 처리.
- 바인딩은 경로빈문자열의 SpriteRenderer.m_Sprite. Animator와 SpriteRenderer가 같은 오브젝트에 있을 때 사용.
- Transform/Scale/알파 곡선 없음. 애니메이션 이벤트 없음. 파괴 후 시각만 사라지며 Collider 해제/풀 반환은 게임 로직에서 별도 처리.

검증
- Unity6000.3.22f1 격리 Preview Scene에서 각 클립의 모든 키를 샘플링하여 프레임01~12 순서와 피벗181,181 확인.
- Break 종단 sprite=null 확인. 모든 클립 floatCurves0 / events0 확인.
- 최종시트의 각 셀 가장자리4px에 alpha>128인 픽셀이 없음. 낮은 알파의 미세 냉기/광택은 존재.
- PreviewFrames/는 실제 Unity 렌더. Preview_Unity_Sequence.gif는 Rise + Hold3회(1.5초) + Break + 빈화면 검토본.
- GIF의 ms 단위는 일부 반올림됨. 실제 클립 타이밍은 위 값이 기준.
- 실제 게임 충돌·구역차단·플레이어 밀어내기·점프 차단은 미구현/미검증.
