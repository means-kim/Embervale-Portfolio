설계
- 기존 v03의 파란색/흰색 원통형 얼음 디자인과 단계 순서를 참조.
- 몸통 폭 약160px, 완성 높이 약780px. 기존 약80x195px와 비교해 PPU512에서 폭은 비슷하고 높이는 약2배.
- 512x1024 셀 x 6열4행 = 실제 PNG3072x4096 RGBA,24개 그림.
- 중심 (256,512), Center Pivot(0.5,0.5), PPU512, FullRect, Bilinear, Clamp, Mipmaps Off, 무압축, MaxSize4096.
- 프레임01~06 성장,07~14 유지,15~18 균열,19~24 파괴/파편/잔광.
- 바닥 몸통 기준선은 이미지 상단 기준 y888로 정렬. 중앙 피봇이므로 기존 프리팹 위치에 연결했을 때 접지 위치는 자동 유지되지 않음.
- 사용자 기존 Scale50을 가정하면 새 셀 월드크기는50x100. 기존 셀은50x50. 실제 몸통 폭/높이는 투명 여백을 제외하여 비교.
- 실제 게임의 Visual 위치와 Collider size/offset은 사용자가 적용 시 검토. 현재 프리팹은 변경하지 않음.

생성 및 후처리
- 내장 image_gen 사용. 기존 v03 시트와 높이2배 시안이 이미지 참조.
- 4프레임씩6회 생성. 요청 각1024x2048, 실제 각887x1774. 네이티브512x1024로 개별 생성된 프레임이 아님.
- GenerationSources에 생성 원본 보존, GenerationPrompts.txt에 실제 프롬프트 보존.
- PackFrames.cs는 생성된 프레임을 분리하고 폭/높이/접지 위치를 정렬한 뒤 정확한 셀에 배치하는 후처리.
- 일부 프레임은 크기 보정과 소폭 확대가 포함됨. 이미지 확대만으로 네이티브 세부 묘사가 추가된다고 주장하지 않음.
- 사라지는 파편은 비율을 유지하며 작아지도록 정렬. 완성 높이/폭과 바닥선 고정에도 얼음 무늬/밑동/광채의 프레임 간 변화는 남아 있음.
- FrameMetrics.csv는 실제 프레임 경계, 배율, 해시. 전체24개 파일 해시가 서로 다름.
