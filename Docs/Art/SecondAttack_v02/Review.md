# SecondAttack v02 — 위로 휘두르는 불꽃 주먹 확인본

2026-10-13 제작, 2026-10-14 적용 확인. SecondAttack 시안 확인 후 사용자가 First·Third 제작을 승인했으며, 현재 SecondAttack도 주 플레이어와 Hyunseo용 클립에 적용되어 있다. [최신 통합 제작·적용 기록](../MeleeAttack_v02/Review.md)을 따른다. 아래 제작 수치와 이미지는 최초 확인본과 동일하다.

- [0.25배속 미리보기](Preview.gif), [16프레임 비교](Contact.png)
- [최종 PNG와 시트](../../../Assets/04.Sprites/NewPlayer/SecondAttack_v02)
- 16개 고유 프레임, 512×512 RGBA, PPU 200. Bilinear, 무압축, mipmap 없음, torso pivot `(270,226)`.
- 동작: 낮게 준비 → 앞쪽으로 휘두르기 → 머리 위까지 올리기 → 머리 위를 지나 후속 동작 → 회수.
- 검은 팔과 주먹을 보여주고, 불꽃은 주먹 주위의 작은 덩어리로 유지했다. 긴 불꽃 칼날은 사용하지 않았다.
- 얼굴이 팔에 가려진 프레임에서 가려진 면적만으로 캐릭터를 확대하지 않도록, 시트 전체에 고정 배율을 사용했다. 양발 바닥 중심으로 정렬했고 모든 프레임의 불꽃과 손이 512 캔버스 안에 들어가는 것을 확인했다.
- 주 플레이어의 기존 1.25초 클립 / state speed 5를 유지해 적용했다. 현재 게임 기준 0.25초 동작을 0.25배속 GIF에서 1초로 보여준다. GIF는 동작 후 0.5초 대기한다.

## 제작과 확인

내장 image_gen으로 [더미 자세표](PoseGuide.png)와 승인된 캐릭터 기준을 참조해 제작했다. [프롬프트](Prompt.txt)와 [생성 원화](Generated.png)를 보존했다. 생성 원화 실제 크기는 **1307×1203**이며, 최종 프레임은 분리·정렬·크기 보정한 결과다.

[명세](Manifest.json)에 각 프레임 파일·해시·피벗·소스 범위를 기록했다. [Unity Import 확인](ImportVerification.json)은 최초 16개 스프라이트의 512 규격과 PPU 200 확인 기록이다. 이후 클립 연결과 Play 검증은 [통합 검증 기록](../MeleeAttack_v02/Review.md)에 별도로 기록했다.

이 시안에서는 같은 공격 팔의 연결과 주먹 불꽃이 유지되어 부분 재생성이 필요하지 않았다. 사용자 승인 후 같은 이미지를 유지해 적용했다.
