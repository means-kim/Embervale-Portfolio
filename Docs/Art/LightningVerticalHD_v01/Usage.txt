실제 사양
각 최종 PNG: 4096×2048 RGBA, 16열×1행. 셀 256×2048. 총32개.
기존 셀384×768 대비 세로 픽셀수2.667배. 가로는 세로 전용 비율에 맞춘256px이며, 양방향 해상도가 모두 증가했다는 의미는 아님.
내장 image_gen 도구로 기존 원본을 참조해 768×2048(4프레임) 이미지8장 생성.
원본의 단순 확대가 아니라 흰 번개 필라멘트와 청보라 발광을 다시 묘사했다.
생성 소스 Generated/group01.png~group08.png 보존.
Windows System.Drawing으로 프레임 분리/크기·위치 정렬/두 아틀라스 조립. 생성된 알파 보존, 완전투명 픽셀의 숨은RGB만0으로 정리.
초기16열 직접생성 후보는1254×1254로 해상도와 여백이 부족해 사용하지 않음. prompt-part1.txt는 그 미채택 시도의 기록이다.
실제 채택 프롬프트: prompt-group01.txt~prompt-group08.txt. 해당 세트는 이 문서 뒤에도 수록한다.

Unity Import
Sprite Multiple / 각16분할 / Center pivot / Full Rect.
PPU=682.6667 (2048÷3). Bilinear / Clamp / Mipmap OFF.
Max Size4096 / RGBA32 / 비압축. 실제 Unity 로딩4096×2048 확인.
텍스처2장 GPU 픽셀 데이터 합계약64MiB(밉맵없음, 추가메모리별도). PNG파일크기와 런타임메모리는 다르다.

재생
12FPS, 32스프라이트 키, 클립2.666667초, Loop OFF.
전용 컨트롤러 기본상태 SmallLightningVerticalHD, speed1.3 → Animator speed1/시간배율1이면 약2.051초.
기존 이벤트 그대로:
0.083333초 EnableHitBox
2.333333초 DisableHitBox
2.666667초 Release

적용
기존 세로 Attack_SmallLightning 프리팹의 구조와 루트 Scale(10,100,1)을 기준으로 제작.
보존용으로 기존 프리팹을 복제한 뒤 복제본의 Visual > Animator > Controller에 새 전용 컨트롤러를 지정하면 된다.
새 클립에 Visual localScale=(10,1,1) 고정곡선이 포함돼 있다. 기존 루트 Scale과 합쳐 XY가(100,100)이 되어 새 세로 아트를 균등 확대한다.
원본과 같은 중심/보이는 길이에 맞춰 아틀라스 안의 그림을 정렬했다. 여백을 포함한 셀의 가로 월드크기는 원본과 같지 않지만 보이는 그림 폭을 기준으로 조정했다.
Visual에 다시 Scale10을 중복해서 곱하거나 루트를 임의로100,100으로 바꾸지 않는다. 루트스케일이 다른 경우 사용자가 원하는 월드길이에 맞춰 별도조정해야 한다.
가로 번개는 기존 컨트롤러와 클립을 계속 사용한다. 이 클립은 가로 프리팹용이 아니다.
기존 AirBossAttackAnimationEvent와 부모 AirBossAttack/Collider가 있어야 기존 이벤트가 동작한다.
새 에셋 생성만 완료했으며 기존 프리팹, 씬, 풀 참조에는 자동 적용하지 않았다.

검증
Unity6000.3.22f1에서 실제 임포트크기,32슬라이스,32키,누락참조0,정렬00~31 확인.
독립 PreviewRenderUtility 환경의 Animator로32/32프레임을 각각샘플링하여 스프라이트와 Visual Scale 확인.
대표00,07,15,16,23,28,31 Unity 렌더 확인: Unity/frameNN.png.
alpha>=32 기준 기존/새 프레임 가시높이 차이최대0.8821%. 완전투명 프레임테두리32/32 확인.
pixel-validation.csv에 프레임별 가시폭/높이와 계산 기록. 가지 모양과 발광 분포가 새로 그려졌으므로 폭/명도는 원본과 완전히 같지 않다.
comparison.png는 동일월드비율에서 원본/신규를 비교한 이미지.
기존PNG/meta,기존클립/meta,기존컨트롤러,기존세로/가로프리팹 SHA256 보존 확인: original-hashes.json.
이벤트 이름과시간 비교를 검증했으며 독립미리보기에서는 fireEvents=false로 실제공격행동을 실행하지 않았다.
실제 게임 Play 모드에서의 공격/피격/풀복귀와 다양한 카메라해상도 검증은 별도.
일반 AnimationClip.SampleAnimation은 이 미리보기에서 Sprite 오브젝트참조를 적용하지 못해, 실제 Animator.Play/Update 샘플링으로 검사했다. 클립자체의참조누락이아님.
새 텍스처 분할은 Unity에서 유효하게 생성됐지만, 재현용 unity-import.cs.txt의 TextureImporter.spritesheet API는6000.3에서obsolete경고가있다. 향후 도구유지보수에는SpriteEditorDataProvider 권장.

pack-sheets.ps1은 Windows PowerShell5.1용. 출력충돌시중단하여 기존파일을덮어쓰지않는다.
생성입력과프롬프트,정렬코드,Unity등록/검증코드는이폴더에보존했다.
