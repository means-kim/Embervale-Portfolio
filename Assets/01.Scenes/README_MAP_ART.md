# 현재 맵 아트 작업과 씬

사용자가 Unity 씬의 배치를 직접 담당한다. 현재 Codex의 역할은 맵 소재 제작과 검토 보조이며, 새 씬 생성이나 기존 씬 재배치를 포함하지 않는다.

## 현재 상태

2026-09-22 확인 시 이 폴더에는 HyunseoScene.unity와 SampleScene.unity가 있다. 이 파일들은 현재 맵 아트 작업에서 임의로 수정하지 않는다.

이전에 Codex가 만든 FrostboundLayout.unity와 FrostboundBackgrounds_v2.unity는 사용자가 삭제했다. 이전 구도와 배치에 문제가 있어 다시 시작한 것이므로 해당 씬을 복원하거나 과거의 좌표·크기를 새 기준으로 사용하지 않는다.

## 아직 확정되지 않은 항목

- 전체 맵의 월드 가로·세로 크기.
- 실제 카메라 표시 범위와 Orthographic Size.
- 배경 소재의 배치 위치, Transform Scale, 패럴랙스 및 조명 설정.

기존 대화의 카메라 수치는 비교용 후보였으며 현재 씬의 확정 설정으로 기록하지 않는다. 이번 문서 작업에서 씬을 변경하지 않았다.
