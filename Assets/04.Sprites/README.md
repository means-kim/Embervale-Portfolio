# 맵 스프라이트 안내

현재 맵 아트 작업의 기준 이미지와 새로 제작한 배경을 보관한다. Unity의 실제 폴더명은 04.Sprites다.

## 공통 참조

[Bg_Concept.png](Bg_Concept.png)는 사용자가 직접 넣은 맵 컨셉 아트다. 제작 전에 반드시 이미지를 열어 확인하고, 생성 도구에 실제 참조 이미지로 전달한다. 삭제하거나 교체하지 않는다.

이미지에 표현된 모든 요소가 제작 대상은 아니다. 하부 성소와 귀환 리프트는 제외되었다. 게임 코딩 및 씬 배치는 현재 Codex 담당 범위가 아니다.

## 현재 맵 이미지

| 파일 | 용도 | 상태 |
|---|---|---|
| [Bg_Concept.png](Bg_Concept.png) | 전체 맵의 화풍·색감·위치 관계 기준 | 사용자 지정 참조 |
| [BG_Start_Far_v01.png](Backgrounds/StartMap/BG_Start_Far_v01.png) | 시작맵 하늘·달·구름·먼 설산·안개 | 1차 제작본, 사용자 확인 전 |

이 목록은 이번 맵 배경 작업 기준이다. 플레이어 애니메이션은 05.Animation 폴더에서 별도로 관리된다.

## 삭제된 이전 작업

이전 Environment/Frostbound 폴더, LayerSources_v2의 12종 소재, FrostboundLayout 및 FrostboundBackgrounds_v2 씬과 관련 DATA는 사용자가 삭제했다. 과거 파일 목록을 현재 보유 소재로 보고하지 말고, 새 작업에 임의로 복원하지 않는다.

## 파일 저장 기준

- 새 배경은 Backgrounds 아래 구역별 폴더에 저장한다.
- PNG와 대응 .meta를 함께 보존한다.
- 기존 결과물은 새 버전과 구분한다. 사용자의 교체 요청이 없으면 승인된 소재를 덮어쓰지 않는다.
- 실제 픽셀 크기, PPU, Scale 1에서의 크기, 포함된 레이어, 확인 상태를 해당 폴더 README에 기록한다.
- 캐릭터 PPU 200과 배경 v01의 PPU 100을 혼동하지 않는다. 배경 설정을 캐릭터에 일괄 적용하지 않는다.
- 전체 맵용 해상도와 각 소재의 최종 배치 Scale은 아직 확정되지 않았다.
