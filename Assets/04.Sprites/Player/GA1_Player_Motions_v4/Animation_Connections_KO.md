# 기존 플레이어 컨트롤러에 모션 연결하기

이 팩은 스프라이트 애니메이션입니다. 이동·중력·더블 점프 횟수·대시 속도·벽 판정·무적 시간·피격 넉백은 기존 게임 코드가 결정합니다. 물리 상태를 읽어 애니메이션을 선택하고, 애니메이션의 보기 좋은 프레임 때문에 물리 반응을 늦추지 않는 것이 기본 원칙입니다.

## 필요한 상태 정보

| 게임 정보 | 애니메이션에서 사용하는 곳 |
|---|---|
| 접지 여부, 이전 프레임의 접지 여부 | Idle/Run 선택, 착지 순간 Land 진입 |
| 수평 속력의 절댓값 | Idle/Run 전환, 필요하면 Run 재생 속도 조정 |
| 수직 속도 | JumpRise / JumpApex / Fall |
| 점프·더블 점프 시작 신호 | JumpStart / DoubleJump를 0초부터 1회 시작 |
| 대시 시작 및 남은 시간 | DashStart / DashLoop / DashEnd |
| 공격 시작, 공격 종료·취소 | Attack 및 판정 활성 구간 |
| 벽 접촉 방향, 벽 오르기 입력, 벽 미끄러짐 상태 | WallCling / WallClimb / WallSlide |
| 벽 점프 시작 신호 | WallJump |
| 피격 시작, 피격 제어 제한 종료 | Hurt |

## 분기 기준

1. **착지와 피격·행동 취소를 먼저 처리합니다.** 공중 동작이 재생 중이어도 충돌·피격 등 실제 게임 상태가 바뀌면 적절한 상태로 전환합니다.
2. 공격·대시·더블 점프 등 일회성 동작에는 상태 유지/종료 조건을 둡니다. 일반적인 Run/Fall 선택 로직이 다음 Update에서 이 동작을 즉시 덮어쓰지 않게 합니다.
3. 행동이 끝나면 현재 물리 상태를 다시 평가합니다. 벽 상태면 해당 벽 클립, 공중이면 상승/낙하, 바닥이면 Run/Idle을 선택합니다.
4. Hurt가 Attack을 끊으면 타격 판정을 끄고, 대시를 끊으면 대시 이동도 게임 규칙에 맞춰 종료합니다. 애니메이션만 바뀌고 이전 행동의 판정이나 속도가 남지 않게 합니다.

## 점프와 더블 점프

- 점프 입력 시 물리 점프를 즉시 시작하며 JumpStart를 재생합니다. 애니메이션 종료를 기다린 뒤 점프 임펄스를 주면 입력 지연이 생깁니다.
- JumpStart가 끝나면 수직 속도에 맞춰 JumpRise/JumpApex/Fall을 선택합니다. 도중에 천장에 부딪히거나 착지하면 해당 물리 상태가 우선합니다.
- JumpApex는 정점을 강조하는 짧은 클립입니다. 수직 속도의 작은 구간에서 선택하고, 하강이 시작되면 Fall로 나갑니다. 짧은 점프에서는 생략해도 됩니다.
- 공중에서 더블 점프가 승인되면 위쪽 속도를 갱신하고 DoubleJump를 0초부터 재생합니다. 0.444초가 끝나면 현재 수직 속도로 다음 상태를 선택합니다. 바닥이나 벽에 먼저 닿으면 접촉 상태로 전환할 수 있어야 합니다.
- Land 중 다시 점프하거나 달리기 시작하면 입력을 우선할 수 있게 합니다. 클립 전체 0.133초를 반드시 기다리도록 고정할 필요는 없습니다.

## 대시

예를 들어 게임의 대시 이동 시간이 0.20초라면 DashStart 0.05초 뒤 DashLoop를 남은 이동 시간 동안 재생합니다. DashLoop의 0.20초는 반복 그림의 길이이며, 실제 대시를 반드시 0.20초로 만들라는 의미는 아닙니다. 이동이 끝나면 DashEnd로 회복하되, 공중에서는 실제 상승/하강 상태로 빠르게 연결할 수 있습니다.

## 벽과 방향

원화는 오른쪽 벽을 기준으로 만들었습니다. 오른쪽 벽에서는 flipX=false, 왼쪽 벽에서는 flipX=true로 같은 포즈를 사용할 수 있습니다. WallJump는 벽을 보는 얼굴을 유지한 채 몸이 벽에서 떨어지는 연출입니다. 수평 속도가 벽 반대 방향으로 바뀌었다는 이유만으로 즉시 flipX를 바꾸면 포즈가 뒤집힙니다. WallJump가 끝나 일반 공중 상태로 돌아갈 때 이동 방향을 적용하세요.

SpriteRenderer.flipX는 그림에만 작용합니다. 자식 히트박스의 위치나 물리 충돌체가 자동으로 반전되는 것은 아니므로 공격 판정의 방향은 게임 코드에서 함께 처리합니다.

## Animator 설정

- State 이름은 README 표의 이름과 맞추면 미리보기 및 코드 예시와 대응하기 쉽습니다.
- 루프 여부는 생성된 클립에 설정되어 있습니다. 유지 상태에서 Loop를 추가로 켜거나 끌 필요가 없습니다.
- 각 클립이 SpriteRenderer에 바인딩된 경로는 반드시 같아야 합니다. Animator와 SpriteRenderer가 같은 객체라면 경로는 빈 문자열입니다.
- 우선 Transition Duration 0으로 설정합니다. Sprite가 바뀌는 곡선은 CrossFade로 중간 그림을 합성하지 않습니다.
- 상승/낙하/착지/벽 접촉처럼 물리 정보로 즉시 바뀌어야 하는 전환에 Has Exit Time을 강제로 걸지 않습니다.
- 일회성 동작을 재생하는 동안에는 게임 상태와 취소 규칙을 우선하고, 끝났을 때는 속도/접지 조건을 다시 평가합니다.
- Rigidbody2D와 Collider2D는 안정적인 공통 크기를 유지합니다. 이 클립들은 해당 컴포넌트를 애니메이션하지 않습니다.

## 연결 후 확인할 항목

Idle → Run → Idle에서 접지선과 머리 크기가 튀는지, 낮은 점프·높은 점프 모두에서 상승/하강 그림이 물리 상태와 맞는지, 더블 점프가 착지 직전에도 상태를 덮어쓰지 않는지 확인합니다. 왼쪽을 보고 벽 점프·공격할 때는 그림과 판정 방향이 함께 맞아야 합니다. 공격 취소 후 판정이 남는지와 Hurt 종료 시 제어가 올바르게 돌아오는지도 확인합니다.
