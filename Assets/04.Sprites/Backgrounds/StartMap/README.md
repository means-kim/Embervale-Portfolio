### 원경 구조물: 성·다리·받침 절벽 v01

[BG_Start_CastleBridge_v01.png](BG_Start_CastleBridge_v01.png), [제작 프롬프트와 기록](../../../../Docs/Backgrounds/StartMap_CastleBridge_v01.md).

- 실제 PNG: 1448×1086, RGBA, 투명 배경. 모서리와 다리 아치 내부의 alpha 0 확인.
- 포함: 성·왼쪽 아치 다리·설경 받침 절벽·하단 옅은 안개 표현. 하늘·달·숲·캐릭터·성소는 제외.
- PPU 100, Scale 1 캔버스 크기 14.48×10.86유닛(투명 여백 포함). 최종 배치 Scale 미정.
- Import: Sprite Single, Full Rect, 중앙 Pivot, Trilinear, Mip Maps On, None 압축, Max Size 2048, Clamp, Alpha Is Transparency On, 자동 Physics Shape Off.
- 연결 대상: 원경 v02 위, 추후 중경 숲 뒤. 사용자 확인 및 합성·실제 플레이 크기 검증 전. Unity 씬 배치 없음.

## 제작과 검토

- [Bg_Concept](../../Bg_Concept.png)의 왼쪽 시작 구역을 실제 이미지 참조로 사용했다.
- 첫 결과에 섞인 침엽수 실루엣을 제거하고 주요 달·구름·설산 구도를 유지했다.
- 전체 맵용 최종 원경이 아니라 시작맵의 1차 소재다.
- 실제 표시 크기에서의 선명도, 다른 레이어와의 합성, 등반맵과의 연결은 아직 검증되지 않았다.
- 승인된 아트로 간주하기 전에 사용자 피드백을 확인한다.

## 다음 소재와 연결

- 오른쪽은 등반 구간 배경으로 이어질 예정이다. 같은 능선·구름·안개 높이를 연결하고 비교한다.
- 수평 반복용 타일로 검증된 파일이 아니다.
- 구간이 이어질 때 달을 중복해서 넣지 않는다.
- 다음 순서의 후보는 별도 성·다리·절벽이며, 이 폴더의 그림에 임의로 합치지 않는다.
- 이후 숲·고목·지형·눈 소재를 각각 분리 제작한다.
