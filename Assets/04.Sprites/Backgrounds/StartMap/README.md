# 시작맵 배경

## 현재 결과물

[BG_Start_Far_v01.png](BG_Start_Far_v01.png)

| 항목 | 현재 상태 |
|---|---|
| 용도 | 시작맵 가장 뒤의 풍경 |
| 포함 | 하늘·달 하나·구름·먼 설산·안개 |
| 제외 | 성·다리·숲·고목·지형·발판·성소·캐릭터 |
| 실제 PNG | 1448×1086, RGB 불투명, 4:3 |
| PPU | 100 |
| Scale 1 크기 | 14.48×10.86 Unity 유닛 |
| Import | Sprite Single, Full Rect, Pivot 중앙 |
| 필터·밉맵 | Trilinear, On |
| 압축·Max Size | None, 2048 |
| Wrap·Physics Shape | Clamp, 자동 물리 모양 생성 안 함 |
| 사용자 확인 | 아직 확인 전 |
| Unity 씬 배치 | Codex가 배치하지 않음 |

3072×2304로 생성 요청했지만 도구의 실제 출력은 1448×1086이었다. 네이티브 4K가 아니며 확대 처리를 하지 않았다. .meta는 Unity Import 설정이므로 PNG와 함께 보존한다.

## 제작과 검토

- [Bg_Concept](../../Bg_Concept.png)의 왼쪽 시작 구역을 실제 이미지 참조로 사용했다.
- 첫 결과에 섞인 침엽수 실루엣을 제거하고 주요 달·구름·설산 구도를 유지했다.
- 전체 맵용 최종 원경이 아니라 시작맵의 1차 소재다.
- 실제 표시 크기에서의 선명도, 다른 레이어와의 합성, 등반맵과의 연결은 아직 검증되지 않았다.
- 승인된 아트로 간주하기 전에 사용자 피드백을 확인한다.

## 다음 소재와 연결

- 오른쪽은 등반 구간 배경으로 이어질 예정이다. 같은 능선·구름·안개 높이를 연결하고 비교한다.
- 수평 반복용 타일로 검증된 파일이 아니다.
- 구간이 이어질 때 달을 중복해서 넣지 않는다.
- 다음 순서의 후보는 별도 성·다리·절벽이며, 이 폴더의 그림에 임의로 합치지 않는다.
- 이후 숲·고목·지형·눈 소재를 각각 분리 제작한다.
