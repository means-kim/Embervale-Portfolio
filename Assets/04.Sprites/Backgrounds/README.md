# 배경 제작 공통 기준

기준 아트: [Bg_Concept.png](../Bg_Concept.png). 전체 진행 상태: [Docs/README.md](../../../Docs/README.md).

## 목표와 역할

시작맵부터 하부 보스전까지 이어지는 하나의 세계를 원경·중경·근경으로 나누어 제작한다. 사용자가 Unity에 직접 하나씩 배치한다. Codex는 소재 제작과 일관성 검토를 보조한다.

구간을 나누더라도 전체 배경의 위치 관계와 색감은 이어져야 한다. 전체 구도용 이미지와 실제 게임에서 충분한 해상도가 필요한 소재를 구분한다.

## 일관성을 유지하는 제작 순서

1. Bg_Concept와 해당 구역의 기존 파일, 사용자 피드백을 확인한다.
2. 이번 소재가 포함할 것과 별도로 만들 것을 정한다.
3. Bg_Concept와 사용자 확인을 받은 기존 소재를 실제 이미지 참조로 전달한다.
4. 연결 부위의 능선, 구름, 안개 높이와 밝기를 맞춘다. 인접 구간의 겹침 영역을 두고 비교한다.
5. 개별 이미지와 이웃 구간의 연결을 확인하고, 여러 레이어가 생기면 겹쳐 확인한다.
6. 실제 표시 범위에서 화질을 확인한다. 아직 카메라 범위가 없으면 그 한계를 기록한다.
7. 결과·실제 사양·프롬프트·확인 상태를 기록하고, 합의한 소재 범위에서 마무리한다.

같은 문구로 별개의 이미지를 반복 생성하는 것만으로 일관성이 확보되었다고 보지 않는다. 생성 결과를 검사하고 어긋난 부분을 수정한다.

## 유지할 미술 기준

| 기준 | 내용 |
|---|---|
| 화풍 | Bg_Concept의 세밀한 손그림 질감 |
| 색감 | 차가운 청색·회청색, 은빛 달빛 |
| 소재 | 각진 설산 능선, 거친 고목, 원본의 바위·눈·얼음 표현 |
| 거리 | 원경은 대비와 윤곽을 부드럽게, 가까운 요소는 더 명확하게 |
| 연결 | 산 능선·안개·광원의 위치를 이웃 구역과 함께 확인 |
| 크기 | 캐릭터의 보이는 그림 크기와 실제 카메라 표시 범위를 함께 고려 |

## 분리할 소재

- 최후방: 하늘·달·먼 설산. 현재 시작맵 v01에는 먼 안개와 구름도 함께 포함되어 있다.
- 원경 구조물: 성·다리·절벽.
- 중경: 침엽수 숲, 독립적으로 움직일 필요가 있는 안개.
- 근경: 고목·뿌리·가지.
- 지형: 바위, 발판, 벽·천장 등.
- 표면: 지형과 분리된 눈 덮개, 필요한 얼음 장식.

현재 v01에 합쳐진 달·구름·안개는 각각 움직일 수 있는 독립 스프라이트가 아니다. 별도 움직임이 필요하면 나중에 분리 소재를 제작해야 한다. 현재 단계에서 관련 동작 코드를 만들지 않는다.

## 구역 진행

시작 → 등반 → 보스전 통로 → 보스전맵1 → 낙하 통로 → 보스전맵2.

현재 제작 폴더는 [StartMap](StartMap/README.md) 하나다. 나머지 구역은 아직 새 스프라이트를 만들지 않았다. 성소와 귀환 리프트는 이 목록의 미제작 항목이 아니라 제작 제외 항목이다.

## 해상도와 PPU

현재 시작맵 v01은 PPU 100, 원본 1448×1086이다. 캐릭터는 기본 PPU 200이다. 같은 PPU라는 이유만으로 화면상의 품질이 보장되지 않으며, Scale·카메라 범위·실제 픽셀 크기를 함께 확인한다.

최종 해상도·구간 분할 수는 미정이다. 요청 해상도와 실제 출력 크기를 구분하고, 확대 저장한 이미지를 네이티브 고해상도로 표기하지 않는다. 이미지 하나를 자르는 것만으로 새로운 세부 묘사가 생기지 않는다.
