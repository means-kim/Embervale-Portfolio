# 맵 아트 작업의 코드 범위

이 문서는 현재 진행 중인 맵 아트 작업에 관한 제한이다. 프로젝트 전체가 영구적으로 코딩을 금지한다는 의미는 아니며, 이후 사용자의 별도 개발 지시는 따로 따른다.

현재 사용자는 배치를 직접 담당하고 Codex에는 스프라이트 제작·분석·기록을 요청했다. 따라서 소재 제작을 이유로 아래 코드를 새로 만들거나 기존 코드에 추가하지 않는다.

- 자동 맵·씬 생성 및 자동 배치 도구.
- 이동, 전투, 콜라이더, 카메라 제어.
- 패럴랙스, 조명 애니메이션, 눈을 밟으면 사라지는 동작.
- 귀환 리프트 기능.

코드 파일이나 기존 사용자 변경·삭제 상태를 정리한다는 이유로 복구하거나 수정하지 않는다. 이번 인계 작업은 Markdown 작성만 수행한다.
