# 플레이어 프리팹

`Prefabs/Player_Hyunseo.prefab`을 현재 프로젝트 씬에 배치한다. 입력·이동·벽타기·공격·발소리 컴포넌트가 연결되어 있다. 기본 Scale 1.5는 기존 설정이며 위치는 (0,0,0)으로 정리했다. 기존 플레이어와 동시에 입력받지 않도록 사용자가 사용할 플레이어 하나를 선택한다.

## 조작과 유지한 변경

| 조작 | 동작 |
| --- | --- |
| A/D 또는 좌우 방향키 | 이동 |
| Space | 점프 / 벽 점프 |
| Shift | 대시 |
| S 또는 아래 방향키 | 발판 내려가기 |
| 마우스 좌클릭 | LeftHorizontalAttack → DownAttack, 연속 입력이 끊기면 처음부터 |
| W + 좌클릭 | 위 공격, 종료 후 0.3초 재사용 대기 |
| E | RightHorizontalAttack |
| R | FireBallAttack |

숫자 키는 직접 공격 입력으로 사용하지 않는다. Inspector의 Alpha1/Alpha2 항목은 좌클릭 콤보 데이터를 찾는 기존 내부 키다. 구형 UpAttack/Alpha3는 제거했다.

- 공격 중 이동 가능. 벽에 다시 붙으면 점프 횟수 회복.
- 발소리는 애니메이션 접지 구간에 맞춰 재생. 이동 중 공격은 보행 주기 유지.
- 근접 타격 판정은 플레이어 애니메이션 이벤트로 열고 닫으며, 성공한 타격에만 소리 재생. 잔상에는 피해 판정 없음.
- 위 공격은 팔을 수정한 `TestSprites/LeftLookUp_Grid512_v02.png` 사용. 프레임512×512, PPU200, 피벗(256,102).
- 위 이펙트는 기존 Left 이펙트를90도 회전. Scale10(이전 대비1.5배), 표시 위치Y2.6(이전 대비+0.5). 확대·이동 전 타격 범위는 콜라이더 보정으로 유지.

## 조정 위치

- 이동·점프·대시·벽타기: 플레이어 프리팹의 해당 컴포넌트 Inspector. 현재 최대 점프2회.
- 공격 피해·생성 위치·회복 시간·재사용 대기: `Data/*Attack.asset`.
- 공격 이펙트와 콜라이더: `Prefabs/Attacks`.
- 모션·타격 이벤트: `Animation/Player`, 이펙트 재생: `Animation/VFX`.
- 발소리: `PlayerFootsteps`와 `Data/Footstep_*`.

## 배치 및 추가 연결 사항

- 바닥/벽 콜라이더는 `Ground`, 내려갈 수 있는 발판은 `Platform` 태그를 사용한다. `Border` 충돌은 저장된 리스폰 위치로 이동한다.
- 기존 Input Manager의 Horizontal/Vertical 축과 기존 태그 설정을 사용한다. 전역 설정은 변경하지 않았다.
- 피해 대상 콜라이더에는 `HyunseoTest.DamageReceiver` 및 `Boss` 태그가 필요하고, 해당 대상 또는 부모에 `HyunseoTest.Health`를 연결한다. Health의 최대 체력은 반드시 양수로 설정한다. 기존 다른 Health/보스 시스템에는 자동 연결되지 않으므로 그 시스템에 맞는 피해 전달 연결은 추가 작업이다.
- 실제 사망 연출/체크포인트·세이브·전역 레벨 버프·카메라 추적 연결은 포함하지 않는다. 현재 Death 상태는 기존처럼 전용 모션이 비어 있다. 원래 게임 시스템 통합 완료로 취급하지 않는다.
- 공용 원본 이미지·사운드·머티리얼을 읽기 전용으로 참조한다. 이 폴더만 다른 프로젝트에 복사하는 방식은 지원하지 않는다. Unity에서 플레이어 프리팹을 Export Package할 때 Include dependencies를 켜고, 코드로만 참조하는 Runtime 폴더도 함께 선택한다.

## 정리 및 확인 범위

테스트 씬/방/UI, 생성·검증 스크립트, 캡처·영상·GIF·시안 원본, 미사용 위 공격 프리팹·클립·스프라이트·셰이더, 구형UpAttack, 디버그 카운터와 미사용 처리 코드를 제거했다. 현재 프리팹이 사용하는 자산과 런타임 타입만 유지했다. HyunseoTest namespace와 GUID는 참조 호환을 위해 유지했다.

정리 후 컴파일, 프리팹6개 참조/누락 스크립트 검사, 임시 Play에서 공격5종 시작·이동 유지, 근접4종 애니메이션 타격/중복 타격 방지/종료, 위 공격 재사용 대기를 확인했다. 실제 게임 씬 통합 및 전체 플레이 검증은 별도다.
