# 맵 제작에서 참고할 플레이어 크기

플레이어 애니메이션은 기존 자료를 유지한다. 이 문서는 배경 스케일 비교를 위한 참고이며, 캐릭터 설정이나 외형을 변경하는 지시가 아니다.

## 기본 사양

사용자가 제공한 사양과 기존 v4 설명서를 기준으로 정리했다. 실제 프리팹의 현재 Scale과 모든 프레임의 보이는 높이를 이번 문서 작업에서 다시 측정한 것은 아니다.

| 항목 | 기본값 |
|---|---|
| 팩 | GA1_Player_Motions_v4 |
| 개별 프레임 | 512×512px, RGBA PNG |
| PPU | 200 |
| Pivot | X 0.5 / Y 0.19921875 |
| 피벗 픽셀 위치 | 왼쪽 아래 기준 (256, 102) |
| 접지 기준선 | 이미지 위에서 Y=410px |
| 얼굴 방향 | 오른쪽 |
| Filter / Compression | Bilinear / None |
| Generate Mip Maps | Off |
| Mesh / Wrap | Full Rect / Clamp |
| 개별 프레임 Max Size | 512 |
| 시트 Slice | Grid by Cell Size 512×512 |
| 시트 Max Size | 4096 이상, 시트가 줄어들지 않도록 확인 |

## 크기 해석

- Scale 1에서 프레임 캔버스: 512 / 200 = 2.56×2.56 Unity 유닛.
- 이 값에는 투명 여백이 포함된다.
- 사용자 제공 Run 첫 프레임의 실제 그림 높이 예시: 약 337px / 200 = 1.685유닛, 약 1.69유닛.
- 자세마다 보이는 높이는 달라진다. 콜라이더 높이, 투명 캔버스 높이, 눈에 보이는 캐릭터 높이를 섞어서 비교하지 않는다.
- 과거에 논의한 1.2유닛을 현재 캐릭터의 확정 키로 적용하지 않는다.
- 배경 v01의 PPU 100과 배경용 밉맵 설정을 캐릭터 전체에 적용하지 않는다.
